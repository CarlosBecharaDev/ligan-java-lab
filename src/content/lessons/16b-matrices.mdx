## ¿Qué es una matriz?

Una **matriz** (arreglo bidimensional) es una estructura de datos que organiza elementos en filas y columnas. En Java, una matriz es simplemente un "arreglo de arreglos": cada elemento de la matriz es otro arreglo.

Imagina una **hoja de cálculo de Excel**: necesitas una fila y una columna para acceder a una celda. En Java, eso se escribe `matriz[fila][columna]`.

## Declaración e inicialización

```java
// Sintaxis completa: 3 filas, 4 columnas
int[][] matriz = new int[3][4];

// Sintaxis simplificada con valores
int[][] tabla = {
    {100, 200, 300},
    {400, 500, 600}
};

// Matriz irregular (cada fila con distinto tamaño)
int[][] irregular = new int[3][];
irregular[0] = new int[2];
irregular[1] = new int[4];
irregular[2] = new int[3];
```

## longitudes: filas vs columnas

```java
int[][] m = {
    {100, 200, 300},
    {400, 500, 600}
};

System.out.println(m.length);      // 2 (filas)
System.out.println(m[0].length);   // 3 (columnas de fila 0)
System.out.println(m[1].length);   // 3 (columnas de fila 1)
```

## Recorrer una matriz con ciclos anidados

<CodeBlock lang="java" title="Recorrer matriz con for anidados">
{`public class RecorrerMatriz {
    public static void main(String[] args) {
        int[][] matriz = {
            {100, 200, 300},
            {400, 500, 600}
        };

        for (int ren = 0; ren < matriz.length; ren++) {
            for (int col = 0; col < matriz[ren].length; col++) {
                System.out.printf("[%d][%d] = %d%n", ren, col, matriz[ren][col]);
            }
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
[0][0] = 100
[0][1] = 200
[0][2] = 300
[1][0] = 400
[1][1] = 500
[1][2] = 600
```

### Orden de recorrido

```
Matriz 2x3: [0][0] → [0][1] → [0][2] → (ren pasa a 1) → [1][0] → [1][1] → [1][2] → fin
```

- **Ciclo externo** (`ren`): recorre las filas
- **Ciclo interno** (`col`): recorre las columnas de la fila actual

## Cómo vive en memoria

```
STACK                    HEAP (arreglo de arreglos)
┌─────────────┐
│ matriz ──────┼──► [ ref0 | ref1 ]
└─────────────┘       │       │
                       ▼       ▼
                [100|200|300] [400|500|600]
```

La variable `matriz` en el Stack guarda una referencia a un arreglo que contiene dos referencias, cada una apuntando a un arreglo de enteros en el Heap.

## Matriz cuadrada y diagonal principal

Una **matriz cuadrada** tiene el mismo número de filas y columnas (`n x n`). La **diagonal principal** son las celdas donde el índice de fila es igual al índice de columna.

```java
int[][] m = {
    {100, 200, 300},
    {400, 500, 600},
    {700, 800, 900}
};
// Diagonal: [0][0]=100, [1][1]=500, [2][2]=900
```

<CodeBlock lang="java" title="Suma de diagonal principal">
{`public class SumaDiagonal {
    public static void main(String[] args) {
        int[][] m = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int suma = 0;
        for (int i = 0; i < m.length; i++) {
            suma += m[i][i];
        }
        System.out.println("Suma diagonal: " + suma);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Suma diagonal: 15
```

## Errores frecuentes

### Error 1: Invertir índices
```java
// ❌ Error: primer índice es fila, segundo es columna
matriz[col][ren] = 10;

// ✅ Correcto
matriz[ren][col] = 10;
```

### Error 2: Usar matriz.length para columnas
```java
// ❌ Error: matriz.length da el número de filas
for (int col = 0; col < matriz.length; col++)

// ✅ Correcto: matriz[0].length da las columnas
for (int col = 0; col < matriz[0].length; col++)
```

### Error 3: Imprimir la matriz directamente
```java
// ❌ Imprime dirección de memoria: [[I@1540e19d
System.out.println(matriz);

// ✅ Usa Arrays.deepToString()
System.out.println(Arrays.deepToString(matriz));
```

## Buenas prácticas

1. **Nombra con claridad** las variables que representan filas y columnas: `for (int fila = 0; fila < matriz.length; fila++)`
2. **Usa `matriz[i].length`** en el ciclo interno, no un número fijo
3. **`Arrays.deepToString(matriz)`** para depuración rápida
4. **`List<List<T>>`** cuando el tamaño de la matriz pueda cambiar dinámicamente
