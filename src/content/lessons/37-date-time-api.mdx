## La API java.time

La API moderna de fecha y hora en Java está en el paquete `java.time`. Es **inmutable**, **fluida** y **thread-safe**.

```java
import java.time.*;

// Clases principales
LocalDate fecha = LocalDate.now();           // 2026-07-27
LocalTime hora = LocalTime.now();            // 14:30:00
LocalDateTime fechaHora = LocalDateTime.now(); // 2026-07-27T14:30:00
```

## LocalDate — fecha sin hora

<CodeBlock lang="java" title="Operaciones con LocalDate">
{`import java.time.*;
import java.time.format.DateTimeFormatter;

public class LocalDateDemo {
    public static void main(String[] args) {
        // Crear fechas
        LocalDate hoy = LocalDate.now();
        LocalDate navidad = LocalDate.of(2026, 12, 25);
        LocalDate parseada = LocalDate.parse("2026-07-27");

        System.out.println("Hoy: " + hoy);
        System.out.println("Navidad: " + navidad);
        System.out.println("Parseada: " + parseada);

        // Acceder a campos
        System.out.println("Año: " + hoy.getYear());
        System.out.println("Mes: " + hoy.getMonth());
        System.out.println("Día: " + hoy.getDayOfMonth());
        System.out.println("Día de semana: " + hoy.getDayOfWeek());

        // Sumar/restar
        System.out.println("Mañana: " + hoy.plusDays(1));
        System.out.println("Próximo mes: " + hoy.plusMonths(1));
        System.out.println("Ayer: " + hoy.minusDays(1));
        System.out.println("¿Bisiesto?: " + hoy.isLeapYear());
    }
}`}
</CodeBlock>

```
Navidad: 2026-12-25
Parseada: 2026-07-27
Año: 2026
Mes: JULY
Día: 27
Día de semana: MONDAY
Mañana: 2026-07-28
Próximo mes: 2026-08-27
Ayer: 2026-07-26
¿Bisiesto?: false
```

## LocalTime y LocalDateTime

<CodeBlock lang="java" title="Trabajar con horas y fechas combinadas">
{`import java.time.*;

public class TimeDemo {
    public static void main(String[] args) {
        // LocalTime — solo hora
        LocalTime ahora = LocalTime.now();
        System.out.println("Ahora: " + ahora);

        LocalTime reunion = LocalTime.of(15, 30);
        System.out.println("Reunión: " + reunion);
        System.out.println("¿Es después?: " + ahora.isAfter(reunion));
        System.out.println("En 2 horas: " + ahora.plusHours(2));

        // LocalDateTime — fecha y hora combinadas
        LocalDateTime cita = LocalDateTime.of(2026, 7, 27, 10, 30);
        System.out.println("Cita: " + cita);
        System.out.println("Cita + 3 días: " + cita.plusDays(3));
    }
}`}
</CodeBlock>

## Period y Duration — calcular diferencias

<CodeBlock lang="java" title="Period (fechas) y Duration (tiempo)">
{`import java.time.*;

public class PeriodDurationDemo {
    public static void main(String[] args) {
        // Period — entre fechas
        LocalDate inicio = LocalDate.of(2026, 1, 1);
        LocalDate fin = LocalDate.of(2026, 12, 31);
        Period periodo = Period.between(inicio, fin);
        System.out.printf("Periodo: %d años, %d meses, %d días%n",
            periodo.getYears(),
            periodo.getMonths(),
            periodo.getDays());

        // Duration — entre horas
        LocalTime apertura = LocalTime.of(8, 0);
        LocalTime cierre = LocalTime.of(18, 0);
        Duration duracion = Duration.between(apertura, cierre);
        System.out.println("Horas laborales: " + duracion.toHours());
        System.out.println("Minutos: " + duracion.toMinutes());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Periodo: 0 años, 11 meses, 30 días
Horas laborales: 10
Minutos: 600
```
