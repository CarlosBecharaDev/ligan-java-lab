## ¿Qué es la Herencia?

La **herencia** permite crear una nueva clase basándose en una clase existente. La clase hija hereda atributos y métodos de la clase padre, y puede agregar o modificar comportamiento.

```java
// Clase padre (superclase)
public class Persona {
    String nombre;
    int edad;

    Persona(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    void saludar() {
        System.out.println("Hola, soy " + nombre);
    }
}

// Clase hija (subclase) que HEREDA de Persona
public class Doctor extends Persona {
    String especialidad;

    Doctor(String nombre, int edad, String especialidad) {
        super(nombre, edad);  // Llama al constructor de Persona
        this.especialidad = especialidad;
    }

    void diagnosticar() {
        System.out.println(nombre + " diagnostica en " + especialidad);
    }
}

// Doctor tiene: nombre, edad (heredados) + especialidad (propio)
Doctor d = new Doctor("Ana", 35, "Cardiología");
d.saludar();       // Hola, soy Ana (método heredado)
d.diagnosticar();  // Ana diagnostica en Cardiología (propio)
```

## La palabra clave `extends`

`extends` declara que una clase hereda de otra:

```java
public class Animal {
    String nombre;
    int patas;

    Animal(String nombre, int patas) {
        this.nombre = nombre;
        this.patas = patas;
    }

    void comer() {
        System.out.println(nombre + " está comiendo");
    }
}

// Perro HEREDA todo de Animal
public class Perro extends Animal {
    String raza;

    Perro(String nombre, String raza) {
        super(nombre, 4);  // Perro siempre tiene 4 patas
        this.raza = raza;
    }

    void ladrar() {
        System.out.println(nombre + " dice: Guau!");
    }
}
```

**Lo que hereda Perro de Animal:**
- Atributo `nombre` (heredado)
- Atributo `patas` (heredado)
- Método `comer()` (heredado)
- Atributo `raza` (propio)
- Método `ladrar()` (propio)

## La palabra clave `super`

`super` se usa para acceder a miembros de la clase padre:

<CodeBlock
  title="Usando super para constructores y métodos"
  lang="java"
  code={`public class Vehiculo {
    String marca;
    double velocidadMax;

    Vehiculo(String marca, double velocidadMax) {
        this.marca = marca;
        this.velocidadMax = velocidadMax;
    }

    void mostrarInfo() {
        System.out.println("Marca: " + marca + " | Vel. máx: " + velocidadMax + " km/h");
    }
}

public class Auto extends Vehiculo {
    int puertas;
    boolean tieneAire;

    Auto(String marca, double velocidadMax, int puertas, boolean tieneAire) {
        super(marca, velocidadMax);  // Llama constructor de Vehiculo
        this.puertas = puertas;
        this.tieneAire = tieneAire;
    }

    @Override
    void mostrarInfo() {
        super.mostrarInfo();  // Llama método del padre
        System.out.println("Puertas: " + puertas + " | Aire: " + tieneAire);
    }

    public static void main(String[] args) {
        Auto auto = new Auto("Toyota", 200, 4, true);
        auto.mostrarInfo();
        // Marca: Toyota | Vel. máx: 200.0 km/h
        // Puertas: 4 | Aire: true
    }
}`}
/>

**Usos de `super`:**
- `super(atributos)` -- Llama al constructor de la clase padre
- `super.metodo()` -- Llama a un método de la clase padre
- `super.atributo` -- Accede a un atributo del padre (si es `protected`)

## @Override: Personalizar Métodos Heredados

Cuando una clase hija quiere cambiar el comportamiento de un método heredado, usa `@Override`:

<CodeBlock
  title="Override de métodos"
  lang="java"
  code={`public class Animal {
    String nombre;

    Animal(String nombre) {
        this.nombre = nombre;
    }

    String hacerSonido() {
        return "...";
    }

    String describir() {
        return nombre + " hace " + hacerSonido();
    }
}

public class Gato extends Animal {
    Gato(String nombre) {
        super(nombre);
    }

    @Override
    String hacerSonido() {
        return "Miau!";
    }
}

public class Perro extends Animal {
    Perro(String nombre) {
        super(nombre);
    }

    @Override
    String hacerSonido() {
        return "Guau!";
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a1 = new Gato("Michi");
        Animal a2 = new Perro("Rex");

        System.out.println(a1.describir());  // Michi hace Miau!
        System.out.println(a2.describir());  // Rex hace Guau!
    }
}`}
/>

**`@Override` es un annotation que:**
- Indica que se está sobreescribiendo un método del padre
- Java verifica que el método realmente exista en el padre
- Si hay un error de firma, el compilador lo detecta

## Cadena de Constructores con `super()`

Cuando creas un objeto hijo, Java ejecuta primero el constructor del padre:

```java
public class Persona {
    Persona(String nombre) {
        System.out.println("1. Constructor de Persona: " + nombre);
    }
}

public class Doctor extends Persona {
    Doctor(String nombre, String especialidad) {
        super(nombre);  // Primero se ejecuta Persona
        System.out.println("2. Constructor de Doctor: " + especialidad);
    }
}

// Al crear un Doctor:
Doctor d = new Doctor("Ana", "Cardiología");
// Salida:
// 1. Constructor de Persona: Ana
// 2. Constructor de Doctor: Cardiología
```

## Ejemplo Real: Salud - Doctor extends Persona

<CodeBlock

  code={`public class Persona {
    protected String nombre;
    protected int edad;
    protected String telefono;

    Persona(String nombre, int edad, String telefono) {
        this.nombre = nombre;
        this.edad = edad;
        this.telefono = telefono;
    }

    void mostrarInfo() {
        System.out.println(nombre + " | " + edad + " años | Tel: " + telefono);
    }

    String getRol() {
        return "Persona";
    }
}

public class Doctor extends Persona {
    private String especialidad;
    private int consultasHoy;

    Doctor(String nombre, int edad, String telefono, String especialidad) {
        super(nombre, edad, telefono);
        this.especialidad = especialidad;
        this.consultasHoy = 0;
    }

    void atenderPaciente(String paciente) {
        consultasHoy++;
        System.out.println("Dr. " + nombre + " atiende a " + paciente +
                           " (Consulta #" + consultasHoy + ")");
    }

    @Override
    void mostrarInfo() {
        super.mostrarInfo();
        System.out.println("Especialidad: " + especialidad + " | Consultas hoy: " + consultasHoy);
    }

    @Override
    String getRol() {
        return "Doctor de " + especialidad;
    }

    public static void main(String[] args) {
        Doctor dr = new Doctor("Ana López", 35, "555-0101", "Cardiología");
        dr.mostrarInfo();
        // Ana López | 35 años | Tel: 555-0101
        // Especialidad: Cardiología | Consultas hoy: 0

        dr.atenderPaciente("Carlos Ruiz");
        dr.atenderPaciente("María García");

        System.out.println("Rol: " + dr.getRol());
        // Rol: Doctor de Cardiología
    }
}`}

## Ejemplo Real: E-commerce - DigitalProduct extends Product

<CodeBlock
  title="Productos físicos y digitales"
  lang="java"
  code={`public class Producto {
    protected String nombre;
    protected double precio;
    protected int stock;

    Producto(String nombre, double precio, int stock) {
        this.nombre = nombre;
        this.precio = precio;
        this.stock = stock;
    }

    boolean hayStock() {
        return stock > 0;
    }

    void vender(int cantidad) {
        if (cantidad <= stock) {
            stock -= cantidad;
            System.out.println("Venta: " + cantidad + " x " + nombre);
        } else {
            System.out.println("Stock insuficiente para " + nombre);
        }
    }

    void mostrar() {
        String estado = hayStock() ? "Disponible" : "Agotado";
        System.out.println(nombre + " - $" + precio + " | " + estado + " (" + stock + ")");
    }

    String getTipo() {
        return "Producto físico";
    }
}

public class ProductoDigital extends Producto {
    private double tamanoMB;
    private int descargasPermitidas;
    private int descargasRealizadas;

    ProductoDigital(String nombre, double precio, double tamanoMB, int descargasMax) {
        super(nombre, precio, 1);  // Stock siempre 1 (infinito digital)
        this.tamanoMB = tamanoMB;
        this.descargasPermitidas = descargasMax;
        this.descargasRealizadas = 0;
    }

    @Override
    void vender(int cantidad) {
        // Los productos digitales no agotan stock
        System.out.println("Descarga permitida: " + nombre);
    }

    void descargar() {
        if (descargasRealizadas < descargasPermitidas) {
            descargasRealizadas++;
            System.out.println("Descargando " + nombre + " (" + tamanoMB + " MB)..."
                               + " [" + descargasRealizadas + "/" + descargasPermitidas + "]");
        } else {
            System.out.println("Límite de descargas alcanzado para " + nombre);
        }
    }

    @Override
    void mostrar() {
        System.out.println(nombre + " - $" + precio + " | " + tamanoMB + " MB"
                           + " | Descargas: " + descargasRealizadas + "/" + descargasPermitidas);
    }

    @Override
    String getTipo() {
        return "Producto digital";
    }

    public static void main(String[] args) {
        Producto laptop = new Producto("Laptop HP", 1200.00, 5);
        ProductoDigital ebook = new ProductoDigital("Java Guía", 29.99, 5.2, 3);

        laptop.mostrar();
        ebook.mostrar();

        laptop.vender(2);   // Venta: 2 x Laptop HP
        ebook.descargar();  // Descargando Java Guía (5.2 MB)... [1/3]
        ebook.descargar();  // Descargando Java Guía (5.2 MB)... [2/3]
        ebook.descargar();  // Descargando Java Guía (5.2 MB)... [3/3]
        ebook.descargar();  // Límite de descargas alcanzado

        System.out.println("Tipo laptop: " + laptop.getTipo());    // Producto físico
        System.out.println("Tipo ebook: " + ebook.getTipo());      // Producto digital
    }
}`}

## Resumen

| Concepto | Descripción |
|----------|-------------|
| **extends** | Declara que una clase hereda de otra |
| **super** | Accede a atributos/métodos del padre |
| **super()** | Llama al constructor del padre |
| **@Override** | Indica que se sobreescribe un método heredado |
| **Herencia** | Relación "es-uno-de" (Doctor es Persona) |
| **Subclase** | Clase que hereda (hija) |
| **Superclase** | Clase de la cual se hereda (padre) |
| **Herencia múltiple** | No permitida en Java (solo una superclase) |

---

## Preguntas Frecuentes

<details>
<summary>¿Puede una clase heredar de varias clases?</summary>
No. Java no permite herencia múltiple de clases. Una clase solo puede extender de una superclase. Para funcionalidad múltiple, se usan interfaces.
</details>

<details>
<summary>¿Cuándo uso herencia vs composición?</summary>
Usa herencia cuando existe una relación natural "es-uno-de" (Doctor es Persona). Usa composición cuando la relación es "tiene-uno" (Auto tiene Motor). La composición es más flexible.
</details>

<details>
<summary>¿Qué pasa si no pongo super() en el constructor?</summary>
Java inserta `super()` automáticamente (constructor vacío del padre). Si el padre no tiene constructor sin parámetros, da error de compilación.
</details>

<details>
<summary>¿Es obligatorio usar @Override?</summary>
No es obligatorio, pero es muy recomendable. Sin él, si cambias la firma del método y no coincides con el del padre, Java lo tratará como un método nuevo en vez de un override.
</details>
