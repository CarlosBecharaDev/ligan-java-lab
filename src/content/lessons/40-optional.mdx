## ¿Qué es Optional?

`Optional<T>` es un contenedor que puede contener un valor de tipo T... o no. Es una forma explícita de decir "este método puede no tener resultado".

```java
// En lugar de:
String resultado = buscar("id");  // ¿puede retornar null?
if (resultado != null) { ... }

// Con Optional:
Optional<String> resultado = buscar("id");  // explícito: puede no tener valor
resultado.ifPresent(System.out::println);
```

## Crear Optionals

<CodeBlock lang="java" title="Las tres formas de crear Optional">
{`import java.util.*;

public class CrearOptional {
    public static void main(String[] args) {
        // 1. Optional.of — cuando SABES que el valor NO es null
        Optional<String> presente = Optional.of("Hola");
        System.out.println("presente: " + presente);

        // 2. Optional.ofNullable — cuando PUEDE ser null
        String nulo = null;
        Optional<String> vacio = Optional.ofNullable(nulo);
        System.out.println("vacio: " + vacio);

        // 3. Optional.empty — Optional vacío explícito
        Optional<String> explicito = Optional.empty();
        System.out.println("explicito: " + explicito);

        // Verificar si hay valor
        System.out.println("presente.isPresent(): " + presente.isPresent());
        System.out.println("vacio.isPresent(): " + vacio.isPresent());
        System.out.println("presente.isEmpty(): " + presente.isEmpty());

        // Java 11+:
        System.out.println("vacio.isEmpty(): " + vacio.isEmpty());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
presente: Optional[Hola]
vacio: Optional.empty
explicito: Optional.empty
presente.isPresent(): true
vacio.isPresent(): false
presente.isEmpty(): false
vacio.isEmpty(): true
```

## Extraer valores

<CodeBlock lang="java" title="Formas seguras de obtener valores de Optional">
{`import java.util.*;

public class ExtraerOptional {
    public static void main(String[] args) {
        Optional<String> opt = Optional.of("Java");
        Optional<String> vacio = Optional.empty();

        // get — solo si estás seguro que hay valor
        System.out.println("get: " + opt.get());

        // orElse — valor por defecto
        System.out.println("orElse: " + vacio.orElse("default"));

        // orElseGet — valor por defecto con lambda (solo se evalúa si está vacío)
        System.out.println("orElseGet: " + vacio.orElseGet(() -> "generado"));

        // orElseThrow — lanzar excepción si vacío
        try {
            vacio.orElseThrow(() -> new RuntimeException("No hay valor"));
        } catch (RuntimeException e) {
            System.out.println("orElseThrow: " + e.getMessage());
        }

        // ifPresent — ejecutar acción solo si hay valor
        opt.ifPresent(v -> System.out.println("Valor: " + v));
    }
}`}
</CodeBlock>

## Operaciones con lambdas

<CodeBlock lang="java" title="Optional con map, filter, ifPresent">
{`import java.util.*;

public class OptionalLambdas {
    public static void main(String[] args) {
        Optional<String> opt = Optional.of("Java 21");
        Optional<String> vacio = Optional.empty();

        // map — transformar valor si existe
        Optional<Integer> longitud = opt.map(String::length);
        System.out.println("Longitud: " + longitud.orElse(0));

        vacio.map(String::length)
             .ifPresent(l -> System.out.println("Nunca se imprime"));

        // filter — probar condición
        opt.filter(s -> s.contains("Java"))
           .ifPresent(s -> System.out.println("Contiene Java: " + s));

        opt.filter(s -> s.startsWith("Python"))
           .ifPresent(s -> System.out.println("Nunca se imprime"));

        // flatMap — para Optionals anidados
        Optional<String> anidado = Optional.of("  texto  ");
        Optional<Integer> resultado = anidado
            .map(String::trim)
            .flatMap(s -> Optional.of(s.length()));
        System.out.println("Trim length: " + resultado.orElse(0));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Longitud: 7
Contiene Java: Java 21
Trim length: 7
```

## Cuándo NO usar Optional

- ❌ Como campo de clase
- ❌ Como parámetro de método
- ❌ En colecciones (`List<Optional<String>>`)
- ❌ Como instancia serializable

```java
// ❌ Mal
class Persona {
    private Optional<String> email;  // No
}

// ✅ Bien
class Persona {
    private String email;  // null significa "sin email"
}
```
