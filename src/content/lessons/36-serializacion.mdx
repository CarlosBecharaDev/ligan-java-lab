      import java.io.*;
      import java.util.ArrayList;

      class Producto implements Serializable {
          private static final long serialVersionUID = 1L;
          String nombre;
          double precio;
          int cantidad;

          Producto(String nombre, double precio, int cantidad) {
              this.nombre = nombre;
              this.precio = precio;
              this.cantidad = cantidad;
          }

          public String toString() {
              return String.format("%s x%d ($%.2f c/u)",
                  nombre, cantidad, precio);
          }
      }

      public class CarritoPersistente {
          static void guardarCarrito(ArrayList<Producto> carrito, String ruta) {
              try (ObjectOutputStream oos = new ObjectOutputStream(
                      new FileOutputStream(ruta))) {
                  oos.writeObject(carrito);
                  System.out.println("Carrito guardado: " + carrito.size() + " productos");
              } catch (IOException e) {
                  System.out.println("Error al guardar: " + e.getMessage());
              }
          }

          static ArrayList<Producto> cargarCarrito(String ruta) {
              try (ObjectInputStream ois = new ObjectInputStream(
                      new FileInputStream(ruta))) {
                  @SuppressWarnings("unchecked")
                  ArrayList<Producto> carrito = (ArrayList<Producto>) ois.readObject();
                  return carrito;
              } catch (IOException | ClassNotFoundException e) {
                  return new ArrayList<>();
              }
          }

          public static void main(String[] args) {
              ArrayList<Producto> carrito = new ArrayList<>();
              carrito.add(new Producto("Laptop", 2500.00, 1));
              carrito.add(new Producto("Mouse", 45.00, 2));

              guardarCarrito(carrito, "carrito.dat");
              ArrayList<Producto> cargado = cargarCarrito("carrito.dat");
              System.out.println("Carrito cargado:");
              for (Producto p : cargado) System.out.println("  " + p);
          }
      }

      import java.io.*;
      import java.util.ArrayList;

      class HistoriaClinica implements Serializable {
          private static final long serialVersionUID = 2L;
          String nombre;
          String diagnostico;
          transient double temperaturaActual;  // No se guarda

          HistoriaClinica(String nombre, String diagnostico) {
              this.nombre = nombre;
              this.diagnostico = diagnostico;
          }

          private void writeObject(ObjectOutputStream oos) throws IOException {
              oos.defaultWriteObject();
          }

          private void readObject(ObjectInputStream ois)
                  throws IOException, ClassNotFoundException {
              ois.defaultReadObject();
              temperaturaActual = 0.0;  // valor por defecto al cargar
          }
      }

      public class GuardarHistorial {
          public static void main(String[] args)
                  throws Exception {
              ArrayList<HistoriaClinica> historiales = new ArrayList<>();
              historiales.add(new HistoriaClinica("Ana", "Gripe"));
              historiales.add(new HistoriaClinica("Luis", "Fractura"));
              historiales.get(0).temperaturaActual = 38.5;
              historiales.get(1).temperaturaActual = 36.8;

              try (ObjectOutputStream oos = new ObjectOutputStream(
                      new FileOutputStream("historiales.dat"))) {
                  oos.writeObject(historiales);
              }

              try (ObjectInputStream ois = new ObjectInputStream(
                      new FileInputStream("historiales.dat"))) {
                  @SuppressWarnings("unchecked")
                  ArrayList<HistoriaClinica> cargados =
                      (ArrayList<HistoriaClinica>) ois.readObject();
                  for (HistoriaClinica h : cargados) {
                      System.out.printf("%s: %s (temp: %.1f)%n",
                          h.nombre, h.diagnostico, h.temperaturaActual);
                  }
              }
          }
      }
    result: |
      Ana: Gripe (temp: 0.0)
      Luis: Fractura (temp: 0.0)

## ¿Qué es la serialización?

Es el proceso de convertir un **objeto completo** (con todos sus campos) en un array de bytes para guardarlo en disco o enviarlo por red. La deserialización hace el proceso inverso: bytes → objeto.

```java
// Guardar un objeto en disco
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("objeto.dat"));
oos.writeObject(miObjeto);
oos.close();

// Leerlo de vuelta
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("objeto.dat"));
MiClase obj = (MiClase) ois.readObject();
ois.close();
```

## Crear una clase serializable

<CodeBlock lang="java" title="Implementar Serializable es simple">
{`import java.io.Serializable;

class Persona implements Serializable {
    private static final long serialVersionUID = 1L;

    String nombre;
    int edad;
    double altura;

    Persona(String nombre, int edad, double altura) {
        this.nombre = nombre;
        this.edad = edad;
        this.altura = altura;
    }

    public String toString() {
        return nombre + ", " + edad + " años, " + altura + " m";
    }
}`}
</CodeBlock>

Solo necesitas implementar la interfaz `Serializable` — no tiene métodos que implementar (es una interfaz de marcado).

## Guardar y leer objetos

<CodeBlock lang="java" title="ObjectOutputStream y ObjectInputStream">
{`import java.io.*;

public class GuardarPersonas {
    public static void main(String[] args)
            throws Exception {
        // --- Guardar objetos ---
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("personas.dat"))) {
            oos.writeObject(new Persona("Ana", 25, 1.65));
            oos.writeObject(new Persona("Luis", 30, 1.80));
            oos.writeObject(new Persona("María", 35, 1.70));
            System.out.println("Objetos guardados");
        }

        // --- Leer objetos ---
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("personas.dat"))) {
            for (int i = 0; i < 3; i++) {
                Persona p = (Persona) ois.readObject();
                System.out.println("Leído: " + p);
            }
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Objetos guardados
Leído: Ana, 25 años, 1.65 m
Leído: Luis, 30 años, 1.8 m
Leído: María, 35 años, 1.7 m
```

## transient — campos que no se guardan

<CodeBlock lang="java" title="Excluir campos con transient">
{`import java.io.Serializable;

class Sesion implements Serializable {
    private static final long serialVersionUID = 1L;

    String usuario;
    transient String tokenSeguridad;  // NO se guarda en disco
    transient long horaExpiracion;     // NO se guarda

    Sesion(String usuario, String token) {
        this.usuario = usuario;
        this.tokenSeguridad = token;
        this.horaExpiracion = System.currentTimeMillis() + 3600000;
    }

    public String toString() {
        return usuario + " (token: " + tokenSeguridad + ")";
    }
}`}
</CodeBlock>

## serialVersionUID — control de versiones

```java
class MiClase implements Serializable {
    // Si cambias la clase, cambia este número
    private static final long serialVersionUID = 1L;
    // ...
}
```

**Si NO declaras serialVersionUID:**
- Java genera uno automáticamente basado en la estructura de la clase
- Si cambias algún campo, el UID cambia y la deserialización falla
- **Siempre** declara serialVersionUID explícitamente
