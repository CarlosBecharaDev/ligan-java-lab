## Leer un archivo de texto

La forma más común de leer archivos de texto en Java:

<CodeBlock lang="java" title="Leer archivo con BufferedReader">
{`import java.io.*;

public class LeerArchivo {
    public static void main(String[] args) {
        // try-with-resources cierra el archivo automáticamente
        try (BufferedReader br = new BufferedReader(new FileReader("datos.txt"))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                System.out.println(linea);
            }
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**¿Qué hace cada parte?**
- `FileReader(ruta)`: abre el archivo para lectura
- `BufferedReader(br)`: envuelve el FileReader para leer por líneas
- `readLine()`: lee una línea completa, retorna `null` al final
- `try-with-resources`: cierra el archivo automáticamente

## Manejo de excepciones

Las operaciones de archivos lanzan **excepciones checked** que debes manejar:

| Excepción | Cuándo ocurre |
|-----------|---------------|
| `FileNotFoundException` | El archivo no existe en la ruta especificada |
| `IOException` | Error general de E/S (disco, permisos, etc.) |
| `SecurityException` (unchecked) | Sin permisos de lectura |

## Leer todo el archivo de una vez

<CodeBlock lang="java" title="Leer todo el archivo como String (Java 11+)">
{`import java.nio.file.*;

public class LeerTodo {
    public static void main(String[] args) {
        try {
            String contenido = Files.readString(Path.of("datos.txt"));
            System.out.println(contenido);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Leer línea por línea con NIO.2

<CodeBlock lang="java" title="Leer con Files.lines() (Java 8+)">
{`import java.nio.file.*;
import java.util.stream.Stream;

public class LeerConStream {
    public static void main(String[] args) {
        try (Stream<String> lineas = Files.lines(Path.of("datos.txt"))) {
            lineas.forEach(System.out::println);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Crear y verificar rutas

<CodeBlock lang="java" title="Operaciones con Path">
{`import java.nio.file.*;
import java.io.File;

public class OperacionesPath {
    public static void main(String[] args) {
        Path ruta = Path.of("datos/config.properties");

        // Información
        System.out.println("Existe: " + Files.exists(ruta));
        System.out.println("Archivo: " + Files.isRegularFile(ruta));
        System.out.println("Directorio: " + Files.isDirectory(ruta));
        System.out.println("Tamaño: " + (Files.exists(ruta) ? Files.size(ruta) : 0));
        System.out.println("Padre: " + ruta.getParent());
        System.out.println("Nombre: " + ruta.getFileName());

        // File (API antigua)
        File archivo = ruta.toFile();
        System.out.println("Ruta absoluta: " + archivo.getAbsolutePath());
    }
}`}
</CodeBlock>

Nota: usa `//` para escribir反斜杠 en Java: `"C:\\\\Datos\\\\archivo.txt"` o mejor aún, usa `Path.of()` con forward slashes.

public class LeerBinario {

        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
