## Bucles indeterminados

Los bucles while y do-while son **indeterminados**: se repiten un número *desconocido* de veces hasta que una condición se vuelve false. A diferencia del bucle for (donde conoces de antemano cuántas veces repetirás), estos bucles son ideales para casos como:

- Leer datos hasta fin de archivo
- Pedir entrada hasta que sea válida
- Esperar hasta que se cumpla una condición

## El bucle while

`while` verifica la condición **antes** de cada iteración (pre-test). Si la condición es false desde el inicio, el cuerpo **no se ejecuta nunca**:

```java
while (condicion) {
    // cuerpo que se repite mientras condicion sea true
    // debe modificar algo para que la condición eventualmente sea false
}
```

<CodeBlock lang="java" title="while — cuenta regresiva">
{`public class CuentaRegresiva {
    public static void main(String[] args) {
        int contador = 5;

        while (contador > 0) {
            System.out.println("Cuenta: " + contador);
            contador--;  // importante: modifica la condición
        }

        System.out.println("¡Despegue! 🚀");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Cuenta: 5
Cuenta: 4
Cuenta: 3
Cuenta: 2
Cuenta: 1
¡Despegue! 🚀
```

### while con condición false desde el inicio

Si la condición es false al empezar, el bucle no se ejecuta:

```java
int x = 10;
while (x < 5) {
    System.out.println("Esto nunca se imprime");
}
System.out.println("Fin");  // imprime "Fin"
```

## El bucle do-while

`do-while` verifica la condición **después** de cada iteración (post-test). El cuerpo **se ejecuta al menos una vez**, sin importar la condición:

```java
do {
    // cuerpo (se ejecuta mínimo 1 vez)
} while (condicion);  // nota el punto y coma final
```

<CodeBlock lang="java" title="do-while — menú interactivo">
{`public class MenuInteractivo {
    public static void main(String[] args) {
        int opcion = 0;

        do {
            System.out.println("\\n--- MENÚ ---");
            System.out.println("1. Ver perfil");
            System.out.println("2. Configuración");
            System.out.println("3. Salir");
            // Simulamos que el usuario elige 3 en la primera iteración
            opcion = 3;
            System.out.println("Opción elegida: " + opcion);
        } while (opcion != 3);

        System.out.println("Saliendo del menú...");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
--- MENÚ ---
1. Ver perfil
2. Configuración
3. Salir
Opción elegida: 3
Saliendo del menú...
```

> 💡 El menú se muestra **al menos una vez** aunque el usuario elija "Salir" inmediatamente. Ese es el propósito de do-while.

## Diferencia clave: while vs do-while

| Característica | while | do-while |
|----------------|-------|----------|
| Verificación | Antes del cuerpo | Después del cuerpo |
| Mínimo de ejecuciones | 0 | 1 |
| Punto y coma final | No | Sí |
| Uso típico | Procesamiento condicional | Menús, validación |

<CodeBlock lang="java" title="Mismo valor, diferente verificación">
{`public class ComparacionBucles {
    public static void main(String[] args) {
        int n = 10;

        // while: NO se ejecuta porque 10 < 5 es false al inicio
        System.out.println("--- while ---");
        while (n < 5) {
            System.out.println("dentro del while");
        }
        System.out.println("while terminado sin imprimir");

        // do-while: se ejecuta UNA vez aunque la condición sea false
        System.out.println("--- do-while ---");
        do {
            System.out.println("dentro del do-while");
        } while (n < 5);
        System.out.println("do-while terminado");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
--- while ---
while terminado sin imprimir
--- do-while ---
dentro del do-while
do-while terminado
```

## Acumuladores y contadores

Un patrón común: usar while con un **acumulador** (suma valores) y un **contador** (cuenta iteraciones):

<CodeBlock lang="java" title="while — suma de números hasta cero (centinela)">
{`public class SumaSentinela {
    public static void main(String[] args) {
        int[] datos = {5, 8, 3, 0};  // 0 es el valor centinela
        int i = 0;
        int suma = 0;
        int cuenta = 0;

        while (i < datos.length && datos[i] != 0) {
            suma += datos[i];
            cuenta++;
            i++;
        }

        System.out.println("Números sumados: " + cuenta);
        System.out.println("Total: " + suma);
        System.out.println("Promedio: " + (cuenta > 0 ? (double) suma / cuenta : 0));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Números sumados: 3
Total: 16
Promedio: 5.333333333333333
```

## El peligro del bucle infinito

El error más común con while es olvidar modificar la variable de condición:

```java
// ❌ Bucle infinito: contador nunca cambia
int i = 0;
while (i < 10) {
    System.out.println(i);
    // falta i++ → i siempre es 0 → bucle eterno
}

// ✅ Correcto: el contador se incrementa
int i = 0;
while (i < 10) {
    System.out.println(i);
    i++;
}
```

<CodeBlock lang="java" title="Cuidado: si el cuerpo no cambia la condición, es infinito">
{`public class CuentaRegresivaBug {
    public static void main(String[] args) {
        int x = 5;

        while (x > 0) {
            System.out.println("x = " + x);
            x--;  // sin esta línea sería infinito
        }
        System.out.println("Fin");
    }
}`}
</CodeBlock>

## Patrón: entrada validada con do-while

El uso más clásico de do-while es pedir entrada hasta que sea válida:

<CodeBlock lang="java" title="Validación de nota con do-while">
{`public class NotaValida {
    public static void main(String[] args) {
        // Simulamos entradas del usuario
        int[] entradas = {150, -5, 85};
        int idx = 0;
        int nota;

        do {
            nota = entradas[idx++];  // lee siguiente entrada
            if (nota < 0 || nota > 100) {
                System.out.println("Nota " + nota + " inválida. Debe ser 0-100.");
            }
        } while (nota < 0 || nota > 100);

        System.out.println("Nota aceptada: " + nota);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Nota 150 inválida. Debe ser 0-100.
Nota -5 inválida. Debe ser 0-100.
Nota aceptada: 85
```

## ¿Cuándo while y cuándo for?

| Situación | Bucle recomendado |
|-----------|-------------------|
| Número de iteraciones conocido | ✅ **for** |
| Iterar hasta fin de archivo o condición externa | ✅ **while** |
| Menú que se muestra al menos una vez | ✅ **do-while** |
| Validar entrada hasta que sea correcta | ✅ **do-while** |
| Procesar hasta encontrar un valor centinela | ✅ **while** |
| Recorrer un array completo | ✅ **for** (o **for-each**) |
