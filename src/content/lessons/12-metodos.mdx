## ¿Qué es un método?

Un método es un **bloque de código con un nombre** que realiza una tarea específica. En lugar de escribir todo el código en `main`, lo divides en métodos que hacen cosas concretas, que puedes reutilizar cuantas veces necesites.

```
// Sintaxis básica
modificador tipoRetorno nombreMetodo(parametros) {
    // cuerpo
    return valor; // si tipoRetorno no es void
}
```

## Tu primer método

Veamos un método simple que saluda a una persona:

<CodeBlock lang="java" title="Método básico — saludar">
{`public class Saludar {
    // Definición del método
    static void saludar(String nombre) {
        System.out.println("¡Hola, " + nombre + "!");
    }

    public static void main(String[] args) {
        // Llamada al método
        saludar("Ana");
        saludar("Luis");
        saludar("María");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
¡Hola, Ana!
¡Hola, Luis!
¡Hola, María!
```

El método `saludar` se define una vez y se llama tres veces con diferentes argumentos. Sin métodos, tendrías que escribir `System.out.println("¡Hola, " + nombre + "!");` tres veces.

## Parámetros vs argumentos

Estos términos se confunden frecuentemente:

- **Parámetro**: la variable en la definición del método (`String nombre`)
- **Argumento**: el valor real que pasas al llamar (`"Ana"`)

```java
//            parámetros
static int sumar(int a, int b) {
    return a + b;
}

//         argumentos
int resultado = sumar(5, 3);  // a=5, b=3 → retorna 8
```

## Métodos con retorno

Un método puede **devolver un valor** usando `return`. El tipo de retorno indica qué tipo de dato devuelve:

<CodeBlock lang="java" title="Método con retorno — calcular área de círculo">
{`public class AreaCirculo {
    static double calcularArea(double radio) {
        return Math.PI * radio * radio;
    }

    static String clasificar(double area) {
        if (area < 10)  return "Pequeño";
        if (area < 50)  return "Mediano";
        return "Grande";
    }

    public static void main(String[] args) {
        double[] radios = {2.0, 4.0, 7.0};

        for (double r : radios) {
            double area = calcularArea(r);
            String tipo = clasificar(area);
            System.out.printf("Radio %.1f → Area: %.2f (%s)%n",
                r, area, tipo);
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Radio 2.0 → Area: 12.57 (Mediano)
Radio 4.0 → Area: 50.27 (Grande)
Radio 7.0 → Area: 153.94 (Grande)
```

## Métodos void — sin retorno

Un método `void` ejecuta una acción pero **no devuelve nada**. No necesita `return`, o puede usar `return;` sin valor para salir antes:

<CodeBlock lang="java" title="Método void — imprimir reporte">
{`public class Reporte {
    static void imprimirLinea(char caracter, int veces) {
        for (int i = 0; i < veces; i++) {
            System.out.print(caracter);
        }
        System.out.println();
    }

    static void imprimirTitulo(String titulo) {
        imprimirLinea('=', 40);
        System.out.println("  " + titulo);
        imprimirLinea('=', 40);
    }

    public static void main(String[] args) {
        imprimirTitulo("REPORTE DE VENTAS");
        System.out.println("Enero:   $12,500");
        System.out.println("Febrero: $15,200");
        System.out.println("Marzo:   $18,900");
        imprimirLinea('-', 40);
        System.out.println("Total:   $46,600");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
========================================
  REPORTE DE VENTAS
========================================
Enero:   $12,500
Febrero: $15,200
Marzo:   $18,900
----------------------------------------
Total:   $46,600
```

## Múltiples parámetros

Un método puede recibir varios parámetros de diferentes tipos:

<CodeBlock lang="java" title="Múltiples parámetros — calculadora de impuestos">
{`public class Impuestos {
    static double calcularImpuesto(
            double monto, double tasaPorcentaje, double descuento) {
        double base = monto - descuento;
        if (base < 0) base = 0;
        return base * tasaPorcentaje / 100;
    }

    public static void main(String[] args) {
        double imp1 = calcularImpuesto(100000, 19, 0);
        double imp2 = calcularImpuesto(100000, 19, 20000);
        double imp3 = calcularImpuesto(50000, 16, 5000);

        System.out.printf("Sin descuento: $%.2f%n", imp1);
        System.out.printf("Con descuento $20k: $%.2f%n", imp2);
        System.out.printf("Tasa 16%%: $%.2f%n", imp3);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Sin descuento: $19000.00
Con descuento $20k: $15200.00
Tasa 16%: $7200.00
```

## El orden importa

En Java, un método debe estar **definido antes** de ser usado (dentro de la misma clase). La buena práctica es poner los métodos auxiliares antes de `main`, o en una clase separada.

```
// ✅ Correcto: método definido antes de usarlo
static void saludar(String nombre) { ... }

public static void main(String[] args) {
    saludar("Ana"); // funciona
}
```

## Parámetros por valor

En Java, los tipos primitivos se pasan **por valor**: el método recibe una copia, no la variable original. Modificar el parámetro dentro del método NO cambia la variable original:

<CodeBlock lang="java" title="Paso por valor — el original no cambia">
{`public class PasoPorValor {
    static void duplicar(int numero) {
        numero = numero * 2; // modifica la copia
        System.out.println("Dentro del método: " + numero);
    }

    public static void main(String[] args) {
        int edad = 25;
        System.out.println("Antes: " + edad);
        duplicar(edad);
        System.out.println("Después: " + edad);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Antes: 25
Dentro del método: 50
Después: 25
```

La variable `edad` sigue siendo 25 porque `duplicar` recibió una copia, no la referencia original.
