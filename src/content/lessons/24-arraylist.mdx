## ¿Qué es un ArrayList?

Un **ArrayList** es una colección que funciona como un array pero con **tamaño dinámico**: crece y decrece automáticamente cuando agregas o eliminas elementos. Es parte del **Java Collections Framework** desde Java 1.2.

```java
import java.util.ArrayList;

ArrayList<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Luis");
System.out.println(nombres);  // [Ana, Luis]
```

**Importante:** Debes importar `java.util.ArrayList` antes de usarlo.

## Crear un ArrayList

```java
import java.util.ArrayList;

// Lista de Strings
ArrayList<String> frutas = new ArrayList<>();

// Lista de enteros (usa Integer, no int)
ArrayList<Integer> numeros = new ArrayList<>();

// Lista de decimales
ArrayList<Double> precios = new ArrayList<>();

// Lista vacía con capacidad inicial
ArrayList<String> lista = new ArrayList<>(100);
```

## Agregar y eliminar elementos

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `add(elemento)` | Agrega al final | `list.add("A")` |
| `add(index, elemento)` | Agrega en posición | `list.add(0, "A")` |
| `remove(elemento)` | Elimina la primera ocurrencia | `list.remove("A")` |
| `remove(index)` | Elimina por índice | `list.remove(0)` |
| `set(index, elemento)` | Reemplaza en posición | `list.set(0, "B")` |

<CodeBlock lang="java" title="Agregar, eliminar y modificar">
{`import java.util.ArrayList;

public class ModificarLista {
    public static void main(String[] args) {
        ArrayList<String> colores = new ArrayList<>();
        colores.add("Rojo");
        colores.add("Verde");
        colores.add("Azul");
        System.out.println("Inicio: " + colores);

        // Agregar en posición específica
        colores.add(1, "Amarillo");
        System.out.println("Insertar: " + colores);

        // Modificar un elemento
        colores.set(2, "Naranja");
        System.out.println("Modificar: " + colores);

        // Eliminar por índice
        colores.remove(0);
        System.out.println("Eliminar primero: " + colores);

        // Eliminar por valor
        colores.remove("Azul");
        System.out.println("Eliminar Azul: " + colores);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Inicio: [Rojo, Verde, Azul]
Insertar: [Rojo, Amarillo, Verde, Azul]
Modificar: [Rojo, Amarillo, Naranja, Azul]
Eliminar primero: [Amarillo, Naranja, Azul]
Eliminar Azul: [Amarillo, Naranja]
```

## Acceder a elementos

```java
String elemento = list.get(0);    // Primer elemento
String ultimo = list.get(list.size() - 1);  // Último
```

<CodeBlock lang="java" title="Acceder y buscar en ArrayList">
{`import java.util.ArrayList;

public class BuscarArrayList {
    public static void main(String[] args) {
        ArrayList<String> lenguajes = new ArrayList<>();
        lenguajes.add("Java");
        lenguajes.add("Python");

}`}

Tercero: JavaScript
¿Contiene Java?: true

Último Java: 3

## Iterar sobre un ArrayList

<CodeBlock lang="java" title="Tres formas de recorrer un ArrayList">
{`import java.util.ArrayList;

public class IterarArrayList {
    public static void main(String[] args) {
        ArrayList<String> frutas = new ArrayList<>();
        frutas.add("Manzana");
        frutas.add("Pera");
        frutas.add("Uva");
        frutas.add("Naranja");

        // Forma 1: for clásico (con índice)
        System.out.println("--- for clásico ---");
        for (int i = 0; i < frutas.size(); i++) {
            System.out.println(i + ": " + frutas.get(i));
        }

        // Forma 2: for-each (sin índice)
        System.out.println("--- for-each ---");
        for (String fruta : frutas) {
            System.out.println(fruta);
        }

        // Forma 3: forEach con lambda (Java 8+)
        System.out.println("--- forEach lambda ---");
        frutas.forEach(f -> System.out.println(f));
    }
}`}
</CodeBlock>

## ArrayList y tipos primitivos

ArrayList no acepta primitivos directamente. Usa las **wrapper classes**:

| Primitivo | Wrapper | ArrayList |
|-----------|---------|-----------|
| `int` | `Integer` | `ArrayList<Integer>` |
| `double` | `Double` | `ArrayList<Double>` |
| `boolean` | `Boolean` | `ArrayList<Boolean>` |
| `char` | `Character` | `ArrayList<Character>` |

```java
ArrayList<Integer> numeros = new ArrayList<>();
numeros.add(10);     // Autoboxing: int → Integer
int valor = numeros.get(0);  // Unboxing: Integer → int
```

## Convertir entre arrays y ArrayList

<CodeBlock lang="java" title="Array ↔ ArrayList">
{`import java.util.ArrayList;
import java.util.Arrays;

public class ConvertirArrays {
    public static void main(String[] args) {
        // Array → ArrayList
        String[] arrayFrutas = {"Manzana", "Pera", "Uva"};
        ArrayList<String> listaFrutas = new ArrayList<>(
            Arrays.asList(arrayFrutas)
        );
        System.out.println("Lista: " + listaFrutas);

        // ArrayList → Array
        String[] nuevoArray = listaFrutas.toArray(new String[0]);
        System.out.println("Array: " + Arrays.toString(nuevoArray));

        // Usando var (Java 10+)
        var listaNumeros = new ArrayList<>(Arrays.asList(1, 2, 3));
        System.out.println("var: " + listaNumeros);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Lista: [Manzana, Pera, Uva]
Array: [Manzana, Pera, Uva]
var: [1, 2, 3]
```
