## ¿Qué es un Stream?

Un **Stream** es una secuencia de elementos que soporta operaciones funcionales encadenadas (pipeline). No es una estructura de datos: es una **vista** que permite procesar datos de forma declarativa.

```java
// En lugar de:
for (Producto p : productos) {
    if (p.precio > 100) {
        System.out.println(p);
    }
}

// Stream (más expresivo):
productos.stream()
    .filter(p -> p.precio > 100)
    .forEach(System.out::println);
```

## Pipeline de Streams

Un pipeline tiene tres partes:

1. **Fuente**: `coleccion.stream()` o `Stream.of(...)`
2. **Operaciones intermedias**: `filter`, `map`, `sorted` (retornan Stream)
3. **Operación terminal**: `forEach`, `collect`, `count` (producen resultado)

<CodeBlock lang="java" title="Pipeline completo de Stream">
{`import java.util.*;
import java.util.stream.*;

public class PipelineStream {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(5, 2, 8, 1, 9, 3, 7);

        List<String> resultado = nums.stream()           // fuente
            .filter(n -> n > 3)                          // intermedia
            .map(n -> "Número: " + n)                    // intermedia
            .sorted()                                    // intermedia
            .collect(Collectors.toList());               // terminal

        System.out.println(resultado);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
[Número: 5, Número: 7, Número: 8, Número: 9]
```

## Operaciones intermedias

<CodeBlock lang="java" title="Las operaciones intermedias más comunes">
{`import java.util.*;
import java.util.stream.*;

public class OpIntermedias {
    public static void main(String[] args) {
        List<String> nombres = Arrays.asList(
            "Ana", "Luis", "María", "Carlos", "Ana", "Pedro", "Luisa");

        // filter — filtrar elementos
        System.out.println("Más de 4 letras:");
        nombres.stream()
            .filter(n -> n.length() > 4)
            .forEach(System.out::println);

        // map — transformar elementos
        System.out.println("En mayúsculas:");
        nombres.stream()
            .map(String::toUpperCase)
            .forEach(System.out::println);

        // distinct — eliminar duplicados
        System.out.println("Sin duplicados:");
        nombres.stream()
            .distinct()
            .forEach(System.out::println);

        // sorted — ordenar
        System.out.println("Ordenados:");
        nombres.stream()
            .sorted()
            .forEach(System.out::println);
    }
}`}
</CodeBlock>

## Operaciones terminales

<CodeBlock lang="java" title="Operaciones terminales — producen el resultado final">
{`import java.util.*;
import java.util.stream.*;

public class OpTerminales {
    public static void main(String[] args) {
        List<Integer> numeros = Arrays.asList(10, 20, 30, 40, 50);

        // forEach — aplicar acción a cada elemento
        numeros.stream().forEach(n -> System.out.print(n + " "));
        System.out.println();

        // count — contar elementos
        long cantidad = numeros.stream()
            .filter(n -> n > 25)
            .count();
        System.out.println("> 25: " + cantidad);

        // collect — recolectar en una lista
        List<Integer> mayores = numeros.stream()
            .filter(n -> n > 25)
            .collect(Collectors.toList());
        System.out.println("Mayores: " + mayores);

        // toList — Java 16+
        List<Integer> menores = numeros.stream()
            .filter(n -> n < 30)
            .toList();
        System.out.println("Menores: " + menores);

        // findFirst — primer elemento (Optional)
        Optional<Integer> primero = numeros.stream()
            .filter(n -> n > 100)
            .findFirst();
        System.out.println("Primero > 100: " + primero.orElse(0));
    }
}`}
</CodeBlock>

## Collectors — agrupar y particionar

<CodeBlock lang="java" title="Agrupar y particionar con Collectors">
{`import java.util.*;
import java.util.stream.*;

public class CollectorsDemo {
    public static void main(String[] args) {
        List<String> palabras = Arrays.asList(
            "Java", "Python", "JavaScript", "C", "C++", "Go", "Rust");

        // groupingBy — agrupar por criterio
        Map<Integer, List<String>> porLongitud = palabras.stream()
            .collect(Collectors.groupingBy(String::length));

        System.out.println("Por longitud:");
        porLongitud.forEach((len, lista) ->
            System.out.printf("  %d: %s%n", len, lista));

        // partitioningBy — particionar en true/false
        Map<Boolean, List<String>> particion = palabras.stream()
            .collect(Collectors.partitioningBy(p -> p.length() > 4));

        System.out.println("Largas (>4): " + particion.get(true));
        System.out.println("Cortas (<=4): " + particion.get(false));

        // joining — unir strings
        String unidas = palabras.stream()
            .collect(Collectors.joining(", "));
        System.out.println("Unidas: " + unidas);
    }
}`}
</CodeBlock>

## Streams paralelos

```java
// Paralelizar con .parallelStream()
long total = lista.parallelStream()
    .filter(p -> p.precio > 100)
    .count();
```

**Importante:** Usa streams paralelos solo con colecciones grandes (>10,000 elementos) y operaciones sin efectos secundarios. El overhead de paralelización reduce el beneficio en colecciones pequeñas.
