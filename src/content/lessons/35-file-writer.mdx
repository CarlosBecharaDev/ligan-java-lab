## Escribir en un archivo

<CodeBlock lang="java" title="Escribir con FileWriter y PrintWriter">
{`import java.io.*;

public class EscribirArchivo {
    public static void main(String[] args) {
        try (PrintWriter pw = new PrintWriter(new FileWriter("salida.txt"))) {
            pw.println("Primera línea");
            pw.println("Segunda línea");
            pw.printf("Número: %d%n", 42);
            System.out.println("Archivo escrito exitosamente");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**PrintWriter** ofrece métodos familiares:
- `println(texto)` — escribe línea + salto de línea
- `printf(formato, args...)` — escribe formateado
- `print(texto)` — escribe sin salto de línea

## Modo Append (agregar al final)

<CodeBlock lang="java" title="Agregar al final con FileWriter(ruta, true)">
{`import java.io.*;

public class AppendArchivo {
    public static void main(String[] args) {
        // El segundo parámetro 'true' activa append
        try (FileWriter fw = new FileWriter("bitacora.txt", true);
             PrintWriter pw = new PrintWriter(fw)) {
            pw.println("Nueva entrada en la bitácora");
            System.out.println("Entrada agregada");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Escribir con Files.writeString() (Java 11+)

<CodeBlock lang="java" title="Escribir String directamente con NIO.2">
{`import java.nio.file.*;

public class WriteString {
    public static void main(String[] args) throws Exception {
        Path ruta = Path.of("nota.txt");

        // Escribir todo el texto
        Files.writeString(ruta, "Hola Mundo\\nJava NIO.2\\n");
        System.out.println("Escrito!");

        // Leerlo de vuelta
        String contenido = Files.readString(ruta);
        System.out.println("Contenido: " + contenido);
    }
}`}
</CodeBlock>

## Crear directorios y archivos

<CodeBlock lang="java" title="Crear estructura de directorios">
{`import java.nio.file.*;

public class CrearDirectorios {
    public static void main(String[] args) throws Exception {
        // Crear directorio (falla si ya existe)
        Path dir = Path.of("reportes/ventas");
        Files.createDirectories(dir);
        System.out.println("Directorio creado: " + dir);

        // Crear archivo
        Path archivo = dir.resolve("ventas.txt");
        Files.createFile(archivo);
        System.out.println("Archivo creado: " + archivo);

        // Crear y escribir en un solo paso
        Files.writeString(archivo, "Datos de ventas aquí");
        System.out.println("Datos escritos");

        // Verificar
        System.out.println("Existe: " + Files.exists(archivo));
        System.out.println("Tamaño: " + Files.size(archivo) + " bytes");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Directorio creado: reportes/ventas
Archivo creado: reportes/ventas/ventas.txt
Datos escritos
Existe: true
Tamaño: 18 bytes
```

## Escribir una lista de líneas

<CodeBlock lang="java" title="Escribir varias líneas con Files.write()">
{`import java.nio.file.*;
import java.util.List;

public class EscribirLista {
    public static void main(String[] args) throws Exception {
        List<String> lineas = List.of(
            "Nombre,Edad,Ciudad",
            "Ana,25,Bogotá",
            "Luis,30,Medellín"
        );

        Path archivo = Path.of("personas.csv");
        Files.write(archivo, lineas);
        System.out.println("CSV creado con " + lineas.size() + " líneas");

        // Leer de vuelta
        List<String> leidas = Files.readAllLines(archivo);
        for (String linea : leidas) {
            System.out.println("  " + linea);
        }
    }
}`}
</CodeBlock>
