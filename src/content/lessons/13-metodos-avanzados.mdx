## Composición de métodos

Un método puede **llamar a otros métodos**. Esto permite dividir un problema complejo en partes más pequeñas y manejables. Cada método hace una cosa específica y bien definida.

<CodeBlock lang="java" title="Métodos que llaman a otros métodos">
{`public class Composicion {
    static double calcularDescuento(double monto, double porcentaje) {
        return monto * porcentaje / 100;
    }

    static double calcularImpuesto(double base, double tasa) {
        return base * tasa / 100;
    }

    static double precioFinal(double monto, double desc, double imp) {
        double descuento = calcularDescuento(monto, desc);
        double base = monto - descuento;
        double impuesto = calcularImpuesto(base, imp);
        return base + impuesto;
    }

    public static void main(String[] args) {
        double total = precioFinal(50000, 15, 16);
        System.out.printf("Precio final: $%.2f%n", total);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Precio final: $45800.00
```

`precioFinal` llama a `calcularDescuento` y `calcularImpuesto`, que son métodos auxiliares que encapsulan cada cálculo por separado.

## Recursión

Un método puede **llamarse a sí mismo**. Esto se llama recursión y es una técnica poderosa para resolver problemas que tienen subproblemas del mismo tipo.

<CodeBlock lang="java" title="Recursión — factorial">
{`public class Factorial {
    static long factorial(int n) {
        if (n <= 1) return 1;          // caso base
        return n * factorial(n - 1);   // caso recursivo
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));
        System.out.println("10! = " + factorial(10));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
5! = 120
10! = 3628800
```

La recursión tiene **dos partes esenciales**:

```
factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * factorial(2)
= 5 * 4 * 3 * 2 * factorial(1)
= 5 * 4 * 3 * 2 * 1
= 120
```

**Sin un caso base**, la recursión sería infinita y causaría `StackOverflowError`.

## Fibonacci recursivo

<CodeBlock lang="java" title="Recursión — Fibonacci">
{`public class Fibonacci {
    static int fibonacci(int n) {
        if (n <= 0) return 0;
        if (n == 1) return 1;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 10; i++) {
            System.out.printf("fib(%d) = %d%n", i, fibonacci(i));
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
fib(0) = 0
fib(1) = 1
fib(2) = 1
fib(3) = 2
fib(4) = 3
fib(5) = 5
fib(6) = 8
fib(7) = 13
fib(8) = 21
fib(9) = 34
fib(10) = 55
```

**Nota:** Para valores grandes de `n`, esta versión recursiva es lenta porque recalcula los mismos valores muchas veces. La versión iterativa es más eficiente para este caso específico.

## Recursión en arreglos

La recursión es natural para procesar arreglos, especialmente cuando se busca un patrón que se repite:

<CodeBlock lang="java" title="Recursión — suma de elementos">
{`public class SumaArreglo {
    static int suma(int[] arr, int indice) {
        if (indice >= arr.length) return 0;  // caso base
        return arr[indice] + suma(arr, indice + 1);
    }

    public static void main(String[] args) {
        int[] numeros = {3, 7, 2, 9, 5};
        System.out.println("Suma: " + suma(numeros, 0));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Suma: 26
```

## Varargs — argumentos variables

Java permite recibir un **número indeterminado de argumentos** del mismo tipo con la sintaxis `Tipo... args`:

<CodeBlock lang="java" title="Varargs — sumar cualquier cantidad de números">
{`public class Varargs {
    static double sumar(double... numeros) {
        double total = 0;
        for (double n : numeros) {
            total += n;
        }
        return total;
    }

    static void imprimir(String separador, String... palabras) {
        for (int i = 0; i < palabras.length; i++) {
            System.out.print(palabras[i]);
            if (i < palabras.length - 1) {
                System.out.print(separador);
            }
        }
        System.out.println();
    }

    public static void main(String[] args) {
        System.out.println("Suma: " + sumar(1, 2, 3));
        System.out.println("Suma: " + sumar(10, 20, 30, 40));
        imprimir(", ", "Java", "Python", "C++");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Suma: 6.0
Suma: 100.0
Java, Python, C++
```

Internamente, `double... numeros` es un `double[]`. Puedes pasarlo como un array normal o como argumentos separados.

## Documentación Javadoc

Los métodos se documentan con comentarios Javadoc que describen qué hacen, sus parámetros y lo que retornan:

```java
/**
 * Calcula el promedio de un array de doubles.
 * @param notas Array con las calificaciones
 * @return El promedio de todas las notas
 * @throws IllegalArgumentException si el array está vacío
 */
static double promedio(double[] notas) {
    if (notas.length == 0) {
        throw new IllegalArgumentException("Array vacío");
    }
    double suma = 0;
    for (double n : notas) suma += n;
    return suma / notas.length;
}
```
