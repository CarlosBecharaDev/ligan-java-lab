## ¿Qué es Java?

Java es un **lenguaje de programación orientado a objetos**, compilado a un código intermedio llamado *bytecode*. Fue creado por James Gosling en Sun Microsystems y lanzado en 1996. Su lema "**Write Once, Run Anywhere**" (WORA) significa que el mismo programa corre en Windows, Linux o macOS sin modificaciones.

Java es uno de los lenguajes más utilizados en el mundo empresarial: sistemas bancarios, aplicaciones Android, big data, microservicios con Spring Boot, y más.

## El ecosistema Java: JDK, JRE y JVM

Para programar en Java necesitas tres componentes anidados:

```
┌────────────────────────────────────────────┐
│                   JDK                        │
│  (Lo necesitas para DESARROLLAR)              │
│  ┌────────────────────────────────────────┐ │
│  │               JRE                        │ │
│  │  (Lo necesitas para EJECUTAR)            │ │
│  │  ┌──────────────────────────────────┐   │ │
│  │  │              JVM                   │   │ │
│  │  │  (Interpreta y ejecuta bytecode)   │   │ │
│  │  └──────────────────────────────────┘   │ │
│  │  + Librerías estándar de Java            │ │
│  └────────────────────────────────────────┘ │
│  + javac, debugger, herramientas de dev      │
└────────────────────────────────────────────┘
```

### JDK — Java Development Kit

Es el kit completo para DESARROLLAR en Java. Incluye:

- **`javac`**: el compilador que convierte `.java` a `.class` (bytecode)
- **JRE**: el entorno de ejecución
- **Debugger**: para depurar código paso a paso
- **Herramientas**: `javadoc`, `jar`, `jlink`, etc.

Lo instala un desarrollador en su máquina.

### JRE — Java Runtime Environment

Es el entorno para EJECUTAR programas Java ya compilados. Incluye:

- **JVM**: la máquina virtual
- **Librerías estándar**: `java.lang`, `java.util`, `java.io`, etc.

Lo instala un usuario final que solo quiere ejecutar aplicaciones Java.

### JVM — Java Virtual Machine

Es el corazón de Java: interpreta y ejecuta el bytecode. Es específica para cada sistema operativo. La JVM es lo que hace posible WORA: el mismo `.class` funciona en cualquier SO que tenga su propia JVM.

## El proceso de compilación y ejecución

```
┌─────────────────────┐      javac       ┌──────────────────┐      JVM       ┌──────────────────┐
│  HolaMundo.java      │ ───────────────► │  HolaMundo.class  │ ─────────────► │  Salida en consola │
│ (código fuente)      │   (compilador)   │   (bytecode)       │  (intérprete)  │                    │
└─────────────────────┘                  └──────────────────┘                └──────────────────┘
```

1. **Escribes** el código en un archivo `.java`
2. **`javac`** compila a bytecode en un archivo `.class`
3. **La JVM** interpreta ese bytecode y lo ejecuta

El bytecode NO es código máquina nativo. Es un formato intermedio que la JVM interpreta. Por eso el mismo `.class` funciona en cualquier sistema operativo que tenga JVM.

## Tu primer programa: Hola Mundo

<CodeBlock lang="java" title="HolaMundo.java">
{`public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("¡Hola Mundo con Java!");
    }
}`}
</CodeBlock>

### Analizando línea por línea

| Línea | Explicación |
|-------|------------|
| `public class HolaMundo` | Declara una clase pública. El nombre debe coincidir EXACTAMENTE con el nombre del archivo: `HolaMundo.java` |
| `public static void main(String[] args)` | Método de entrada. La JVM busca esta firma exacta para empezar a ejecutar |
| `System.out.println(...)` | Imprime texto en consola seguido de un salto de línea |
| `;` | Cada sentencia termina con punto y coma (obligatorio) |

### Desglose de `public static void main(String[] args)`

| Palabra | Significado |
|---------|------------|
| `public` | Accesible desde fuera de la clase (la JVM necesita llamarlo) |
| `static` | No requiere crear un objeto para ejecutarse |
| `void` | No retorna ningún valor |
| `main` | Nombre del método — debe ser exactamente `main` en minúscula |
| `String[] args` | Parámetro que recibe argumentos de línea de comandos |

### Compilar y ejecutar paso a paso

```bash
# 1. Compilar: genera HolaMundo.class
javac HolaMundo.java

# 2. Ejecutar: la JVM interpreta el bytecode
java HolaMundo
```

**Salida esperada:**
```
¡Hola Mundo con Java!
```

## Convenciones de nombrado

| Elemento | Convención | Ejemplo |
|----------|-----------|---------|
| Clase | **PascalCase** | `MiPrimerPrograma` |
| Método | **camelCase** | `calcularPromedio()` |
| Variable | **camelCase** | `nombreUsuario` |
| Constante | **MAYÚSCULAS** | `MAX_INTENTOS` |
| Paquete | **minúsculas** | `com.miempresa.app` |
| Archivo `.java` | = clase pública | `MiClase.java` |

## Estructura de un proyecto real

```
mi-proyecto/
├── src/
│   └── main/
│       └── java/
│           └── com/empresa/app/
│               ├── Main.java
│               ├── modelo/
│               └── servicios/
├── pom.xml (o build.gradle)
└── README.md
```

En proyectos profesionales el código se organiza en **paquetes** (carpetas que reflejan el dominio del negocio) y se gestiona con herramientas de build como Maven o Gradle.

## Errores frecuentes

### Error 1: Nombre de archivo no coincide con la clase
```java
// Archivo: holamundo.java
public class HolaMundo {  // ❌ Error de compilación
}
// ✅ Archivo debe llamarse HolaMundo.java (exactamente igual)
```

### Error 2: `main` mal escrito
```java
public static void Main(String[] args) {  // ❌ Error: debe ser main (minúscula)
public static void main(String[] args) {   // ✅ Correcto
}
```

### Error 3: Olvidar el punto y coma
```java
System.out.println("Hola")  // ❌ Error de compilación: falta ;
System.out.println("Hola"); // ✅ Correcto
```

### Error 4: Confundir JDK con JRE
```bash
# Intentar compilar con solo JRE
java HolaMundo.java    # ❌ java ejecuta .class, no compila
javac HolaMundo.java   # ✅ javac compila (solo en JDK)
```

## Cómo instalar el JDK

1. Ve a [adoptium.net](https://adoptium.net) y descarga **JDK 21 LTS** para tu sistema operativo
2. Ejecuta el instalador (siguiente, siguiente, finalizar)
3. Verifica la instalación:
   ```bash
   java -version
   javac -version
   ```
4. Opcional: instala **IntelliJ IDEA Community** o **VS Code** con las extensiones de Java

## Buenas prácticas

1. **PascalCase para clases**: `MiClase`, no `miclase` ni `mi_clase`
2. **Un archivo `.java` por clase pública** con el mismo nombre
3. **Usa versiones LTS del JDK** (21 es la más reciente)
4. **Aprende a usar un IDE** desde el inicio: autocompletado, refactorización y depuración aceleran el aprendizaje
