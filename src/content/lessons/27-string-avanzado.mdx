## Inmutabilidad de String

En Java, **String es inmutable**: una vez creado, no puede modificarse. Cada operación crea un **nuevo** String.

```java
String s = "Hola";
s.toUpperCase();   // retorna "HOLA" pero NO modifica s
System.out.println(s);  // imprime "Hola"

String s2 = s.toUpperCase();  // s2 es nuevo, s sigue igual
```

**Consecuencia:** Las concatenaciones frecuentes en bucles crean muchos objetos temporales. Para eso existe StringBuilder.

## Extraer subcadenas

<CodeBlock lang="java" title="substring y métodos de extracción">
{`public class Substring {
    public static void main(String[] args) {
        String fecha = "2026-07-27";

        // substring(inicio, fin) — fin excluido
        String anio = fecha.substring(0, 4);
        String mes = fecha.substring(5, 7);
        String dia = fecha.substring(8, 10);

        System.out.println("Año: " + anio);
        System.out.println("Mes: " + mes);
        System.out.println("Día: " + dia);

        // substring(inicio) — hasta el final
        String desdeJulio = fecha.substring(5);
        System.out.println("Desde julio: " + desdeJulio);

        // charAt — obtener carácter en posición
        System.out.println("Primer carácter: " + fecha.charAt(0));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Año: 2026
Mes: 07
Día: 27
Desde julio: 07-27
Primer carácter: 2
```

## Buscar en un String

<CodeBlock lang="java" title="Métodos de búsqueda">
{`public class BuscarString {
    public static void main(String[] args) {
        String email = "usuario@ejemplo.com";

        // indexOf — posición de subcadena
        int arroba = email.indexOf("@");
        System.out.println("@ en posición: " + arroba);

        // lastIndexOf — última aparición
        int ultimo = email.lastIndexOf(".");
        System.out.println("Último . en posición: " + ultimo);

        // startsWith y endsWith
        System.out.println("Empieza con 'user': " + email.startsWith("user"));
        System.out.println("Termina con '.com': " + email.endsWith(".com"));

        // contains
        System.out.println("Contiene '@': " + email.contains("@"));

        // Comparación ignorando mayúsculas
        String nombre = "Carlos";
        System.out.println("igual 'carlos'?: " + nombre.equalsIgnoreCase("carlos"));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
@ en posición: 7
Último . en posición: 13
Empieza con 'user': true
Termina con '.com': true
Contiene '@': true
igual 'carlos'?: true
```

## Reemplazar, recortar y dividir

<CodeBlock lang="java" title="replace, trim/strip, split">
{`public class ManipularString {
    public static void main(String[] args) {
        // replace
        String msg = "Hola Mundo Java";
        System.out.println(msg.replace("Java", "Mundo"));
        System.out.println(msg.replaceAll("o", "0"));

        // trim (Java 1.0) y strip (Java 11+)
        String conEspacios = "   Hola   ";
        System.out.println("[" + conEspacios.trim() + "]");
        System.out.println("[" + conEspacios.strip() + "]");

        // split
        String csv = "manzana,pera,uva,naranja";
        String[] frutas = csv.split(",");
        for (String f : frutas) {
            System.out.println("  - " + f);
        }

        // join
        String unido = String.join(" | ", frutas);
        System.out.println("Unido: " + unido);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Hola Mundo Mundo
H0la Mund0 Java
[   Hola   ]
[Hola]
  - manzana
  - pera
  - uva
  - naranja
Unido: manzana | pera | uva | naranja
```

## Formatear strings

<CodeBlock lang="java" title="String.format y printf">
{`public class Formatear {
    public static void main(String[] args) {
        String nombre = "Ana";
        double nota = 9.25;
        int edad = 22;

        // String.format — retorna un nuevo String
        String perfil = String.format(
            "%s tiene %d años y nota %.1f",
            nombre, edad, nota
        );
        System.out.println(perfil);

        // Formatos comunes
        System.out.printf("Hexadecimal: %x%n", 255);
        System.out.printf("Octal: %o%n", 255);
        System.out.printf("Notación científica: %e%n", 123456.789);
        System.out.printf("Con ceros: %05d%n", 42);

        // Alineación
        System.out.printf("%-10s | %5d%n", "Java", 30);
        System.out.printf("%-10s | %5d%n", "Python", 25);
        System.out.printf("%-10s | %5d%n", "JavaScript", 20);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Ana tiene 22 años y nota 9.3
Hexadecimal: ff
Octal: 377
Notación científica: 1.234568e+05
Con ceros: 00042
Java       |    30
Python     |    25
JavaScript |    20
```

## StringBuilder — para construir strings eficientemente

<CodeBlock lang="java" title="Construir texto con StringBuilder">
{`public class BuilderString {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();

        // append — agregar texto
        sb.append("Línea 1\\n");
        sb.append("Línea 2\\n");
        sb.append("Línea 3\\n");

        String resultado = sb.toString();
        System.out.println(resultado);

        // Construir CSV
        StringBuilder csv = new StringBuilder();
        String[] datos = {"Ana", "25", "Bogotá"};
        for (int i = 0; i < datos.length; i++) {
            csv.append(datos[i]);
            if (i < datos.length - 1) csv.append(", ");
        }
        System.out.println("CSV: " + csv.toString());

        // insert, delete, reverse
        StringBuilder sb2 = new StringBuilder("Hola");
        sb2.insert(4, " Mundo");
        System.out.println("Insert: " + sb2);

        sb2.delete(4, 10);
        System.out.println("Delete: " + sb2);

        sb2.reverse();
        System.out.println("Reverse: " + sb2);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Línea 1
Línea 2
Línea 3

CSV: Ana, 25, Bogotá
Insert: Hola Mundo
Delete: Hola
Reverse: aloH
```
