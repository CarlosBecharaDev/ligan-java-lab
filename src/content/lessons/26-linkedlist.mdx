## ¿Qué es un LinkedList?

Un **LinkedList** es una lista doblemente enlazada: cada elemento (nodo) contiene el dato y referencias al nodo anterior y siguiente. A diferencia de ArrayList (basado en array), LinkedList permite inserciones y eliminaciones eficientes en cualquier posición.

```java
import java.util.LinkedList;

LinkedList<String> lista = new LinkedList<>();
lista.add("Primero");
lista.add("Segundo");
lista.add("Tercero");
```

## Crear y usar un LinkedList

<CodeBlock lang="java" title="Crear LinkedList y operaciones básicas">
{`import java.util.LinkedList;

public class CrearLinkedList {
    public static void main(String[] args) {
        LinkedList<String> ciudades = new LinkedList<>();

        // Agregar elementos
        ciudades.add("Bogotá");
        ciudades.add("Medellín");
        ciudades.add("Cali");
        System.out.println("Lista: " + ciudades);

        // Agregar al inicio y final
        ciudades.addFirst("Barranquilla");
        ciudades.addLast("Cartagena");
        System.out.println("Con extremos: " + ciudades);

        // Acceder
        System.out.println("Primero: " + ciudades.getFirst());
        System.out.println("Último: " + ciudades.getLast());
        System.out.println("Índice 2: " + ciudades.get(2));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Lista: [Bogotá, Medellín, Cali]
Con extremos: [Barranquilla, Bogotá, Medellín, Cali, Cartagena]
Primero: Barranquilla
Último: Cartagena
Índice 2: Medellín
```

## Métodos de extremos

| Método | Descripción | Excepción si vacía |
|--------|-------------|-------------------|
| `addFirst(e)` / `addLast(e)` | Agrega al inicio/final | No lanza excepción |
| `getFirst()` / `getLast()` | Obtiene sin eliminar | `NoSuchElementException` |
| `removeFirst()` / `removeLast()` | Obtiene y elimina | `NoSuchElementException` |
| `peekFirst()` / `peekLast()` | Obtiene sin eliminar | `null` si vacío |
| `pollFirst()` / `pollLast()` | Obtiene y elimina | `null` si vacío |

## LinkedList como cola (Queue)

<CodeBlock lang="java" title="Cola FIFO con LinkedList">
{`import java.util.LinkedList;

public class ColaFIFO {
    public static void main(String[] args) {
        LinkedList<String> cola = new LinkedList<>();

        // Encolar (agregar al final)
        cola.offer("Cliente 1");
        cola.offer("Cliente 2");
        cola.offer("Cliente 3");
        System.out.println("Cola: " + cola);

        // Desencolar (sacar del frente)
        while (!cola.isEmpty()) {
            String cliente = cola.poll();
            System.out.println("Atendiendo: " + cliente);
        }
        System.out.println("Cola vacía: " + cola.isEmpty());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Cola: [Cliente 1, Cliente 2, Cliente 3]
Atendiendo: Cliente 1
Atendiendo: Cliente 2
Atendiendo: Cliente 3
Cola vacía: true
```

## LinkedList como pila (Stack)

<CodeBlock lang="java" title="Pila LIFO con LinkedList">
{`import java.util.LinkedList;

public class PilaLIFO {
    public static void main(String[] args) {
        LinkedList<String> pila = new LinkedList<>();

        // Push (agregar al frente)
        pila.push("Primero");
        pila.push("Segundo");
        pila.push("Tercero");
        System.out.println("Pila: " + pila);

        // Pop (sacar del frente)
        while (!pila.isEmpty()) {
            System.out.println("Desapilando: " + pila.pop());
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Pila: [Tercero, Segundo, Primero]
Desapilando: Tercero
Desapilando: Segundo
Desapilando: Primero
```

## Iterar sobre un LinkedList

```java
LinkedList<String> lista = new LinkedList<>();
// ... agregar elementos

// for clásico (lento en LinkedList)
for (int i = 0; i < lista.size(); i++) {
    System.out.println(lista.get(i));  // O(n) por cada get
}

// for-each (recomendado)
for (String elemento : lista) {
    System.out.println(elemento);  // O(1) por iterador
}
```

**Importante:** En LinkedList, usar `get(i)` en un bucle for es O(n²) porque cada acceso recorre la lista desde el inicio. Usa for-each o Iterator para recorrer LinkedList eficientemente.
