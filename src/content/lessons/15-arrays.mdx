## ¿Qué es un arreglo?

Un arreglo (array) es una **colección de elementos del mismo tipo** con un tamaño fijo. Cada elemento se accede mediante un **índice** que comienza en 0.

```
int[] numeros = {10, 20, 30, 40, 50};

Índice:   [0]  [1]  [2]  [3]  [4]
Valor:     10   20   30   40   50
```

## Declarar e inicializar arreglos

Hay varias formas de crear arreglos en Java:

<CodeBlock lang="java" title="Formas de declarar arreglos">
{`public class DeclararArrays {
    public static void main(String[] args) {
        // Forma 1: con valores iniciales
        int[] edades = {25, 30, 22, 35, 28};

        // Forma 2: tamaño fijo, valores por defecto (0)
        double[] notas = new double[5];

        // Forma 3: tamaño y llenado manual
        String[] frutas = new String[3];
        frutas[0] = "Manzana";
        frutas[1] = "Pera";
        frutas[2] = "Uva";

        // Forma 4: tamaño variable
        int tamanio = 10;
        int[] datos = new int[tamanio];

        System.out.println("Edades: " + edades.length);
        System.out.println("Frutas: " + frutas[0]);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Edades: 5
Frutas: Manzana
```

## Acceder a elementos

Se usa el **índice** entre corchetes `[]` para leer o modificar elementos:

<CodeBlock lang="java" title="Acceder y modificar elementos">
{`public class AccederArrays {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50};

        System.out.println("Primero: " + nums[0]);   // 10
        System.out.println("Tercero: " + nums[2]);   // 30
        System.out.println("Último: " + nums[nums.length - 1]); // 50

        // Modificar un elemento
        nums[1] = 25;
        System.out.println("Modificado: " + nums[1]); // 25

        // El tamaño es fijo
        System.out.println("Tamaño: " + nums.length); // 5
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Primero: 10
Tercero: 30
Último: 50
Modificado: 25
Tamaño: 5
```

**Importante:** `.length` NO lleva paréntesis — es una propiedad, no un método.

## Recorrer con for

<CodeBlock lang="java" title="For clásico — recorrer por índice">
{`public class ForClasico {
    public static void main(String[] args) {
        String[] colores = {"Rojo", "Verde", "Azul", "Amarillo"};

        for (int i = 0; i < colores.length; i++) {
            System.out.println("[" + i + "] " + colores[i]);
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
[0] Rojo
[1] Verde
[2] Azul
[3] Amarillo
```

## Recorrer con for-each

<CodeBlock lang="java" title="For-each — recorrer valores directamente">
{`public class ForEachArray {
    public static void main(String[] args) {
        int[] calificaciones = {85, 92, 78, 95, 88};
        int suma = 0;

        for (int nota : calificaciones) {
            suma += nota;
        }

        double promedio = (double) suma / calificaciones.length;
        System.out.println("Promedio: " + promedio);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Promedio: 87.6
```

El for-each es más legible cuando **no necesitas el índice**. Si necesitas modificar el array o conocer la posición, usa el for clásico.

## Valores por defecto

Cuando creas un array con `new`, sus elementos se inicializan automáticamente:

| Tipo | Valor por defecto |
|------|-------------------|
| `int`, `long`, `short`, `byte` | `0` |
| `float`, `double` | `0.0` |
| `boolean` | `false` |
| `char` | `' '` |
| `String` (u objetos) | `null` |

## Arrays y métodos

Los arrays se pueden pasar como parámetros a métodos:

<CodeBlock lang="java" title="Método que procesa un array">
{`public class MetodoArray {
    static void imprimirArray(int[] arr) {
        System.out.print("[");
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i]);
            if (i < arr.length - 1) System.out.print(", ");
        }
        System.out.println("]");
    }

    static int sumar(int[] arr) {
        int total = 0;
        for (int n : arr) total += n;
        return total;
    }

    public static void main(String[] args) {
        int[] numeros = {5, 10, 15, 20};
        imprimirArray(numeros);
        System.out.println("Suma: " + sumar(numeros));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
[5, 10, 15, 20]
Suma: 50
```
