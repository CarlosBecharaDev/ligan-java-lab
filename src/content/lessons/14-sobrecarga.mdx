## ¿Qué es la sobrecarga?

La sobrecarga (overloading) permite tener **varios métodos con el mismo nombre** pero diferentes parámetros. El compilador elige cuál ejecutar según los argumentos que pases.

<CodeBlock lang="java" title="Métodos sobrecargados — sumar distintos tipos">
{`public class SumaSobrecargada {
    static int sumar(int a, int b) {
        return a + b;
    }

    static double sumar(double a, double b) {
        return a + b;
    }

    static int sumar(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println("enteros: " + sumar(3, 5));
        System.out.println("decimales: " + sumar(2.5, 3.7));
        System.out.println("tres: " + sumar(1, 2, 3));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
enteros: 8
decimales: 6.2
tres: 6
```

Todos los métodos se llaman `sumar`, pero el compilador elige el correcto según los tipos y cantidad de argumentos.

## Reglas de la sobrecarga

Para que dos métodos sean sobrecargados, **deben diferir en los parámetros**:

```
✅ Diferente cantidad de parámetros:
   sumar(int, int) vs sumar(int, int, int)

✅ Diferente tipo de parámetros:
   sumar(int, int) vs sumar(double, double)

✅ Ambos:
   sumar(int) vs sumar(int, double)

❌ NO es sobrecarga — mismo nombre y mismos parámetros:
   int sumar(int a, int b)
   double sumar(int a, int b)  // ERROR: solo cambia el retorno
```

La clave: **el tipo de retorno NO cuenta** para la sobrecarga. Dos métodos con el mismo nombre, mismos parámetros y distinto retorno dan error de compilación.

## El compilador resuelve la ambigüedad

Cuando llamas un método sobrecargado, el compilador busca la versión cuyos parámetros coinciden mejor:

<CodeBlock lang="java" title="Resolución de sobrecarga">
{`public class Resolucion {
    static void mostrar(String texto) {
        System.out.println("String: " + texto);
    }

    static void mostrar(int numero) {
        System.out.println("int: " + numero);
    }

    static void mostrar(double valor) {
        System.out.println("double: " + valor);
    }

    public static void main(String[] args) {
        mostrar("Hola");     // llama a mostrar(String)
        mostrar(42);         // llama a mostrar(int)
        mostrar(3.14);       // llama a mostrar(double)
        mostrar('A');        // llama a mostrar(int) — char se promueve a int
    }
}`}
</CodeBlock>

**Salida esperada:**
```
String: Hola
int: 42
double: 3.14
int: 65
```

**Nota:** `char` se convierte implícitamente a `int` (promoción), por lo que `mostrar('A')` llama a `mostrar(int)`, no a `mostrar(String)`.

## Sobrecarga con tipos compatibles

La jerarquía de conversión de tipos afecta qué versión se elige:

```
byte → short → int → long → float → double
         char ↗
```

El compilador elige la conversión **más pequeña** posible:

<CodeBlock lang="java" title="Promoción de tipos en sobrecarga">
{`public class Promocion {
    static void procesar(int n) {
        System.out.println("int: " + n);
    }

    static void procesar(double d) {
        System.out.println("double: " + d);
    }

    public static void main(String[] args) {
        byte b = 10;
        procesar(b);    // int — byte se promueve a int

        float f = 5.5f;
        procesar(f);    // double — float se promueve a double

        short s = 20;
        procesar(s);    // int — short se promueve a int
    }
}`}
</CodeBlock>

**Salida esperada:**
```
int: 10
double: 5.5
int: 20
```

## Sobrecarga útil en la práctica

Un patrón común es ofrecer una versión simple y otra completa:

<CodeBlock lang="java" title="Sobrecarga práctica — formatear texto">
{`public class Formatear {
    static String formatear(String texto) {
        return texto.trim().toUpperCase();
    }

    static String formatear(String texto, int longitud) {
        String resultado = texto.trim().toUpperCase();
        if (resultado.length() > longitud) {
            return resultado.substring(0, longitud) + "...";
        }
        return resultado;
    }

    static String formatear(String texto, int longitud,
            char relleno) {
        String resultado = texto.trim().toUpperCase();
        while (resultado.length() < longitud) {
            resultado = relleno + resultado + relleno;
        }
        return resultado;
    }

    public static void main(String[] args) {
        System.out.println(formatear("  hola mundo  "));
        System.out.println(formatear("  hola mundo  ", 8));
        System.out.println(formatear("  hola  ", 12, '*'));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
HOLA MUNDO
HOLA MU...
***HOLA*****
```

Las tres versiones de `formatear` hacen cosas similares pero con diferentes niveles de personalización.
