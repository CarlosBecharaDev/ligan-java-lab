## La jerarquía de excepciones

```
Throwable (la raíz de todo)
├── Error (problemas graves del JVM — no manejar)
│   ├── OutOfMemoryError
│   ├── StackOverflowError
│   └── ...
└── Exception (errores que tu código puede manejar)
    ├── RuntimeException (UNCHECKED)
    │   ├── NullPointerException
    │   ├── IllegalArgumentException
    │   ├── ArrayIndexOutOfBoundsException
    │   └── ...
    └── Checked Exceptions (verificadas por el compilador)
        ├── IOException
        ├── FileNotFoundException
        ├── SQLException
        └── ...
```

## Excepciones Unchecked (RuntimeException)

Son errores de **programación** (bugs). El compilador no obliga a manejarlas.

<CodeBlock lang="java" title="RuntimeException más comunes">
{`public class TiposRuntimeException {
    public static void main(String[] args) {
        // 1. NullPointerException
        try {
            String texto = null;
            texto.length();
        } catch (NullPointerException e) {
            System.out.println("NullPointerException: " + e.getMessage());
        }

        // 2. ArrayIndexOutOfBoundsException
        try {
            int[] nums = {1, 2, 3};
            int valor = nums[10];
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("ArrayIndexOutOfBounds: " + e.getMessage());
        }

        // 3. NumberFormatException
        try {
            int num = Integer.parseInt("abc");
        } catch (NumberFormatException e) {
            System.out.println("NumberFormatException: " + e.getMessage());
        }

        // 4. IllegalArgumentException
        try {
            setEdad(-5);
        } catch (IllegalArgumentException e) {
            System.out.println("IllegalArgumentException: " + e.getMessage());
        }
    }

    static void setEdad(int edad) {
        if (edad < 0 || edad > 150) {
            throw new IllegalArgumentException("Edad inválida: " + edad);
        }
        System.out.println("Edad establecida: " + edad);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
NullPointerException: null
ArrayIndexOutOfBounds: Index 10 out of bounds for length 3
NumberFormatException: For input string: "abc"
IllegalArgumentException: Edad inválida: -5
```

## Excepciones Checked

El compilador **obliga** a manejarlas con `try-catch` o declararlas con `throws`.

<CodeBlock lang="java" title="Checked exception —FileNotFoundException">
{`import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class CheckedDemo {
    static void leerArchivo(String ruta) throws FileNotFoundException {
        // FileNotFoundException es checked — debemos declarar throws
        Scanner sc = new Scanner(new File(ruta));
        while (sc.hasNextLine()) {
            System.out.println(sc.nextLine());
        }
        sc.close();
    }

    public static void main(String[] args) {
        try {
            leerArchivo("datos.txt");
        } catch (FileNotFoundException e) {
            System.out.println("No se pudo leer: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
No se pudo leer: datos.txt (El sistema no puede encontrar el archivo especificado)
```

## Leer un stack trace

Cuando ocurre una excepción, el stack trace te dice **dónde** y **cómo** ocurrió:

```
java.lang.ArithmeticException: / by zero
    at Calculator.dividir(Calculator.java:15)      ← dónde ocurrió
    at Calculator.main(Calculator.java:8)            ← quién lo llamó
```

**Leer de abajo hacia arriba:** `main` llama a `dividir`, y ahí ocurre la división por cero.

## Las excepciones más importantes

| Excepción | Tipo | Causa común |
|-----------|------|-------------|
| `NullPointerException` | Unchecked | Usar un objeto null como si tuviera valor |
| `ArrayIndexOutOfBoundsException` | Unchecked | Acceder a un índice fuera de rango |
| `NumberFormatException` | Unchecked | Convertir texto inválido a número |
| `IllegalArgumentException` | Unchecked | Parámetro con valor inaceptable |
| `FileNotFoundException` | Checked | Archivo no encontrado en disco |
| `IOException` | Checked | Error de entrada/salida general |
| `ClassNotFoundException` | Checked | Clase no encontrada en classpath |
