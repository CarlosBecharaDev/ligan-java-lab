## ¿Qué es una sentencia de decisión?

Las sentencias de decisión permiten que un programa **tome caminos diferentes** según condiciones específicas. Son la base de la lógica en cualquier lenguaje de programación.

En Java, la sentencia de decisión fundamental es `if`:

```java
if (condicion) {
    // bloque que se ejecuta si condicion es true
}
```

## La sentencia if

El `if` ejecuta un bloque de código **solo si** la condición es `true`:

<CodeBlock lang="java" title="Sentencia if básica">
{`public class IfBasico {
    public static void main(String[] args) {
        int edad = 20;

        if (edad >= 18) {
            System.out.println("Eres mayor de edad");
        }

        System.out.println("Esta línea siempre se ejecuta");

        // if con una sola línea (sin llaves, no recomendado)
        if (edad >= 18) System.out.println("Mayor de edad");

        // Siempre usa llaves para evitar errores
        if (edad >= 18) {
            System.out.println("Mayor de edad");
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Eres mayor de edad
Esta línea siempre se ejecuta
Mayor de edad
Mayor de edad
```

## If-else: dos caminos

El `else` ejecuta un bloque cuando la condición es `false`:

```java
if (condicion) {
    // cuando es true
} else {
    // cuando es false
}
```

<CodeBlock lang="java" title="If-else">
{`public class IfElse {
    public static void main(String[] args) {
        int temperatura = 5;

        if (temperatura > 25) {
            System.out.println("Hace calor 🥵");
        } else {
            System.out.println("Hace frío 🥶");
        }

        System.out.println("Dentro o fuera, el programa continúa");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Hace frío 🥶
Dentro o fuera, el programa continúa
```

## Else-if: múltiples condiciones

Cuando tienes más de dos caminos, encadena `else if`:

<CodeBlock lang="java" title="Else-if">
{`public class ElseIf {
    public static void main(String[] args) {
        int nota = 85;

        if (nota >= 90) {
            System.out.println("Excelente 🏆");
        } else if (nota >= 80) {
            System.out.println("Muy bien 👍");
        } else if (nota >= 70) {
            System.out.println("Bien 👌");
        } else if (nota >= 60) {
            System.out.println("Suficiente 📖");
        } else {
            System.out.println("Reprobado ❌");
        }

        System.out.println("Nota final: " + nota);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Muy bien 👍
Nota final: 85
```

## Condiciones booleanas complejas

Puedes combinar múltiples condiciones con operadores lógicos:

<CodeBlock lang="java" title="Condiciones compuestas">
{`public class CondicionesCompuestas {
    public static void main(String[] args) {
        int edad = 25;
        boolean tieneLicencia = true;
        boolean tieneMultas = false;

        // AND: ambas deben cumplirse
        if (edad >= 18 && tieneLicencia) {
            System.out.println("Puede conducir legalmente");
        }

        // OR: al menos una debe cumplirse
        if (edad < 12 || tieneMultas) {
            System.out.println("Tiene restricciones");
        }

        // NOT + AND: combinación
        if (edad >= 18 && !tieneMultas) {
            System.out.println("No tiene multas y es mayor");
        }

        // Condición compuesta compleja
        if ((edad >= 18 && tieneLicencia) && !tieneMultas) {
            System.out.println("✅ Conductor sin restricciones");
        } else {
            System.out.println("⚠️ No puede conducir");
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Puede conducir legalmente
No tiene multas y es mayor
✅ Conductor sin restricciones
```

## If-else vs operador ternario

El operador ternario es una versión compacta de `if-else` para asignaciones:

```java
// if-else tradicional
String mensaje;
if (edad >= 18) {
    mensaje = "Mayor de edad";
} else {
    mensaje = "Menor de edad";
}

// Ternario equivalente (una línea)
String mensaje = (edad >= 18) ? "Mayor de edad" : "Menor de edad";
```

## Errores frecuentes

### Error 1: Usar `=` en vez de `==`
```java
// ❌ Asigna 5 a x, no compara. La condición siempre es true
if (x = 5) { }  // Error de compilación

// ✅ Comparación correcta
if (x == 5) { }
```

### Error 2: Olvidar las llaves
```java
// ❌ Solo "Verificar..." está dentro del if
if (edad >= 18)
    System.out.println("Verificar...");
    System.out.println("Mayor de edad");  // siempre se ejecuta

// ✅ Con llaves, ambas líneas están dentro
if (edad >= 18) {
    System.out.println("Verificar...");
    System.out.println("Mayor de edad");
}
```

### Error 3: Punto y coma después del if
```java
// ❌ El ; termina la sentencia if, el bloque siempre se ejecuta
if (edad >= 18); {
    System.out.println("Mayor de edad");  // siempre se imprime
}

// ✅ Sin punto y coma
if (edad >= 18) {
    System.out.println("Mayor de edad");
}
```

### Error 4: Comparación de Strings con ==
```java
// ❌ Compara referencias, no contenido
if (nombre == "Carlos") { }

// ✅ Compara contenido correctamente
if ("Carlos".equals(nombre)) { }
```
