## ¿Qué es Scanner?

`Scanner` es una clase del paquete `java.util` que permite leer datos desde diversas fuentes: la consola (System.in), archivos, strings, etc. Es la forma más común de obtener entrada del usuario en programas Java.

Para usar Scanner, primero debes importarlo:

```java
import java.util.Scanner;
```

La línea de import debe ir **antes** de la definición de cualquier clase.

## Crear un Scanner

Para leer datos de la consola:

```java
Scanner sc = new Scanner(System.in);
```

- `Scanner` es el tipo de la variable
- `new Scanner(System.in)` crea un nuevo objeto que lee de la entrada estándar (teclado)

Siempre indica al usuario qué esperas **antes** de llamar a un método de lectura:

```java
System.out.print("¿Cuál es tu nombre? ");
String nombre = sc.nextLine();  // se detiene aquí hasta que el usuario presione Enter
```

## Métodos principales de lectura

| Método | Lee | Tipo de retorno |
|--------|-----|-----------------|
| `nextLine()` | Una línea completa (hasta Enter) | `String` |
| `next()` | Una palabra (hasta espacio) | `String` |
| `nextInt()` | Un entero | `int` |
| `nextDouble()` | Un decimal | `double` |
| `nextBoolean()` | true o false | `boolean` |

<CodeBlock lang="java" title="Lectura de diferentes tipos">
{`import java.util.Scanner;

public class TiposDeEntrada {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Tu nombre: ");
        String nombre = sc.nextLine();

        System.out.print("Tu edad: ");
        int edad = sc.nextInt();

        System.out.print("Tu altura (m): ");
        double altura = sc.nextDouble();

        System.out.print("¿Estás estudiando? (true/false): ");
        boolean estudiando = sc.nextBoolean();

        System.out.println("\\n--- Tu perfil ---");
        System.out.println("Nombre: " + nombre);
        System.out.println("Edad: " + edad);
        System.out.println("Altura: " + altura + "m");
        System.out.println("Estudiando: " + estudiando);

        sc.close();
    }
}`}
</CodeBlock>

**Salida de ejemplo:**
```
Tu nombre: Ana López
Tu edad: 22
Tu altura (m): 1.65
¿Estás estudiando? (true/false): true

--- Tu perfil ---
Nombre: Ana López
Edad: 22
Altura: 1.65m
Estudiando: true
```

## La trampa del buffer: el error más común

Cuando usas `nextInt()` o `nextDouble()`, Scanner lee el número pero **deja el salto de línea** (Enter) en el buffer. Si luego llamas `nextLine()`, consume ese salto pendiente y parece que "salta" la entrada:

<CodeBlock lang="java" title="El problema del buffer">
{`import java.util.Scanner;

public class TrampaBuffer {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Edad: ");
        int edad = sc.nextInt();

        // ❌ PROBLEMA: nextLine() consume el Enter pendiente
        System.out.print("Nombre: ");
        String nombre = sc.nextLine();  // ¡Se salta! No espera entrada

        System.out.println("Edad: " + edad);
        System.out.println("Nombre: '" + nombre + "'");  // nombre está vacío

        sc.close();
    }
}`}
</CodeBlock>

**La solución:** Añade un `nextLine()` vacío después de cada `nextInt()` o `nextDouble()` para limpiar el buffer:

<CodeBlock lang="java" title="Solución al problema del buffer">
{`import java.util.Scanner;

public class SolucionBuffer {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Edad: ");
        int edad = sc.nextInt();
        sc.nextLine();  // Limpia el buffer — ¡clave!

        System.out.print("Nombre: ");
        String nombre = sc.nextLine();  // Ahora funciona correctamente

        System.out.println("Edad: " + edad);
        System.out.println("Nombre: " + nombre);

        sc.close();
    }
}`}
</CodeBlock>

**Salida de ejemplo:**
```
Edad: 25
Nombre: Carlos Bechara
Edad: 25
Nombre: Carlos Bechara
```

## Lectura de líneas completas vs. palabras

<CodeBlock lang="java" title="nextLine vs next">
{`import java.util.Scanner;

public class LineaVsPalabra {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // next() lee solo hasta el primer espacio
        System.out.print("Escribe algo (una palabra): ");
        String palabra = sc.next();
        System.out.println("Leído con next(): '" + palabra + "'");

        sc.nextLine();  // limpiar buffer

        // nextLine() lee toda la línea
        System.out.print("Escribe algo (una línea completa): ");
        String linea = sc.nextLine();
        System.out.println("Leído con nextLine(): '" + linea + "'");

        sc.close();
    }
}`}
</CodeBlock>

**Salida de ejemplo:**
```
Escribe algo (una palabra): Hola Mundo
Leído con next(): 'Hola'
Escribe algo (una línea completa): Hola Mundo
Leído con nextLine(): 'Hola Mundo'
```

## Manejo de errores con hasNext

Para evitar que tu programa crashee si el usuario ingresa un tipo incorrecto, usa `hasNextInt()`, `hasNextDouble()`, etc.:

<CodeBlock lang="java" title="Validación con hasNext">
{`import java.util.Scanner;

public class EntradaSegura {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // Leer entero de forma segura
        int numero = 0;
        boolean valido = false;

        while (!valido) {
            System.out.print("Ingresa un número entero: ");
            if (sc.hasNextInt()) {
                numero = sc.nextInt();
                valido = true;
            } else {
                System.out.println("❌ Eso no es un número entero. Intenta de nuevo.");
                sc.next();  // descarta la entrada incorrecta
            }
        }

        System.out.println("✅ Ingresaste: " + numero);
        sc.close();
    }
}`}
</CodeBlock>

**Salida de ejemplo:**
```
Ingresa un número entero: abc
❌ Eso no es un número entero. Intenta de nuevo.
Ingresa un número entero: 42
✅ Ingresaste: 42
```

## Errores frecuentes

### Error 1: Olvidar importar Scanner
```java
// ❌ Error: Scanner cannot be resolved to a type
Scanner sc = new Scanner(System.in);

// ✅ Agregar el import al inicio
import java.util.Scanner;
```

### Error 2: No limpiar el buffer después de nextInt
```java
// ❌ El Enter pendiente se consume con nextLine()
int edad = sc.nextInt();
String nombre = sc.nextLine();  // nombre queda vacío

// ✅ Limpiar el buffer
int edad = sc.nextInt();
sc.nextLine();  // consume el Enter pendiente
String nombre = sc.nextLine();
```

### Error 3: No cerrar Scanner
```java
// ❌ Fuga de recursos
Scanner sc = new Scanner(System.in);
// ... usa sc
// olvidaste sc.close()

// ✅ Siempre cerrar
Scanner sc = new Scanner(System.in);
// ... usa sc
sc.close();
```
