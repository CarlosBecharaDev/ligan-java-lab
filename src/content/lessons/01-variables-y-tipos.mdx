## ¿Qué es una variable?

Una **variable** es un espacio con nombre en la memoria que almacena un valor durante la ejecución de un programa. Piensa en ella como una caja etiquetada: la etiqueta es el nombre de la variable, y lo que guardas dentro es el valor.

En Java, cada variable debe declararse con un **tipo de dato específico** que no puede cambiar después de su declaración. Esto se llama **tipado estático fuerte** y es una de las razones por las que Java es robusto y confiable.

## Analogía: la oficina de correos

Imagina la memoria RAM de tu computadora como una gran oficina de correos con casilleros de distintos tamaños:

- **Casilleros pequeños** (`int`, `boolean`, `char`): Guardan el valor directamente dentro del casillero. Son los **tipos primitivos**.
- **Casilleros gigantes** (`String`, `ArrayList`): Son demasiado grandes para guardar el valor real. En su lugar, contienen una nota con la dirección de donde está el paquete. Esta nota es una **referencia**.

Los casilleros pequeños están en la zona rápida (**Stack**), y los paquetes grandes están en el almacén (**Heap**).

## Los 8 tipos primitivos de Java

Java tiene exactamente 8 tipos primitivos:

| Tipo | Tamaño | Rango / Descripción | Ejemplo |
|------|--------|---------------------|---------|
| `byte` | 8 bits | -128 a 127 | `byte nivel = 5;` |
| `short` | 16 bits | -32,768 a 32,767 | `short año = 2026;` |
| `int` | 32 bits | -2,147M a 2,147M | `int edad = 30;` |
| `long` | 64 bits | Muy grande | `long poblacion = 8_000_000_000L;` |
| `float` | 32 bits | Decimal (precisión limitada) | `float temperatura = 36.5f;` |
| `double` | 64 bits | Decimal (alta precisión) | `double salario = 1500.50;` |
| `char` | 16 bits | Un carácter Unicode | `char genero = 'M';` |
| `boolean` | 1 bit | `true` o `false` | `boolean activo = true;` |

<CodeBlock lang="java" title="Los 8 tipos primitivos">
{`public class TiposPrimitivos {
    public static void main(String[] args) {
        byte nivel = 5;
        short año = 2026;
        int edad = 30;
        long poblacion = 8_000_000_000L;
        float temperatura = 36.5f;
        double salario = 1500.50;
        char genero = 'M';
        boolean activo = true;

        System.out.println("Nivel: " + nivel);
        System.out.println("Año: " + año);
        System.out.println("Edad: " + edad);
        System.out.println("Población: " + poblacion);
        System.out.println("Temperatura: " + temperatura);
        System.out.println("Salario: " + salario);
        System.out.println("Género: " + genero);
        System.out.println("Activo: " + activo);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Nivel: 5
Año: 2026
Edad: 30
Población: 8000000000
Temperatura: 36.5
Salario: 1500.5
Género: M
Activo: true
```

## Tipos de referencia: String y más allá

Los **tipos de referencia** son objetos que almacenan una dirección de memoria (referencia) que apunta al objeto real en el Heap. El más usado es `String`:

<CodeBlock lang="java" title="String y tipos de referencia">
{`public class TiposReferencia {
    public static void main(String[] args) {
        String nombre = "Carlos";
        String apellido = "Bechara";
        String nombreCompleto = nombre + " " + apellido;

        System.out.println("Nombre completo: " + nombreCompleto);
        System.out.println("Longitud: " + nombreCompleto.length());
        System.out.println("En mayúsculas: " + nombreCompleto.toUpperCase());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Nombre completo: Carlos Bechara
Longitud: 14
En mayúsculas: CARLOS BECHARA
```

Nota cómo `String` tiene métodos como `.length()` y `.toUpperCase()` — los tipos primitivos no tienen métodos porque no son objetos.

## Declaración e inicialización

La sintaxis para declarar una variable sigue un patrón claro:

```java
// [Tipo] [nombre] = [valor];
int edad = 25;
String nombre = "Ana";

// Declaración sin valor (inicialización posterior)
double salario;
salario = 1500.50;

// En Java 10+, var infiere el tipo automáticamente
var precio = 99.99;    // infiere double
var mensaje = "Hola";  // infiere String
```

## Constantes con `final`

Cuando un valor no debe cambiar durante la ejecución, se declara con `final`. Por convención, las constantes se nombran en `MAYÚSCULAS_CON_GUIONES_BAJOS`:

```java
final double PI = 3.14159;
final int MAX_INTENTOS = 3;
final String PAIS = "México";

// PI = 3.14;  // Error de compilación: no se puede reasignar
```

## Errores frecuentes

### Error 1: Tipo incorrecto en la asignación
```java
// ❌ Error: no se puede asignar un double a un int directamente
int precio = 19.99;

// ✅ Corrección: usar double o casting explícito
double precio = 19.99;
int precioEntero = (int) 19.99;  // resultado: 19 (pierde decimales)
```

### Error 2: Variable local sin inicializar
```java
// ❌ Error de compilación
int resultado;
System.out.println(resultado);  // variable might not have been initialized

// ✅ Corrección: inicializar antes de usar
int resultado = 0;
System.out.println(resultado);
```

### Error 3: Confundir `=` con `==`
```java
// = es asignación (guarda un valor)
int x = 10;

// == es comparación (compara dos valores)
if (x == 10) {
    System.out.println("x es igual a 10");
}
```
