## Switch Expression (Java 14+)

La forma moderna de switch: usa `->` y retorna valores:

```java
// ❌ Antiguo (statement):
String resultado;
switch (dia) {
    case "LUNES": resultado = "Laboral"; break;
    case "SABADO": resultado = "Descanso"; break;
    default: resultado = "Desconocido";
}

// ✅ Moderno (expression):
String resultado = switch (dia) {
    case "LUNES" -> "Laboral";
    case "SABADO" -> "Descanso";
    default -> "Desconocido";
};
```

<CodeBlock lang="java" title="Switch expression con diferentes tipos">
{`public class SwitchExpression {
    public static void main(String[] args) {
        // Con String (Java 7+)
        String dia = "SABADO";

        String tipo = switch (dia) {
            case "LUNES", "MARTES", "MIERCOLES", "JUEVES", "VIERNES"
                -> "Laboral";
            case "SABADO", "DOMINGO" -> "Descanso";
            case null -> "Día nulo";
            default -> "Desconocido: " + dia;
        };
        System.out.println(dia + " → " + tipo);

        // Con int
        int nota = 85;
        String letra = switch (nota / 10) {
            case 10, 9 -> "A";
            case 8 -> "B";
            case 7 -> "C";
            case 6 -> "D";
            default -> "F";
        };
        System.out.println(nota + " → " + letra);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
SABADO → Descanso
85 → B
```

## Pattern Matching con instanceof (Java 16+)

<CodeBlock lang="java" title="instanceof sin cast manual">
{`public class PatternInstanceof {
    public static void main(String[] args) {
        Object obj = "Hola Java 21";

        // ❌ Antes de Java 16:
        if (obj instanceof String) {
            String s = (String) obj;
            System.out.println("Longitud: " + s.length());
        }

        // ✅ Pattern matching (Java 16+):
        if (obj instanceof String s) {
            System.out.println("Largo: " + s.length());
            System.out.println("Mayúsculas: " + s.toUpperCase());
        }

        // Con operadores lógicos
        Object num = 42;
        if (num instanceof Integer i && i > 10) {
            System.out.println("Número > 10: " + i);
        }
    }
}`}
</CodeBlock>

## Pattern Matching en switch (Java 21+)

<CodeBlock lang="java" title="Pattern matching en switch">
{`public class PatternSwitch {
    static String describir(Object obj) {
        return switch (obj) {
            case Integer i -> "Entero: " + i;
            case String s -> "String: " + s;
            case Double d -> "Decimal: " + d;
            case null -> "Es null";
            default -> "Tipo desconocido: " + obj.getClass().getSimpleName();
        };
    }

    public static void main(String[] args) {
        System.out.println(describir(42));
        System.out.println(describir("Hola"));
        System.out.println(describir(3.14));
        System.out.println(describir((Object) null));
        System.out.println(describir(true));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Entero: 42
String: Hola
Decimal: 3.14
Es null
Tipo desconocido: Boolean
```

## Guarded Patterns con when

<CodeBlock lang="java" title="Patrones con condiciones (when)">
{`public class GuardedPatterns {
    record Persona(String nombre, int edad) {}

    static String clasificar(Object obj) {
        return switch (obj) {
            case Persona(var n, var e) when e >= 60
                -> n + " (Adulto mayor)";
            case Persona(var n, var e) when e >= 18
                -> n + " (Adulto)";
            case Persona(var n, _)
                -> n + " (Menor)";
            case null -> "Objeto nulo";
            default -> "No es una persona";
        };
    }

    public static void main(String[] args) {
        System.out.println(clasificar(new Persona("Ana", 70)));
        System.out.println(clasificar(new Persona("Luis", 25)));
        System.out.println(clasificar(new Persona("Sofía", 12)));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Ana (Adulto mayor)
Luis (Adulto)
Sofía (Menor)
```

## Desestructuración de records

```java
record Punto(int x, int y) {}

// Pattern matching con desestructuración
if (p instanceof Punto(var x, var y)) {
    System.out.println("x=" + x + ", y=" + y);
}

// Con ignore (_)
if (p instanceof Punto(var x, _)) {
    System.out.println("x=" + x);
}
```
