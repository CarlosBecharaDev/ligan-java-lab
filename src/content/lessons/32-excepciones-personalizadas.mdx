## ¿Por qué crear excepciones personalizadas?

Las excepciones genéricas (`IllegalArgumentException`, `RuntimeException`) no comunican **qué específicamente** falló. Una excepción personalizada como `SaldoInsuficienteException` le dice al llamador exactamente qué pasó y le da datos útiles para recuperarse.

## Crear una excepción unchecked

<CodeBlock lang="java" title="Excepción unchecked personalizada">
{`class SaldoInsuficienteException extends RuntimeException {
    private final double saldoActual;
    private final double montoSolicitado;

    SaldoInsuficienteException(double saldoActual, double montoSolicitado) {
        super(String.format(
            "Saldo insuficiente: disponible $%.2f, solicitado $%.2f",
            saldoActual, montoSolicitado));
        this.saldoActual = saldoActual;
        this.montoSolicitado = montoSolicitado;
    }

    public double getSaldoActual() { return saldoActual; }
    public double getMontoSolicitado() { return montoSolicitado; }
    public double getFalta() { return montoSolicitado - saldoActual; }
}

public class CuentaBancaria {
    private double saldo;

    CuentaBancaria(double saldo) { this.saldo = saldo; }

    void retirar(double monto) {
        if (monto > saldo) {
            throw new SaldoInsuficienteException(saldo, monto);
        }
        saldo -= monto;
        System.out.printf("Retiro: $%.2f. Saldo: $%.2f%n", monto, saldo);
    }

    public static void main(String[] args) {
        CuentaBancaria cuenta = new CuentaBancaria(500);
        try {
            cuenta.retirar(300);
            cuenta.retirar(400);
        } catch (SaldoInsuficienteException e) {
            System.out.println("Error: " + e.getMessage());
            System.out.printf("Falta: $%.2f%n", e.getFalta());
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Retiro: $300.00. Saldo: $200.00
Error: Saldo insuficiente: disponible $200.00, solicitado $400.00
Falta: $200.00
```

## Crear una excepción checked

<CodeBlock lang="java" title="Excepción checked personalizada">
{`class ConexionException extends Exception {
    private final String servidor;
    private final int codigoError;

    ConexionException(String servidor, int codigoError, String mensaje) {
        super(mensaje);
        this.servidor = servidor;
        this.codigoError = codigoError;
    }

    public String getServidor() { return servidor; }
    public int getCodigoError() { return codigoError; }
}

public class ServicioExterno {
    static void conectar(String servidor) throws ConexionException {
        if (servidor.contains("localhost")) {
            throw new ConexionException(servidor, 503,
                "No se pudo conectar a " + servidor);
        }
        System.out.println("Conectado a " + servidor);
    }

    public static void main(String[] args) {
        try {
            conectar("api.empresa.com");
            conectar("localhost:8080");
        } catch (ConexionException e) {
            System.out.printf("Error %d: %s (servidor: %s)%n",
                e.getCodigoError(), e.getMessage(), e.getServidor());
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Conectado a api.empresa.com
Error 503: No se pudo conectar a localhost:8080 (servidor: localhost:8080)
```

## Jerarquía de excepciones para un módulo

```java
// Excepción base del módulo
class AppException extends Exception {
    AppException(String msg) { super(msg); }
    AppException(String msg, Throwable cause) { super(msg, cause); }
}

// Excepciones específicas
class DatabaseException extends AppException { ... }
class ValidationException extends AppException { ... }
class AuthenticationException extends AppException { ... }
```

**Ventaja:** Puedes capturar todas las excepciones del módulo con `catch (AppException e)` o manejar cada una por separado.

| Campo | Tipo | Ejemplo |

| `context` | Map/String | `"producto=Laptop, usuario=123"` |
| `cause` | Throwable | La excepción original |
| `severity` | enum | `WARNING, ERROR, CRITICAL` |
