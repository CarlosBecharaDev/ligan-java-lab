## ¿Qué es un Record?

Un **record** es una clase especial diseñada para contener **datos inmutables** de forma concisa. El compilador genera automáticamente:

```java
// Esta única línea genera:
record Persona(String nombre, int edad) { }

// ✅ Constructor con todos los campos
// ✅ Accessors (nombre(), edad() — NO getNombre())
// ✅ equals() y hashCode()
// ✅ toString()
```

## Comparación: clase vs record

**Clase tradicional (~50 líneas):**
```java
public class Persona {
    private final String nombre;
    private final int edad;

    public Persona(String nombre, int edad) { ... }
    public String getNombre() { return nombre; }
    public int getEdad() { return edad; }
    public boolean equals(Object o) { ... }
    public int hashCode() { ... }
    public String toString() { ... }
}
```

**Record (1 línea):**
```java
record Persona(String nombre, int edad) { }
```

## Usar un record

<CodeBlock lang="java" title="Record en acción">
{`public class DemoRecord {
    public static void main(String[] args) {
        record Punto(int x, int y) {}

        Punto p1 = new Punto(3, 4);
        Punto p2 = new Punto(3, 4);
        Punto p3 = new Punto(5, 6);

        // toString
        System.out.println("p1: " + p1);

        // Accessors (sin get prefijo)
        System.out.println("x: " + p1.x() + ", y: " + p1.y());

        // equals
        System.out.println("p1.equals(p2): " + p1.equals(p2));
        System.out.println("p1.equals(p3): " + p1.equals(p3));

        // hashCode
        System.out.println("hashCode: " + p1.hashCode());

        // Deconstructor (pattern matching, Java 21+)
        if (p1 instanceof Punto(var x, var y)) {
            System.out.println("Desestructurado: " + x + ", " + y);
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
p1: Punto[x=3, y=4]
x: 3, y: 4
p1.equals(p2): true
p1.equals(p3): false
hashCode: 28
Desestructurado: 3, 4
```

## Compact Constructor — validación

<CodeBlock lang="java" title="Validar datos en el compact constructor">
{`public class CompactConstructor {
    public static void main(String[] args) {
        record Email(String direccion) {
            Email {  // Compact constructor: no necesitas asignar this.direccion
                if (direccion == null || !direccion.contains("@")) {
                    throw new IllegalArgumentException(
                        "Email inválido: " + direccion);
                }
            }
        }

        Email valido = new Email("user@mail.com");
        System.out.println("OK: " + valido.direccion());

        try {
            new Email("invalido");
        } catch (IllegalArgumentException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Métodos en records

<CodeBlock lang="java" title="Agregar métodos a un record">
{`public class MetodosRecord {
    public static void main(String[] args) {
        record Temperatura(double celsius) {
            // Método de instancia
            public double fahrenheit() {
                return celsius * 9.0 / 5.0 + 32;
            }

            // Método estático
            public static Temperatura fromFahrenheit(double f) {
                return new Temperatura((f - 32) * 5.0 / 9.0);
            }
        }

        Temperatura t = new Temperatura(37.5);
        System.out.printf("%.1f°C = %.1f°F%n", t.celsius(), t.fahrenheit());

        Temperatura t2 = Temperatura.fromFahrenheit(98.6);
        System.out.printf("98.6°F = %.1f°C%n", t2.celsius());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
37.5°C = 99.5°F
98.6°F = 37.0°C
```
