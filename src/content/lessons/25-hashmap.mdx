## ¿Qué es un HashMap?

Un **HashMap** almacena pares de **clave-valor**. Cada clave es única y permite acceder a su valor en tiempo casi constante O(1). Es como un diccionario: buscas por palabra (clave) y obtienes la definición (valor).

```java
import java.util.HashMap;

HashMap<String, Integer> edades = new HashMap<>();
edades.put("Ana", 25);
edades.put("Luis", 30);
System.out.println(edades.get("Ana"));  // 25
```

## Crear y usar un HashMap

<CodeBlock lang="java" title="Crear HashMap y operaciones básicas">
{`import java.util.HashMap;

public class CrearHashMap {
    public static void main(String[] args) {
        HashMap<String, Double> calificaciones = new HashMap<>();

        // put: agregar o actualizar
        calificaciones.put("Mate", 9.5);
        calificaciones.put("Español", 8.0);
        calificaciones.put("Ciencias", 9.2);
        System.out.println("Calificaciones: " + calificaciones);

        // get: obtener valor por clave
        double notaMate = calificaciones.get("Mate");
        System.out.println("Nota Mate: " + notaMate);

        // Actualizar valor
        calificaciones.put("Español", 8.5);
        System.out.println("Español actualizado: " + calificaciones.get("Español"));

        // size: cantidad de pares
        System.out.println("Total materias: " + calificaciones.size());
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Calificaciones: {Mate=9.5, Español=8.0, Ciencias=9.2}
Nota Mate: 9.5
Español actualizado: 8.5
Total materias: 3
```

## Métodos importantes

| Método | Descripción | Retorno |
|--------|-------------|---------|
| `put(clave, valor)` | Agrega o actualiza | valor anterior (o null) |
| `get(clave)` | Obtiene valor | valor o null |
| `getOrDefault(clave, defecto)` | Obtiene o usa defecto | valor o defecto |
| `remove(clave)` | Elimina par | valor eliminado |
| `containsKey(clave)` | ¿Existe la clave? | boolean |
| `containsValue(valor)` | ¿Existe el valor? | boolean |
| `size()` | Cantidad de pares | int |

<CodeBlock lang="java" title="Métodos útiles de HashMap">
{`import java.util.HashMap;

public class MetodosHashMap {
    public static void main(String[] args) {
        HashMap<String, Integer> inventario = new HashMap<>();
        inventario.put("Manzanas", 50);
        inventario.put("Peras", 30);

        // getOrDefault: si no existe, retorna valor por defecto
        int uvas = inventario.getOrDefault("Uvas", 0);
        System.out.println("Uvas: " + uvas);  // 0

        // putIfAbsent: solo agrega si no existe
        inventario.putIfAbsent("Manzanas", 100);  // no cambia
        inventario.putIfAbsent("Uvas", 25);        // agrega
        System.out.println("Después de putIfAbsent: " + inventario);

        // containsKey / containsValue
        System.out.println("¿Tiene Peras?: " + inventario.containsKey("Peras"));
        System.out.println("¿Tiene 50?: " + inventario.containsValue(50));

        // remove
        inventario.remove("Peras");
        System.out.println("Sin Peras: " + inventario);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Uvas: 0
Después de putIfAbsent: {Manzanas=50, Uvas=25}
¿Tiene Peras?: true
¿Tiene 50?: true
Sin Peras: {Manzanas=50, Uvas=25}
```

## Iterar sobre un HashMap

<CodeBlock lang="java" title="Tres formas de recorrer un HashMap">
{`import java.util.HashMap;
import java.util.Map;

public class IterarHashMap {
    public static void main(String[] args) {
        HashMap<String, String> capitales = new HashMap<>();
        capitales.put("Colombia", "Bogotá");
        capitales.put("México", "Ciudad de México");
        capitales.put("Argentina", "Buenos Aires");

        // Forma 1: entrySet (clave + valor)
        System.out.println("--- entrySet ---");
        for (Map.Entry<String, String> entry : capitales.entrySet()) {
            System.out.println(entry.getKey() + " → " + entry.getValue());
        }

        // Forma 2: keySet (solo claves)
        System.out.println("--- keySet ---");
        for (String pais : capitales.keySet()) {
            System.out.println(pais);
        }

        // Forma 3: values (solo valores)
        System.out.println("--- values ---");
        for (String capital : capitales.values()) {
            System.out.println(capital);
        }

        // Forma 4: forEach con lambda (Java 8+)
        System.out.println("--- forEach ---");
        capitales.forEach((pais, capital) ->
            System.out.println(pais + " → " + capital));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
--- entrySet ---
Colombia → Bogotá
México → Ciudad de México
Argentina → Buenos Aires
--- keySet ---
Colombia
México
Argentina
--- values ---
Bogotá
Ciudad de México
Buenos Aires
--- forEach ---
Colombia → Bogotá
México → Ciudad de México
Argentina → Buenos Aires
```

## HashMap con objetos como valores

<CodeBlock lang="java" title="HashMap con valores complejos">
{`import java.util.HashMap;

public class HashMapObjetos {
    public static void main(String[] args) {
        HashMap<String, double[]> notas = new HashMap<>();

        notas.put("Ana", new double[]{9.0, 8.5, 9.2});
        notas.put("Luis", new double[]{7.5, 8.0, 7.8});
        notas.put("María", new double[]{9.5, 9.0, 9.8});

        for (String nombre : notas.keySet()) {
            double[] exámenes = notas.get(nombre);
            double promedio = 0;
            for (double nota : exámenes) promedio += nota;
            promedio /= exámenes.length;
            System.out.printf("%s: promedio %.1f%n",
                nombre, promedio);
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Ana: promedio 8.9
Luis: promedio 7.8
María: promedio 9.4
```
