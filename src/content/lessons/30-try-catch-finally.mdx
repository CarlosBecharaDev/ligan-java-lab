## try-catch básico

El bloque `try` contiene código que puede lanzar excepciones. El bloque `catch` maneja el error:

<CodeBlock lang="java" title="try-catch básico">
{`public class TryCatchBasico {
    public static void main(String[] args) {
        try {
            int resultado = 10 / 0;
            System.out.println("Esto no se imprime");
        } catch (ArithmeticException e) {
            System.out.println("Error aritmético: " + e.getMessage());
        }

        System.out.println("El programa continúa");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Error aritmético: / by zero
El programa continúa
```

## Multi-catch (Java 7+)

Manejar múltiples excepciones en un solo bloque:

<CodeBlock lang="java" title="Multi-catch — manejar varios errores juntos">
{`public class MultiCatch {
    public static void main(String[] args) {
        String[] datos = {"10", "abc", null};

        for (String dato : datos) {
            try {
                int valor = Integer.parseInt(dato);
                int divisor = 100 / valor;
                System.out.println("100/" + valor + " = " + divisor);
            } catch (NumberFormatException | ArithmeticException e) {
                System.out.println("Error con '" + dato + "': "
                    + e.getClass().getSimpleName());
            }
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
100/10 = 10
Error con 'abc': NumberFormatException
Error con 'null': NumberFormatException
```

## finally — ejecución garantizada

El bloque `finally` se ejecuta **siempre**, tanto si hay excepción como si no:

<CodeBlock lang="java" title="finally siempre se ejecuta">
{`public class FinallyDemo {
    public static void main(String[] args) {
        System.out.println("Inicio");

        try {
            System.out.println("En try — antes del error");
            int x = 1 / 0;
            System.out.println("Esto no se ejecuta");
        } catch (ArithmeticException e) {
            System.out.println("En catch — error atrapado");
        } finally {
            System.out.println("En finally — siempre se ejecuta");
        }

        System.out.println("Fin del programa");
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Inicio
En try — antes del error
En catch — error atrapado
En finally — siempre se ejecuta
Fin del programa
```

## try-with-resources (Java 7+)

Cierra **automáticamente** los recursos que implementan `AutoCloseable`:

<CodeBlock lang="java" title="try-with-resources — cierre automático">
{`import java.io.*;

public class TryWithResources {
    public static void main(String[] args) {
        // El recurso se declara en try y se cierra automáticamente
        try (BufferedReader br = new BufferedReader(
                new FileReader("datos.txt"))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                System.out.println(linea);
            }
        } catch (FileNotFoundException e) {
            System.out.println("Archivo no encontrado");
        } catch (IOException e) {
            System.out.println("Error de lectura: " + e.getMessage());
        }
        // No necesitas llamar br.close() — se hace automáticamente
    }
}`}
</CodeBlock>

## Múltiples recursos en try-with-resources

<CodeBlock lang="java" title="Cierre de múltiples recursos">
{`import java.io.*;

public class MultiRecurso {
    public static void main(String[] args) {
        try (
            FileReader fr = new FileReader("entrada.txt");
            BufferedReader br = new BufferedReader(fr);
            PrintWriter pw = new PrintWriter(new FileWriter("salida.txt"))
        ) {
            String linea;
            while ((linea = br.readLine()) != null) {
                pw.println(linea.toUpperCase());
            }
            System.out.println("Archivo procesado");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**Importante:** Los recursos se cierran en **orden inverso** al que se declararon.

## Excepciones en finally

```java
try {
    // código que lanza excepción A
} catch (A e) {
    // maneja A
} finally {
    // si aquí lanzas B, se pierde A
    // Java 7+ guarda A como "suppressed" en B
}
```
