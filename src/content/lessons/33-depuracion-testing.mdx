      public class AnalisisTemperatura {
          static double promedio(double[] temperaturas) {
              if (temperaturas == null || temperaturas.length == 0) {
                  throw new IllegalArgumentException("Array vacío o null");
              }
              double suma = 0;
              for (double t : temperaturas) {
                  suma += t;
              }
              return suma / temperaturas.length;  // potencial bug: división por entero
          }

          public static void main(String[] args) {
              double[] temps = {36.5, 37.0, 38.2, 37.5, 36.8};
              double prom = promedio(temps);
              System.out.printf("Promedio: %.2f°C%n", prom);

              // Prueba simple inline
              double esperado = 37.2;
              if (Math.abs(prom - esperado) > 0.01) {
                  System.out.println("ERROR: Promedio esperado " + esperado +
                      ", obtenido " + prom);
              } else {
                  System.out.println("OK: Promedio correcto");
              }
          }
      }
    result: |
      Promedio: 37.20°C
      OK: Promedio correcto

## Depuración con println

La técnica más básica y universal: imprimir valores en puntos estratégicos:

<CodeBlock lang="java" title="Depuración con println">
{`public class DebugPrintln {
    static int factorial(int n) {
        System.out.println("factorial(" + n + ")");
        if (n == 0) return 1;
        int resultado = n * factorial(n - 1);
        System.out.println("  → factorial(" + n + ") = " + resultado);
        return resultado;
    }

    public static void main(String[] args) {
        System.out.println("Resultado: " + factorial(4));
    }
}`}
</CodeBlock>

**Salida esperada:**
```
factorial(4)
factorial(3)
factorial(2)
factorial(1)
factorial(0)
  → factorial(1) = 1
  → factorial(2) = 2
  → factorial(3) = 6
  → factorial(4) = 24
Resultado: 24
```

## Aserciones (assert)

`assert` verifica condiciones en tiempo de desarrollo. Se activan con la flag `-ea`:

```bash
java -ea MiPrograma
```

<CodeBlock lang="java" title="Aserciones para depuración">
{`public class Aserciones {
    static double raizCuadrada(double n) {
        assert n >= 0 : "No se puede raíz de número negativo: " + n;
        return Math.sqrt(n);
    }

    public static void main(String[] args) {
        System.out.println(raizCuadrada(25));  // 5.0
        System.out.println(raizCuadrada(-1));  // lanza AssertionError con -ea
    }
}`}
</CodeBlock>

## Técnica de "divide y vencerás"

Para encontrar un bug, ve eliminando partes del código hasta aislar el error:

1. **Comenta la mitad del código** y prueba si el error persiste
2. Si persiste → el bug está en la mitad no comentada
3. Si desaparece → el bug está en la comentada
4. **Repite** hasta aislar el bug

## Escribir pruebas unitarias con JUnit 5

```java
// Calculadora.java
public class Calculadora {
    static int sumar(int a, int b) { return a + b; }
    static int restar(int a, int b) { return a - b; }
    static int multiplicar(int a, int b) { return a * b; }
    static int dividir(int a, int b) { return a / b; }
}
```

```java
// CalculadoraTest.java
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CalculadoraTest {
    @Test
    void testSumar() {
        assertEquals(5, Calculadora.sumar(2, 3));
        assertEquals(-1, Calculadora.sumar(-2, 1));
        assertEquals(0, Calculadora.sumar(0, 0));
    }

    @Test
    void testDividir() {
        assertEquals(2, Calculadora.dividir(10, 5));
        assertThrows(ArithmeticException.class,
            () -> Calculadora.dividir(5, 0));
    }
}
```

## Leer un stack trace como un experto

```
Exception in thread "main" java.lang.NullPointerException
    └──────────────────────────────────────↕──┘
     Tipo de excepción                      Mensaje

    at com.app.Paciente.nombre.toUpperCase(Paciente.java:42)
    └───────────────────┘
     Qué se intentó hacer (nombre.toUpperCase en un nombre null)

    at com.app.Main.registrar(Main.java:15)
    at com.app.Main.main(Main.java:5)
    └── Pila de quién llamó a quién
```

**Pasos:**
1. Identifica el **tipo** de excepción (`NullPointerException`)
2. Lee el **mensaje** (null)
3. Ve a la **primera línea 'at'** que es TU código (`Paciente.java:42`)
4. Abre el archivo en la línea indicada y busca qué es `null`

## La técnica del "rubber duck"

Explica tu código línea por línea a un objeto inanimado (un pato de goma). Al verbalizar lo que hace cada línea, a menudo encuentras el error tú mismo sin que el pato diga nada.
