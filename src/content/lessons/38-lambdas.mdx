      import java.util.*;
      import java.util.function.*;

      class Paciente {
          String nombre;
          double temperatura;
          boolean urgencia;

          Paciente(String n, double t, boolean u) {
              nombre = n; temperatura = t; urgencia = u;
          }
      }

      public class ProcesarPacientes {
          public static void main(String[] args) {
              ArrayList<Paciente> pacientes = new ArrayList<>();
              pacientes.add(new Paciente("Ana", 38.5, true));
              pacientes.add(new Paciente("Luis", 36.5, false));
              pacientes.add(new Paciente("María", 39.2, true));

              // Predicate — probar condición
              Predicate<Paciente> tieneFiebre = p -> p.temperatura >= 37.5;

              // Consumer — imprimir resultado
              Consumer<Paciente> reportar = p -> {
                  String estado = tieneFiebre.test(p) ? "FIEBRE" : "Normal";
                  System.out.printf("%s: %.1f°C (%s)%n",
                      p.nombre, p.temperatura, estado);
              };

              pacientes.forEach(reportar);

              // Supplier — generar alerta
              Supplier<String> alerta = () -> {
                  long graves = pacientes.stream()
                      .filter(p -> p.urgencia && tieneFiebre.test(p))
                      .count();
                  return "Alerta: " + graves + " pacientes urgentes con fiebre";
              };
              System.out.println(alerta.get());
          }
      }
    result: |
      Ana: 38.5°C (FIEBRE)
      Luis: 36.5°C (Normal)
      María: 39.2°C (FIEBRE)
      Alerta: 2 pacientes urgentes con fiebre

## ¿Qué es una expresión lambda?

Una **lambda** es una función anónima que puedes tratar como un valor. Es una forma concisa de implementar interfaces funcionales (interfaces con un solo método).

```java
// Sintaxis básica
(parametros) -> { cuerpo }

// Ejemplo: comparador
Comparator<String> c = (a, b) -> a.length() - b.length();
```

## Sintaxis de lambdas

<CodeBlock lang="java" title="Diferentes formas de escribir una lambda">
{`import java.util.function.*;

public class SintaxisLambda {
    public static void main(String[] args) {
        // Forma 1: sin parámetros
        Supplier<String> saludar = () -> "Hola Mundo";
        System.out.println(saludar.get());

        // Forma 2: un parámetro (sin paréntesis)
        Function<String, Integer> longitud = s -> s.length();
        System.out.println("Longitud: " + longitud.apply("Java"));

        // Forma 3: dos parámetros (con paréntesis)
        BiFunction<Integer, Integer, Integer> suma = (a, b) -> a + b;
        System.out.println("Suma: " + suma.apply(5, 3));

        // Forma 4: múltiples líneas (con llaves y return)
        Predicate<Integer> esPar = n -> {
            System.out.println("Probando: " + n);
            return n % 2 == 0;
        };
        System.out.println("¿Es par? " + esPar.test(7));
    }
}`}
</CodeBlock>

## Interfaces funcionales principales

```java
// Evalúa una condición → retorna boolean
Predicate<T>       → boolean test(T t)

// Transforma un valor → retorna otro
Function<T, R>     → R apply(T t)

// Recibe un valor → no retorna nada
Consumer<T>        → void accept(T t)

// Genera un valor → no recibe parámetros
Supplier<T>        → T get()

// Compara dos valores → retorna int
Comparator<T>      → int compare(T a, T b)
```

<CodeBlock lang="java" title="Usando las interfaces funcionales">
{`import java.util.*;
import java.util.function.*;

public class InterfacesFuncionales {
    public static void main(String[] args) {
        List<String> nombres = Arrays.asList("Ana", "Luis", "María", "Carlos");

        // Consumer — imprimir
        Consumer<String> imprimir = nombre -> System.out.println("Hola " + nombre);
        nombres.forEach(imprimir);

        // Predicate — filtrar
        Predicate<String> masDe3 = s -> s.length() > 3;
        System.out.println("Nombres > 3 letras:");
        nombres.stream()
               .filter(masDe3)
               .forEach(System.out::println);

        // Function — transformar
        Function<String, String> aMayusculas = s -> s.toUpperCase();
        List<String> mayusculas = new ArrayList<>();
        for (String n : nombres) {
            mayusculas.add(aMayusculas.apply(n));
        }
        System.out.println("Mayúsculas: " + mayusculas);
    }
}`}
</CodeBlock>

## Method References

Un atajo cuando la lambda solo llama a un método existente:

```java
// Lambda
list.forEach(s -> System.out.println(s));

// Method Reference (equivalente)
list.forEach(System.out::println);

// Lambda
list.sort((a, b) -> a.compareToIgnoreCase(b));

// Method Reference
list.sort(String::compareToIgnoreCase);
```

<CodeBlock lang="java" title="Method References en acción">
{`import java.util.*;

public class MethodRefs {
    public static void main(String[] args) {
        List<String> ciudades = Arrays.asList(
            "Bogotá", "Medellín", "Cali", "Barranquilla");

        // Lambda
        ciudades.forEach(c -> System.out.print(c + " "));
        System.out.println();

        // Method Reference: System.out::println
        ciudades.forEach(System.out::println);

        // Static method reference
        ciudades.sort(String::compareToIgnoreCase);
        System.out.println("Ordenado: " + ciudades);

        // Instance method reference
        ciudades.forEach(System.out::print);
    }
}`}
</CodeBlock>

## Lambdas vs clases anónimas

| Aspecto | Clase anónima | Lambda |
|---------|--------------|--------|
| Código | `new X() { metodo() { ... } }` | `() -> ...` |
| `this` | Apunta a la clase anónima | Apunta a la clase circundante |
| Variables | Pueden modificar campos | Deben ser effectively final |
| Ideal | Múltiples métodos | Un solo método (funcional) |
