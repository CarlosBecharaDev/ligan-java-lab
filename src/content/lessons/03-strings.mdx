## ¿Qué es un String?

Un `String` en Java es una **secuencia de caracteres** que forma parte de la librería estándar. A diferencia de los tipos primitivos, `String` es un **objeto** (tipo de referencia), lo que significa que tiene métodos propios que nos permiten manipularlo.

```java
String saludo = "Hola, Java";
System.out.println(saludo.length());    // 10
System.out.println(saludo.charAt(0));  // H
```

## La inmutabilidad: un concepto clave

Los strings en Java son **inmutables**: una vez creados, no pueden modificarse. Cada operación que parece modificar un string en realidad crea uno **nuevo**:

```java
String original = "hola";
String modificado = original.toUpperCase();

System.out.println(original);   // hola (no cambió)
System.out.println(modificado); // HOLA (nuevo string)
```

Esto tiene implicaciones importantes:
- **Seguridad:** Los strings son seguros entre múltiples hilos.
- **String Pool:** Java puede reutilizar strings con el mismo valor en memoria.
- **Rendimiento:** La concatenación repetida en bucles es costosa (crea muchos objetos temporales).

## Crear strings

Hay dos formas principales de crear strings:

<CodeBlock lang="java" title="Creación de strings">
{`public class CrearStrings {
    public static void main(String[] args) {
        // Literal de string (se almacena en el String Pool)
        String literal = "Hola Mundo";

        // Constructor new (siempre crea un objeto nuevo en el Heap)
        String objeto = new String("Hola Mundo");

        // Caracteres
        String desdeChar = new String(new char[]{'J', 'a', 'v', 'a'});

        // Métodos estáticos de conversión
        String desdeNumero = String.valueOf(42);
        String desdeDouble = String.format("%.2f", 3.14159);

        System.out.println(literal);
        System.out.println(objeto);
        System.out.println(desdeChar);
        System.out.println(desdeNumero);
        System.out.println(desdeDouble);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Hola Mundo
Hola Mundo
Java
42
3.14
```

### Literal vs. `new String()`

```java
String a = "java";
String b = "java";
String c = new String("java");

System.out.println(a == b);       // true — mismo objeto en el Pool
System.out.println(a == c);       // false — objetos diferentes
System.out.println(a.equals(c));  // true — mismo contenido
```

> **Regla de oro:** Usa literales para strings conocidos. Usa `new String()` solo cuando necesites forzar un objeto nuevo (raramente es necesario).

## Métodos esenciales de String

### Información del string

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `length()` | Número de caracteres | `"Java".length()` → `4` |
| `charAt(i)` | Carácter en posición i | `"Java".charAt(1)` → `'a'` |
| `isEmpty()` | true si length es 0 | `"".isEmpty()` → `true` |
| `isBlank()` | true si está vacío o solo espacios | `" ".isBlank()` → `true` |

<CodeBlock lang="java" title="Información del string">
{`public class InfoString {
    public static void main(String[] args) {
        String texto = "Programación en Java";

        System.out.println("Longitud: " + texto.length());          // 20
        System.out.println("Primer carácter: " + texto.charAt(0));  // P
        System.out.println("Último carácter: " + texto.charAt(texto.length() - 1)); // a
        System.out.println("Está vacío: " + texto.isEmpty());       // false
        System.out.println("En blanco: " + "  ".isBlank());         // true
    }
}`}
</CodeBlock>

### Búsqueda dentro del string

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `indexOf("sub")` | Primera posición de "sub" | `"Java".indexOf("va")` → `2` |
| `lastIndexOf("sub")` | Última posición | `"Java".lastIndexOf('a')` → `3` |
| `contains("sub")` | true si contiene "sub" | `"Java".contains("av")` → `true` |
| `startsWith("pre")` | true si empieza con "pre" | `"Java".startsWith("Ja")` → `true` |
| `endsWith("suf")` | true si termina con "suf" | `"Java".endsWith("va")` → `true` |

### Extracción de subcadenas

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `substring(inicio)` | Desde inicio hasta el final | `"Java".substring(2)` → `"va"` |
| `substring(inicio, fin)` | Desde inicio hasta fin-1 | `"Java".substring(1, 3)` → `"av"` |

<CodeBlock lang="java" title="Búsqueda y extracción">
{`public class BusquedaExtraccion {
    public static void main(String[] args) {
        String url = "https://www.ejemplo.com/java";

        // Búsqueda
        System.out.println("Contiene 'java': " + url.contains("java"));
        System.out.println("Empieza con 'https': " + url.startsWith("https"));
        System.out.println("Termina con '.com': " + url.endsWith(".com"));

        // Posiciones
        int posicionJava = url.indexOf("java");
        System.out.println("Posición de 'java': " + posicionJava);

        // Subcadenas
        String dominio = url.substring(8, url.indexOf("/", 8));
        System.out.println("Dominio: " + dominio);  // www.ejemplo.com

        String extension = url.substring(url.lastIndexOf("."));
        System.out.println("Extensión: " + extension);  // .com
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Contiene 'java': true
Empieza con 'https': true
Termina con '.com': false
Posición de 'java': 23
Dominio: www.ejemplo.com
Extensión: .com
```

## Transformación de texto

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `toUpperCase()` | Todo en mayúsculas | `"java".toUpperCase()` → `"JAVA"` |
| `toLowerCase()` | Todo en minúsculas | `"JAVA".toLowerCase()` → `"java"` |
| `trim()` | Elimina espacios al inicio y final | `" hola ".trim()` → `"hola"` |
| `strip()` | Como trim pero con soporte Unicode | `" hola ".strip()` → `"hola"` |
| `replace(old, new)` | Reemplaza todas las ocurrencias | `"java".replace('a', 'o')` → `"jovo"` |

<CodeBlock lang="java" title="Transformación de texto">
{`public class TransformacionTexto {
    public static void main(String[] args) {
        String nombre = "  Carlos Bechara  ";

        // Limpiar y formatear
        String limpio = nombre.trim();
        String mayusculas = limpio.toUpperCase();
        String minusculas = limpio.toLowerCase();

        System.out.println("Original: '" + nombre + "'");
        System.out.println("Limpio: '" + limpio + "'");
        System.out.println("Mayúsculas: " + mayusculas);
        System.out.println("Minúsculas: " + minusculas);

        // Reemplazo
        String mensaje = "Hola Mundo, bienvenido a Java";
        String nuevo = mensaje.replace("Mundo", "Java Developer");
        System.out.println("Reemplazado: " + nuevo);

        // Reemplazo de múltiples caracteres
        String codigo = "A1-B2-C3";
        String sinGuiones = codigo.replace("-", "");
        System.out.println("Sin guiones: " + sinGuiones);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Original: '  Carlos Bechara  '
Limpio: 'Carlos Bechara'
Mayúsculas: CARLOS BECHARA
Minúsculas: carlos bechara
Reemplazado: Hola Java Developer, bienvenido a Java
Sin guiones: A1B2C3
```

## División y unión de strings

{`public class SplitJoin {
    public static void main(String[] args) {
        // Dividir un string en un array
        String csv = "Manzana,Pera,Uva,Naranja";

}`}

## Comparación de strings

Nunca uses `==` para comparar contenido de strings. Usa los métodos de comparación:

| Método | Descripción |
|--------|-------------|
| `equals(other)` | Compara contenido exacto |
| `equalsIgnoreCase(other)` | Compara ignorando mayúsculas |
| `compareTo(other)` | Orden lexicográfico (negativo, 0, positivo) |
| `compareToIgnoreCase(other)` | Como compareTo pero ignorando caso |

<CodeBlock lang="java" title="Comparación de strings">
{`public class ComparacionStrings {
    public static void main(String[] args) {
        String a = "Java";
        String b = "java";
        String c = "Kotlin";

        // equals: contenido exacto
        System.out.println("a.equals(b): " + a.equals(b));           // false

        // equalsIgnoreCase: ignora mayúsculas
        System.out.println("a.equalsIgnoreCase(b): " + a.equalsIgnoreCase(b)); // true

        // compareTo: orden lexicográfico
        System.out.println("a.compareTo(c): " + a.compareTo(c));     // negativo (Java < Kotlin)
        System.out.println("c.compareTo(a): " + c.compareTo(a));     // positivo (Kotlin > Java)

        // Comparación práctica: ordenar nombres
        String[] nombres = {"Carlos", "ana", "Bernardo"};
        java.util.Arrays.sort(nombres);
        System.out.println("Orden natural:");
        for (String n : nombres) {
            System.out.println("  " + n);
        }
    }
}`}
</CodeBlock>

**Salida esperada:**
```
a.equals(b): false
a.equalsIgnoreCase(b): true
a.compareTo(c): -3
c.compareTo(a): 3
Orden natural:
  Bernardoa
  Carlos
  ana
```

## Construcción eficiente con StringBuilder

Cuando necesitas construir un string paso a paso (especialmente en bucles), usa `StringBuilder` en vez de concatenar con `+`:

<CodeBlock lang="java" title="StringBuilder vs concatenación">
{`public class EjemploStringBuilder {
    public static void main(String[] args) {
        // ❌ Ineficiente: crea un objeto String nuevo en cada iteración
        String lenta = "";
        for (int i = 0; i < 5; i++) {
            lenta += "Número " + i + " ";  // crea String nuevo cada vez
        }
        System.out.println("Concatenación: " + lenta.trim());

        // ✅ Eficiente: modifica el mismo objeto StringBuilder
        StringBuilder rapida = new StringBuilder();
        for (int i = 0; i < 5; i++) {
            rapida.append("Número ").append(i).append(" ");
        }
        System.out.println("StringBuilder: " + rapida.toString().trim());

        // Otros métodos útiles de StringBuilder
        StringBuilder sb = new StringBuilder("Java");
        sb.insert(4, " Script");   // "Java Script"
        sb.delete(4, 10);          // "Java"
        sb.replace(0, 4, "Python"); // "Python"
        System.out.println("Builder: " + sb);
    }
}`}
</CodeBlock>

**Salida esperada:**
```
Concatenación: Número 0 Número 1 Número 2 Número 3 Número 4
StringBuilder: Número 0 Número 1 Número 2 Número 3 Número 4
Builder: Python
```

### Cuándo usar cada uno

| Situación | Usa |
|-----------|-----|
| Texto conocido que no cambia | `String` literal |
| Concatenar 2-3 partes | `+` (legible) |
| Construir en un bucle | `StringBuilder` |
| Concatenar más de 4 partes | `StringBuilder` |
| Clave de HashMap | `String` (inmutabilidad = seguridad) |

## Errores frecuentes

### Error 1: Comparar con `==` en vez de `.equals()`
```java
// ❌ Compara referencias de memoria, no contenido
String a = new String("java");
String b = new String("java");
if (a == b) { System.out.println("Iguales"); }  // NO se imprime

// ✅ Compara contenido
if (a.equals(b)) { System.out.println("Iguales"); }  // Sí se imprime
```

### Error 2: Subcadenas fuera de rango
```java
// ❌ StringIndexOutOfBoundsException
String s = "Java";
char c = s.charAt(10);

// ✅ Verificar longitud primero
if (s.length() > 10) {
    char c = s.charAt(10);
}
```

### Error 3: Concatenación en bucle
```java
// ❌ Crea 1000 objetos String temporales
String resultado = "";
for (int i = 0; i < 1000; i++) {
    resultado += i + " ";
}

// ✅ Un solo StringBuilder
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(" ");
}
String resultado = sb.toString();
```
