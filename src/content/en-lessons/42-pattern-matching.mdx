## Switch Expression (Java 14+)

The modern form of switch: uses `->` and returns values:

```java
// ❌ Old (statement):
String resultado;
switch (dia) {
    case "LUNES": resultado = "Workday"; break;
    case "SABADO": resultado = "Day off"; break;
    default: resultado = "Unknown";
}

// ✅ Modern (expression):
String resultado = switch (dia) {
    case "LUNES" -> "Workday";
    case "SABADO" -> "Day off";
    default -> "Unknown";
};
```

<CodeBlock lang="java" title="Switch expression with different types">
{`public class SwitchExpression {
    public static void main(String[] args) {
        // With String (Java 7+)
        String dia = "SABADO";

        String tipo = switch (dia) {
            case "LUNES", "MARTES", "MIERCOLES", "JUEVES", "VIERNES"
                -> "Workday";
            case "SABADO", "DOMINGO" -> "Day off";
            case null -> "Null day";
            default -> "Unknown: " + dia;
        };
        System.out.println(dia + " → " + tipo);

        // With int
        int nota = 85;
        String letra = switch (nota / 10) {
            case 10, 9 -> "A";
            case 8 -> "B";
            case 7 -> "C";
            case 6 -> "D";
            default -> "F";
        };
        System.out.println(nota + " → " + letra);
    }
}`}
</CodeBlock>

**Expected output:**
```
SABADO → Day off
85 → B
```

## Pattern Matching with instanceof (Java 16+)

<CodeBlock lang="java" title="instanceof without manual cast">
{`public class PatternInstanceof {
    public static void main(String[] args) {
        Object obj = "Hola Java 21";

        // ❌ Before Java 16:
        if (obj instanceof String) {
            String s = (String) obj;
            System.out.println("Length: " + s.length());
        }

        // ✅ Pattern matching (Java 16+):
        if (obj instanceof String s) {
            System.out.println("Length: " + s.length());
            System.out.println("Uppercase: " + s.toUpperCase());
        }

        // With logical operators
        Object num = 42;
        if (num instanceof Integer i && i > 10) {
            System.out.println("Number > 10: " + i);
        }
    }
}`}
</CodeBlock>

## Pattern Matching in switch (Java 21+)

<CodeBlock lang="java" title="Pattern matching in switch">
{`public class PatternSwitch {
    static String describir(Object obj) {
        return switch (obj) {
            case Integer i -> "Integer: " + i;
            case String s -> "String: " + s;
            case Double d -> "Decimal: " + d;
            case null -> "It is null";
            default -> "Unknown type: " + obj.getClass().getSimpleName();
        };
    }

    public static void main(String[] args) {
        System.out.println(describir(42));
        System.out.println(describir("Hola"));
        System.out.println(describir(3.14));
        System.out.println(describir((Object) null));
        System.out.println(describir(true));
    }
}`}
</CodeBlock>

**Expected output:**
```
Integer: 42
String: Hola
Decimal: 3.14
It is null
Unknown type: Boolean
```

## Guarded Patterns with when

<CodeBlock lang="java" title="Patterns with conditions (when)">
{`public class GuardedPatterns {
    record Persona(String nombre, int edad) {}

    static String clasificar(Object obj) {
        return switch (obj) {
            case Persona(var n, var e) when e >= 60
                -> n + " (Senior)";
            case Persona(var n, var e) when e >= 18
                -> n + " (Adult)";
            case Persona(var n, _)
                -> n + " (Minor)";
            case null -> "Null object";
            default -> "Not a person";
        };
    }

    public static void main(String[] args) {
        System.out.println(clasificar(new Persona("Ana", 70)));
        System.out.println(clasificar(new Persona("Luis", 25)));
        System.out.println(clasificar(new Persona("Sofía", 12)));
    }
}`}
</CodeBlock>

**Expected output:**
```
Ana (Senior)
Luis (Adult)
Sofía (Minor)
```

## Record destructuring

```java
record Punto(int x, int y) {}

// Pattern matching with destructuring
if (p instanceof Punto(var x, var y)) {
    System.out.println("x=" + x + ", y=" + y);
}

// With ignore (_)
if (p instanceof Punto(var x, _)) {
    System.out.println("x=" + x);
}
```
