## Basic try-catch

The `try` block contains code that can throw exceptions. The `catch` block handles the error:

<CodeBlock lang="java" title="Basic try-catch">
{`public class TryCatchBasico {
    public static void main(String[] args) {
        try {
            int resultado = 10 / 0;
            System.out.println("This is not printed");
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error: " + e.getMessage());
        }

        System.out.println("The program continues");
    }
}`}
</CodeBlock>

**Expected output:**
```
Arithmetic error: / by zero
The program continues
```

## Multi-catch (Java 7+)

Handle multiple exceptions in a single block:

<CodeBlock lang="java" title="Multi-catch — handling several errors together">
{`public class MultiCatch {
    public static void main(String[] args) {
        String[] datos = {"10", "abc", null};

        for (String dato : datos) {
            try {
                int valor = Integer.parseInt(dato);
                int divisor = 100 / valor;
                System.out.println("100/" + valor + " = " + divisor);
            } catch (NumberFormatException | ArithmeticException e) {
                System.out.println("Error with '" + dato + "': "
                    + e.getClass().getSimpleName());
            }
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
100/10 = 10
Error with 'abc': NumberFormatException
Error with 'null': NumberFormatException
```

## finally — guaranteed execution

The `finally` block **always** runs, whether there is an exception or not:

<CodeBlock lang="java" title="finally always runs">
{`public class FinallyDemo {
    public static void main(String[] args) {
        System.out.println("Start");

        try {
            System.out.println("In try — before the error");
            int x = 1 / 0;
            System.out.println("This doesn't run");
        } catch (ArithmeticException e) {
            System.out.println("In catch — error caught");
        } finally {
            System.out.println("In finally — always runs");
        }

        System.out.println("End of program");
    }
}`}
</CodeBlock>

**Expected output:**
```
Start
In try — before the error
In catch — error caught
In finally — always runs
End of program
```

## try-with-resources (Java 7+)

**Automatically** closes resources that implement `AutoCloseable`:

<CodeBlock lang="java" title="try-with-resources — automatic closing">
{`import java.io.*;

public class TryWithResources {
    public static void main(String[] args) {
        // The resource is declared in try and closed automatically
        try (BufferedReader br = new BufferedReader(
                new FileReader("datos.txt"))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                System.out.println(linea);
            }
        } catch (FileNotFoundException e) {
            System.out.println("File not found");
        } catch (IOException e) {
            System.out.println("Read error: " + e.getMessage());
        }
        // You don't need to call br.close() — it's done automatically
    }
}`}
</CodeBlock>

## Multiple resources in try-with-resources

<CodeBlock lang="java" title="Closing multiple resources">
{`import java.io.*;

public class MultiRecurso {
    public static void main(String[] args) {
        try (
            FileReader fr = new FileReader("entrada.txt");
            BufferedReader br = new BufferedReader(fr);
            PrintWriter pw = new PrintWriter(new FileWriter("salida.txt"))
        ) {
            String linea;
            while ((linea = br.readLine()) != null) {
                pw.println(linea.toUpperCase());
            }
            System.out.println("File processed");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**Important:** Resources are closed in **reverse order** from the order they were declared.

## Exceptions in finally

```java
try {
    // code that throws exception A
} catch (A e) {
    // handles A
} finally {
    // if you throw B here, A is lost
    // Java 7+ saves A as "suppressed" in B
}
```
