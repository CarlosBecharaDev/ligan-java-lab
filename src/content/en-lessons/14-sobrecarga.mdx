## What is overloading?

Overloading lets you have **several methods with the same name** but different parameters. The compiler picks which one to run based on the arguments you pass.

<CodeBlock lang="java" title="Overloaded methods — sum different types">
{`public class SumaSobrecargada {
    static int sumar(int a, int b) {
        return a + b;
    }

    static double sumar(double a, double b) {
        return a + b;
    }

    static int sumar(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println("integers: " + sumar(3, 5));
        System.out.println("decimals: " + sumar(2.5, 3.7));
        System.out.println("three: " + sumar(1, 2, 3));
    }
}`}
</CodeBlock>

**Expected output:**
```
integers: 8
decimals: 6.2
three: 6
```

All the methods are called `sumar`, but the compiler chooses the right one based on the types and number of arguments.

## Overloading rules

For two methods to be overloaded, they **must differ in their parameters**:

```
✅ Different number of parameters:
   sumar(int, int) vs sumar(int, int, int)

✅ Different parameter types:
   sumar(int, int) vs sumar(double, double)

✅ Both:
   sumar(int) vs sumar(int, double)

❌ NOT overloading — same name and same parameters:
   int sumar(int a, int b)
   double sumar(int a, int b)  // ERROR: only the return type changes
```

The key: **the return type does NOT count** for overloading. Two methods with the same name, same parameters and different return types produce a compilation error.

## The compiler resolves the ambiguity

When you call an overloaded method, the compiler looks for the version whose parameters match best:

<CodeBlock lang="java" title="Overload resolution">
{`public class Resolucion {
    static void mostrar(String texto) {
        System.out.println("String: " + texto);
    }

    static void mostrar(int numero) {
        System.out.println("int: " + numero);
    }

    static void mostrar(double valor) {
        System.out.println("double: " + valor);
    }

    public static void main(String[] args) {
        mostrar("Hello");     // calls mostrar(String)
        mostrar(42);          // calls mostrar(int)
        mostrar(3.14);        // calls mostrar(double)
        mostrar('A');         // calls mostrar(int) — char is promoted to int
    }
}`}
</CodeBlock>

**Expected output:**
```
String: Hello
int: 42
double: 3.14
int: 65
```

**Note:** `char` is implicitly converted to `int` (promotion), so `mostrar('A')` calls `mostrar(int)`, not `mostrar(String)`.

## Overloading with compatible types

The type conversion hierarchy affects which version is chosen:

```
byte → short → int → long → float → double
         char ↗
```

The compiler chooses the **smallest** possible conversion:

<CodeBlock lang="java" title="Type promotion in overloading">
{`public class Promocion {
    static void procesar(int n) {
        System.out.println("int: " + n);
    }

    static void procesar(double d) {
        System.out.println("double: " + d);
    }

    public static void main(String[] args) {
        byte b = 10;
        procesar(b);    // int — byte is promoted to int

        float f = 5.5f;
        procesar(f);    // double — float is promoted to double

        short s = 20;
        procesar(s);    // int — short is promoted to int
    }
}`}
</CodeBlock>

**Expected output:**
```
int: 10
double: 5.5
int: 20
```

## Useful overloading in practice

A common pattern is to offer a simple version and a complete one:

<CodeBlock lang="java" title="Practical overloading — formatting text">
{`public class Formatear {
    static String formatear(String texto) {
        return texto.trim().toUpperCase();
    }

    static String formatear(String texto, int longitud) {
        String resultado = texto.trim().toUpperCase();
        if (resultado.length() > longitud) {
            return resultado.substring(0, longitud) + "...";
        }
        return resultado;
    }

    static String formatear(String texto, int longitud,
            char relleno) {
        String resultado = texto.trim().toUpperCase();
        while (resultado.length() < longitud) {
            resultado = relleno + resultado + relleno;
        }
        return resultado;
    }

    public static void main(String[] args) {
        System.out.println(formatear("  hello world  "));
        System.out.println(formatear("  hello world  ", 8));
        System.out.println(formatear("  hi  ", 12, '*'));
    }
}`}
</CodeBlock>

**Expected output:**
```
HELLO WORLD
HELLO WO...
***HI*****
```

The three versions of `formatear` do similar things but with different levels of customization.
