## Reading a text file

The most common way to read text files in Java:

<CodeBlock lang="java" title="Read a file with BufferedReader">
{`import java.io.*;

public class LeerArchivo {
    public static void main(String[] args) {
        // try-with-resources closes the file automatically
        try (BufferedReader br = new BufferedReader(new FileReader("datos.txt"))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                System.out.println(linea);
            }
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**What does each part do?**
- `FileReader(ruta)`: opens the file for reading
- `BufferedReader(br)`: wraps the FileReader to read line by line
- `readLine()`: reads a complete line, returns `null` at the end
- `try-with-resources`: closes the file automatically

## Exception handling

File operations throw **checked exceptions** that you must handle:

| Exception | When it occurs |
|-----------|---------------|
| `FileNotFoundException` | The file does not exist at the specified path |
| `IOException` | General I/O error (disk, permissions, etc.) |
| `SecurityException` (unchecked) | No read permissions |

## Read the whole file at once

<CodeBlock lang="java" title="Read the whole file as a String (Java 11+)">
{`import java.nio.file.*;

public class LeerTodo {
    public static void main(String[] args) {
        try {
            String contenido = Files.readString(Path.of("datos.txt"));
            System.out.println(contenido);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Read line by line with NIO.2

<CodeBlock lang="java" title="Read with Files.lines() (Java 8+)">
{`import java.nio.file.*;
import java.util.stream.Stream;

public class LeerConStream {
    public static void main(String[] args) {
        try (Stream<String> lineas = Files.lines(Path.of("datos.txt"))) {
            lineas.forEach(System.out::println);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Creating and verifying paths

<CodeBlock lang="java" title="Path operations">
{`import java.nio.file.*;
import java.io.File;

public class OperacionesPath {
    public static void main(String[] args) {
        Path ruta = Path.of("datos/config.properties");

        // Information
        System.out.println("Exists: " + Files.exists(ruta));
        System.out.println("File: " + Files.isRegularFile(ruta));
        System.out.println("Directory: " + Files.isDirectory(ruta));
        System.out.println("Size: " + (Files.exists(ruta) ? Files.size(ruta) : 0));
        System.out.println("Parent: " + ruta.getParent());
        System.out.println("Name: " + ruta.getFileName());

        // File (old API)
        File archivo = ruta.toFile();
        System.out.println("Absolute path: " + archivo.getAbsolutePath());
    }
}`}
</CodeBlock>

Note: use `\\` to write a backslash in Java: `"C:\\\\Datos\\\\archivo.txt"` or better yet, use `Path.of()` with forward slashes.

## Reading binary files

<CodeBlock lang="java" title="Read bytes from a file">
{`import java.nio.file.*;

public class LeerBinario {
    public static void main(String[] args) {
        try {
            byte[] datos = Files.readAllBytes(Path.of("imagen.jpg"));
            System.out.println("Size: " + datos.length + " bytes");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>
