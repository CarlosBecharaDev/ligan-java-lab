## Indeterminate loops

The while and do-while loops are **indeterminate**: they repeat an *unknown* number of times until a condition becomes false. Unlike the for loop (where you know in advance how many times you'll repeat), these loops are ideal for cases like:

- Reading data until end of file
- Asking for input until it is valid
- Waiting until a condition is met

## The while loop

`while` checks the condition **before** each iteration (pre-test). If the condition is false from the start, the body **never runs**:

```java
while (condicion) {
    // body that repeats while condicion is true
    // must modify something so the condition eventually becomes false
}
```

<CodeBlock lang="java" title="while — countdown">
{`public class CuentaRegresiva {
    public static void main(String[] args) {
        int contador = 5;

        while (contador > 0) {
            System.out.println("Count: " + contador);
            contador--;  // important: modifies the condition
        }

        System.out.println("Liftoff! 🚀");
    }
}`}
</CodeBlock>

**Expected output:**
```
Count: 5
Count: 4
Count: 3
Count: 2
Count: 1
Liftoff! 🚀
```

### while with a false condition from the start

If the condition is false at the beginning, the loop does not run:

```java
int x = 10;
while (x < 5) {
    System.out.println("This is never printed");
}
System.out.println("End");  // prints "End"
```

## The do-while loop

`do-while` checks the condition **after** each iteration (post-test). The body **runs at least once**, regardless of the condition:

```java
do {
    // body (runs at least 1 time)
} while (condicion);  // note the trailing semicolon
```

<CodeBlock lang="java" title="do-while — interactive menu">
{`public class MenuInteractivo {
    public static void main(String[] args) {
        int opcion = 0;

        do {
            System.out.println("\\n--- MENU ---");
            System.out.println("1. View profile");
            System.out.println("2. Settings");
            System.out.println("3. Exit");
            // We simulate that the user chooses 3 in the first iteration
            opcion = 3;
            System.out.println("Chosen option: " + opcion);
        } while (opcion != 3);

        System.out.println("Leaving the menu...");
    }
}`}
</CodeBlock>

**Expected output:**
```
--- MENU ---
1. View profile
2. Settings
3. Exit
Chosen option: 3
Leaving the menu...
```

> 💡 The menu is shown **at least once** even if the user chooses "Exit" immediately. That is the purpose of do-while.

## Key difference: while vs do-while

| Feature | while | do-while |
|----------------|-------|----------|
| Check | Before the body | After the body |
| Minimum executions | 0 | 1 |
| Trailing semicolon | No | Yes |
| Typical use | Conditional processing | Menus, validation |

<CodeBlock lang="java" title="Same value, different check">
{`public class ComparacionBucles {
    public static void main(String[] args) {
        int n = 10;

        // while: does NOT run because 10 < 5 is false at the start
        System.out.println("--- while ---");
        while (n < 5) {
            System.out.println("inside the while");
        }
        System.out.println("while ended without printing");

        // do-while: runs ONCE even though the condition is false
        System.out.println("--- do-while ---");
        do {
            System.out.println("inside the do-while");
        } while (n < 5);
        System.out.println("do-while ended");
    }
}`}
</CodeBlock>

**Expected output:**
```
--- while ---
while ended without printing
--- do-while ---
inside the do-while
do-while ended
```

## Accumulators and counters

A common pattern: use while with an **accumulator** (sums values) and a **counter** (counts iterations):

<CodeBlock lang="java" title="while — sum of numbers until zero (sentinel)">
{`public class SumaSentinela {
    public static void main(String[] args) {
        int[] datos = {5, 8, 3, 0};  // 0 is the sentinel value
        int i = 0;
        int suma = 0;
        int cuenta = 0;

        while (i < datos.length && datos[i] != 0) {
            suma += datos[i];
            cuenta++;
            i++;
        }

        System.out.println("Numbers added: " + cuenta);
        System.out.println("Total: " + suma);
        System.out.println("Average: " + (cuenta > 0 ? (double) suma / cuenta : 0));
    }
}`}
</CodeBlock>

**Expected output:**
```
Numbers added: 3
Total: 16
Average: 5.333333333333333
```

## The danger of the infinite loop

The most common error with while is forgetting to modify the condition variable:

```java
// ❌ Infinite loop: counter never changes
int i = 0;
while (i < 10) {
    System.out.println(i);
    // missing i++ → i is always 0 → endless loop
}

// ✅ Correct: the counter is incremented
int i = 0;
while (i < 10) {
    System.out.println(i);
    i++;
}
```

<CodeBlock lang="java" title="Careful: if the body does not change the condition, it is infinite">
{`public class CuentaRegresivaBug {
    public static void main(String[] args) {
        int x = 5;

        while (x > 0) {
            System.out.println("x = " + x);
            x--;  // without this line it would be infinite
        }
        System.out.println("End");
    }
}`}
</CodeBlock>

## Pattern: validated input with do-while

The most classic use of do-while is asking for input until it is valid:

<CodeBlock lang="java" title="Grade validation with do-while">
{`public class NotaValida {
    public static void main(String[] args) {
        // We simulate user inputs
        int[] entradas = {150, -5, 85};
        int idx = 0;
        int nota;

        do {
            nota = entradas[idx++];  // reads the next input
            if (nota < 0 || nota > 100) {
                System.out.println("Grade " + nota + " invalid. It must be 0-100.");
            }
        } while (nota < 0 || nota > 100);

        System.out.println("Accepted grade: " + nota);
    }
}`}
</CodeBlock>

**Expected output:**
```
Grade 150 invalid. It must be 0-100.
Grade -5 invalid. It must be 0-100.
Accepted grade: 85
```

## When to use while and when for?

| Situation | Recommended loop |
|-----------|-------------------|
| Known number of iterations | ✅ **for** |
| Iterate until end of file or an external condition | ✅ **while** |
| Menu shown at least once | ✅ **do-while** |
| Validate input until it is correct | ✅ **do-while** |
| Process until a sentinel value is found | ✅ **while** |
| Traverse a complete array | ✅ **for** (or **for-each**) |
