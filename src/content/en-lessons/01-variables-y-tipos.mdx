## What is a variable?

A **variable** is a named space in memory that stores a value during the execution of a program. Think of it as a labeled box: the label is the variable name, and what you store inside is the value.

In Java, every variable must be declared with a **specific data type** that cannot change after its declaration. This is called **strong static typing** and is one of the reasons Java is robust and reliable.

## Analogy: the post office

Imagine your computer's RAM as a large post office with lockers of different sizes:

- **Small lockers** (`int`, `boolean`, `char`): They store the value directly inside the locker. These are the **primitive types**.
- **Giant lockers** (`String`, `ArrayList`): They are too large to store the real value. Instead, they contain a note with the address of where the package is. This note is a **reference**.

The small lockers are in the fast zone (**Stack**), and the large packages are in the warehouse (**Heap**).

## The 8 primitive types of Java

Java has exactly 8 primitive types:

| Type | Size | Range / Description | Example |
|------|--------|---------------------|---------|
| `byte` | 8 bits | -128 to 127 | `byte nivel = 5;` |
| `short` | 16 bits | -32,768 to 32,767 | `short año = 2026;` |
| `int` | 32 bits | -2,147M to 2,147M | `int edad = 30;` |
| `long` | 64 bits | Very large | `long poblacion = 8_000_000_000L;` |
| `float` | 32 bits | Decimal (limited precision) | `float temperatura = 36.5f;` |
| `double` | 64 bits | Decimal (high precision) | `double salario = 1500.50;` |
| `char` | 16 bits | A Unicode character | `char genero = 'M';` |
| `boolean` | 1 bit | `true` or `false` | `boolean activo = true;` |

<CodeBlock lang="java" title="The 8 primitive types">
{`public class TiposPrimitivos {
    public static void main(String[] args) {
        byte nivel = 5;
        short año = 2026;
        int edad = 30;
        long poblacion = 8_000_000_000L;
        float temperatura = 36.5f;
        double salario = 1500.50;
        char genero = 'M';
        boolean activo = true;

        System.out.println("Level: " + nivel);
        System.out.println("Year: " + año);
        System.out.println("Age: " + edad);
        System.out.println("Population: " + poblacion);
        System.out.println("Temperature: " + temperatura);
        System.out.println("Salary: " + salario);
        System.out.println("Gender: " + genero);
        System.out.println("Active: " + activo);
    }
}`}
</CodeBlock>

**Expected output:**
```
Level: 5
Year: 2026
Age: 30
Population: 8000000000
Temperature: 36.5
Salary: 1500.5
Gender: M
Active: true
```

## Reference types: String and beyond

**Reference types** are objects that store a memory address (reference) pointing to the real object on the Heap. The most used one is `String`:

<CodeBlock lang="java" title="String and reference types">
{`public class TiposReferencia {
    public static void main(String[] args) {
        String nombre = "Carlos";
        String apellido = "Bechara";
        String nombreCompleto = nombre + " " + apellido;

        System.out.println("Full name: " + nombreCompleto);
        System.out.println("Length: " + nombreCompleto.length());
        System.out.println("In uppercase: " + nombreCompleto.toUpperCase());
    }
}`}
</CodeBlock>

**Expected output:**
```
Full name: Carlos Bechara
Length: 14
In uppercase: CARLOS BECHARA
```

Notice how `String` has methods like `.length()` and `.toUpperCase()` — primitive types have no methods because they are not objects.

## Declaration and initialization

The syntax for declaring a variable follows a clear pattern:

```java
// [Type] [name] = [value];
int edad = 25;
String nombre = "Ana";

// Declaration without a value (later initialization)
double salario;
salario = 1500.50;

// In Java 10+, var infers the type automatically
var precio = 99.99;    // infers double
var mensaje = "Hola";  // infers String
```

## Constants with `final`

When a value must not change during execution, it is declared with `final`. By convention, constants are named in `UPPER_CASE_WITH_UNDERSCORES`:

```java
final double PI = 3.14159;
final int MAX_INTENTOS = 3;
final String PAIS = "México";

// PI = 3.14;  // Compilation error: cannot be reassigned
```

## Common errors

### Error 1: Wrong type in the assignment
```java
// ❌ Error: a double cannot be assigned to an int directly
int precio = 19.99;

// ✅ Fix: use double or explicit casting
double precio = 19.99;
int precioEntero = (int) 19.99;  // result: 19 (loses decimals)
```

### Error 2: Uninitialized local variable
```java
// ❌ Compilation error
int resultado;
System.out.println(resultado);  // variable might not have been initialized

// ✅ Fix: initialize before using
int resultado = 0;
System.out.println(resultado);
```

### Error 3: Confusing `=` with `==`
```java
// = is assignment (stores a value)
int x = 10;

// == is comparison (compares two values)
if (x == 10) {
    System.out.println("x is equal to 10");
}
```
