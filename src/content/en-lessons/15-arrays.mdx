## What is an array?

An array is a **collection of elements of the same type** with a fixed size. Each element is accessed through an **index** that starts at 0.

```
int[] numeros = {10, 20, 30, 40, 50};

Index:    [0]  [1]  [2]  [3]  [4]
Value:    10   20   30   40   50
```

## Declaring and initializing arrays

There are several ways to create arrays in Java:

<CodeBlock lang="java" title="Ways to declare arrays">
{`public class DeclararArrays {
    public static void main(String[] args) {
        // Way 1: with initial values
        int[] edades = {25, 30, 22, 35, 28};

        // Way 2: fixed size, default values (0)
        double[] notas = new double[5];

        // Way 3: size and manual filling
        String[] frutas = new String[3];
        frutas[0] = "Apple";
        frutas[1] = "Pear";
        frutas[2] = "Grape";

        // Way 4: variable size
        int tamanio = 10;
        int[] datos = new int[tamanio];

        System.out.println("Ages: " + edades.length);
        System.out.println("Fruits: " + frutas[0]);
    }
}`}
</CodeBlock>

**Expected output:**
```
Ages: 5
Fruits: Apple
```

## Accessing elements

Use the **index** in square brackets `[]` to read or modify elements:

<CodeBlock lang="java" title="Accessing and modifying elements">
{`public class AccederArrays {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50};

        System.out.println("First: " + nums[0]);   // 10
        System.out.println("Third: " + nums[2]);   // 30
        System.out.println("Last: " + nums[nums.length - 1]); // 50

        // Modify an element
        nums[1] = 25;
        System.out.println("Modified: " + nums[1]); // 25

        // The size is fixed
        System.out.println("Size: " + nums.length); // 5
    }
}`}
</CodeBlock>

**Expected output:**
```
First: 10
Third: 30
Last: 50
Modified: 25
Size: 5
```

**Important:** `.length` does NOT have parentheses — it's a property, not a method.

## Iterating with for

<CodeBlock lang="java" title="Classic for — iterate by index">
{`public class ForClasico {
    public static void main(String[] args) {
        String[] colores = {"Red", "Green", "Blue", "Yellow"};

        for (int i = 0; i < colores.length; i++) {
            System.out.println("[" + i + "] " + colores[i]);
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
[0] Red
[1] Green
[2] Blue
[3] Yellow
```

## Iterating with for-each

<CodeBlock lang="java" title="For-each — iterate over values directly">
{`public class ForEachArray {
    public static void main(String[] args) {
        int[] calificaciones = {85, 92, 78, 95, 88};
        int suma = 0;

        for (int nota : calificaciones) {
            suma += nota;
        }

        double promedio = (double) suma / calificaciones.length;
        System.out.println("Average: " + promedio);
    }
}`}
</CodeBlock>

**Expected output:**
```
Average: 87.6
```

For-each is more readable when **you don't need the index**. If you need to modify the array or know the position, use the classic for loop.

## Default values

When you create an array with `new`, its elements are initialized automatically:

| Type | Default value |
|------|---------------|
| `int`, `long`, `short`, `byte` | `0` |
| `float`, `double` | `0.0` |
| `boolean` | `false` |
| `char` | `' '` |
| `String` (or objects) | `null` |

## Arrays and methods

Arrays can be passed as parameters to methods:

<CodeBlock lang="java" title="Method that processes an array">
{`public class MetodoArray {
    static void imprimirArray(int[] arr) {
        System.out.print("[");
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i]);
            if (i < arr.length - 1) System.out.print(", ");
        }
        System.out.println("]");
    }

    static int sumar(int[] arr) {
        int total = 0;
        for (int n : arr) total += n;
        return total;
    }

    public static void main(String[] args) {
        int[] numeros = {5, 10, 15, 20};
        imprimirArray(numeros);
        System.out.println("Sum: " + sumar(numeros));
    }
}`}
</CodeBlock>

**Expected output:**
```
[5, 10, 15, 20]
Sum: 50
```
