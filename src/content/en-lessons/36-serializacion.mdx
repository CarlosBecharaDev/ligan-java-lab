      class Producto implements Serializable {

          double precio;

              this.nombre = nombre;

          }

      public class CarritoPersistente {
          static void guardarCarrito(ArrayList<Producto> carrito, String ruta) {
              try (ObjectOutputStream oos = new ObjectOutputStream(
                      new FileOutputStream(ruta))) {
                  oos.writeObject(carrito);
                  System.out.println("Carrito guardado: " + carrito.size() + " productos");
              } catch (IOException e) {
                  System.out.println("Error al guardar: " + e.getMessage());
              }
          }

          static ArrayList<Producto> cargarCarrito(String ruta) {
              try (ObjectInputStream ois = new ObjectInputStream(
                      new FileInputStream(ruta))) {
                  @SuppressWarnings("unchecked")
                  ArrayList<Producto> carrito = (ArrayList<Producto>) ois.readObject();
                  return carrito;
              } catch (IOException | ClassNotFoundException e) {
                  return new ArrayList<>();
              }
          }

          public static void main(String[] args) {
              ArrayList<Producto> carrito = new ArrayList<>();
              carrito.add(new Producto("Laptop", 2500.00, 1));
              carrito.add(new Producto("Mouse", 45.00, 2));

              guardarCarrito(carrito, "carrito.dat");
              ArrayList<Producto> cargado = cargarCarrito("carrito.dat");
              System.out.println("Carrito cargado:");
              for (Producto p : cargado) System.out.println("  " + p);
          }
      }

      import java.util.ArrayList;

      class HistoriaClinica implements Serializable {
          private static final long serialVersionUID = 2L;
          String nombre;
          String diagnostico;

              this.nombre = nombre;
              this.diagnostico = diagnostico;
          }

          private void writeObject(ObjectOutputStream oos) throws IOException {
              oos.defaultWriteObject();
          }

          private void readObject(ObjectInputStream ois)
                  throws IOException, ClassNotFoundException {
              ois.defaultReadObject();
              temperaturaActual = 0.0;  // valor por defecto al cargar
          }
      }

                  throws Exception {

              historiales.add(new HistoriaClinica("Ana", "Gripe"));
              historiales.add(new HistoriaClinica("Luis", "Fractura"));
              historiales.get(0).temperaturaActual = 38.5;
              historiales.get(1).temperaturaActual = 36.8;

              try (ObjectOutputStream oos = new ObjectOutputStream(
                      new FileOutputStream("historiales.dat"))) {
                  oos.writeObject(historiales);
              }

                  @SuppressWarnings("unchecked")

## What is serialization?

It is the process of converting a **whole object** (with all its fields) into a byte array to save it to disk or send it over the network. Deserialization does the reverse: bytes → object.

```java
// Save an object to disk
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("objeto.dat"));
oos.writeObject(miObjeto);
oos.close();

// Read it back
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("objeto.dat"));
MiClase obj = (MiClase) ois.readObject();
ois.close();
```

## Creating a serializable class

<CodeBlock lang="java" title="Implementing Serializable is simple">
{`import java.io.Serializable;

class Persona implements Serializable {
    private static final long serialVersionUID = 1L;

    String nombre;
    int edad;
    double altura;

    Persona(String nombre, int edad, double altura) {
        this.nombre = nombre;
        this.edad = edad;
        this.altura = altura;
    }

    public String toString() {
        return nombre + ", " + edad + " years, " + altura + " m";
    }
}`}
</CodeBlock>

You only need to implement the `Serializable` interface — it has no methods to implement (it is a marker interface).

## Saving and reading objects

<CodeBlock lang="java" title="ObjectOutputStream and ObjectInputStream">
{`import java.io.*;

public class GuardarPersonas {
    public static void main(String[] args)
            throws Exception {
        // --- Save objects ---
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("personas.dat"))) {
            oos.writeObject(new Persona("Ana", 25, 1.65));
            oos.writeObject(new Persona("Luis", 30, 1.80));
            oos.writeObject(new Persona("María", 35, 1.70));
            System.out.println("Objects saved");
        }

        // --- Read objects ---
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("personas.dat"))) {
            for (int i = 0; i < 3; i++) {
                Persona p = (Persona) ois.readObject();
                System.out.println("Read: " + p);
            }
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Objects saved
Read: Ana, 25 years, 1.65 m
Read: Luis, 30 years, 1.8 m
Read: María, 35 years, 1.7 m
```

## transient — fields that are not saved

<CodeBlock lang="java" title="Exclude fields with transient">
{`import java.io.Serializable;

class Sesion implements Serializable {
    private static final long serialVersionUID = 1L;

    String usuario;
    transient String tokenSeguridad;  // NOT saved to disk
    transient long horaExpiracion;     // NOT saved

    Sesion(String usuario, String token) {
        this.usuario = usuario;
        this.tokenSeguridad = token;
        this.horaExpiracion = System.currentTimeMillis() + 3600000;
    }

    public String toString() {
        return usuario + " (token: " + tokenSeguridad + ")";
    }
}`}
</CodeBlock>

## serialVersionUID — version control

```java
class MiClase implements Serializable {
    // If you change the class, change this number
    private static final long serialVersionUID = 1L;
    // ...
}
```

**If you do NOT declare serialVersionUID:**
- Java generates one automatically based on the class structure
- If you change any field, the UID changes and deserialization fails
- **Always** declare serialVersionUID explicitly
