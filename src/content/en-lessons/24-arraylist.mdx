## What Is an ArrayList?

An **ArrayList** is a collection that works like an array but with **dynamic size**: it grows and shrinks automatically when you add or remove elements. It is part of the **Java Collections Framework** since Java 1.2.

```java
import java.util.ArrayList;

ArrayList<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Luis");
System.out.println(nombres);  // [Ana, Luis]
```

**Important:** You must import `java.util.ArrayList` before using it.

## Creating an ArrayList

```java
import java.util.ArrayList;

// List of Strings
ArrayList<String> frutas = new ArrayList<>();

// List of integers (uses Integer, not int)
ArrayList<Integer> numeros = new ArrayList<>();

// List of decimals
ArrayList<Double> precios = new ArrayList<>();

// Empty list with initial capacity
ArrayList<String> lista = new ArrayList<>(100);
```

## Adding and Removing Elements

| Method | Description | Example |
|--------|-------------|---------|
| `add(element)` | Adds at the end | `list.add("A")` |
| `add(index, element)` | Adds at a position | `list.add(0, "A")` |
| `remove(element)` | Removes the first occurrence | `list.remove("A")` |
| `remove(index)` | Removes by index | `list.remove(0)` |
| `set(index, element)` | Replaces at a position | `list.set(0, "B")` |

<CodeBlock lang="java" title="Add, remove and modify">
{`import java.util.ArrayList;

public class ModificarLista {
    public static void main(String[] args) {
        ArrayList<String> colores = new ArrayList<>();
        colores.add("Red");
        colores.add("Green");
        colores.add("Blue");
        System.out.println("Start: " + colores);

        // Add at a specific position
        colores.add(1, "Yellow");
        System.out.println("Insert: " + colores);

        // Modify an element
        colores.set(2, "Orange");
        System.out.println("Modify: " + colores);

        // Remove by index
        colores.remove(0);
        System.out.println("Remove first: " + colores);

        // Remove by value
        colores.remove("Blue");
        System.out.println("Remove Blue: " + colores);
    }
}`}
</CodeBlock>

**Expected output:**
```
Start: [Red, Green, Blue]
Insert: [Red, Yellow, Green, Blue]
Modify: [Red, Yellow, Orange, Blue]
Remove first: [Yellow, Orange, Blue]
Remove Blue: [Yellow, Orange]
```

## Iterating over an ArrayList

<CodeBlock lang="java" title="Three ways to traverse an ArrayList">
{`import java.util.ArrayList;

public class IterarArrayList {
    public static void main(String[] args) {
        ArrayList<String> frutas = new ArrayList<>();
        frutas.add("Apple");
        frutas.add("Pear");
        frutas.add("Grape");
        frutas.add("Orange");

        // Way 1: classic for (with index)
        System.out.println("--- classic for ---");
        for (int i = 0; i < frutas.size(); i++) {
            System.out.println(i + ": " + frutas.get(i));
        }

        // Way 2: for-each (without index)
        System.out.println("--- for-each ---");
        for (String fruta : frutas) {
            System.out.println(fruta);
        }

        // Way 3: forEach with lambda (Java 8+)
        System.out.println("--- forEach lambda ---");
        frutas.forEach(f -> System.out.println(f));
    }
}`}
</CodeBlock>

## ArrayList and Primitive Types

ArrayList does not accept primitives directly. Use the **wrapper classes**:

| Primitive | Wrapper | ArrayList |
|-----------|---------|-----------|
| `int` | `Integer` | `ArrayList<Integer>` |
| `double` | `Double` | `ArrayList<Double>` |
| `boolean` | `Boolean` | `ArrayList<Boolean>` |
| `char` | `Character` | `ArrayList<Character>` |

```java
ArrayList<Integer> numeros = new ArrayList<>();
numeros.add(10);     // Autoboxing: int → Integer
int valor = numeros.get(0);  // Unboxing: Integer → int
```

## Converting between Arrays and ArrayList

<CodeBlock lang="java" title="Array ↔ ArrayList">
{`import java.util.ArrayList;
import java.util.Arrays;

public class ConvertirArrays {
    public static void main(String[] args) {
        // Array → ArrayList
        String[] arrayFrutas = {"Apple", "Pear", "Grape"};
        ArrayList<String> listaFrutas = new ArrayList<>(
            Arrays.asList(arrayFrutas)
        );
        System.out.println("List: " + listaFrutas);

        // ArrayList → Array
        String[] nuevoArray = listaFrutas.toArray(new String[0]);
        System.out.println("Array: " + Arrays.toString(nuevoArray));

        // Using var (Java 10+)
        var listaNumeros = new ArrayList<>(Arrays.asList(1, 2, 3));
        System.out.println("var: " + listaNumeros);
    }
}`}
</CodeBlock>

**Expected output:**
```
List: [Apple, Pear, Grape]
Array: [Apple, Pear, Grape]
var: [1, 2, 3]
```
