## What Is a HashMap?

A **HashMap** stores **key-value** pairs. Each key is unique and allows accessing its value in near-constant time O(1). It is like a dictionary: you search by word (key) and get the definition (value).

```java
import java.util.HashMap;

HashMap<String, Integer> edades = new HashMap<>();
edades.put("Ana", 25);
edades.put("Luis", 30);
System.out.println(edades.get("Ana"));  // 25
```

## Creating and Using a HashMap

<CodeBlock lang="java" title="Create HashMap and basic operations">
{`import java.util.HashMap;

public class CrearHashMap {
    public static void main(String[] args) {
        HashMap<String, Double> calificaciones = new HashMap<>();

        // put: add or update
        calificaciones.put("Math", 9.5);
        calificaciones.put("Spanish", 8.0);
        calificaciones.put("Science", 9.2);
        System.out.println("Grades: " + calificaciones);

        // get: get value by key
        double notaMate = calificaciones.get("Math");
        System.out.println("Math grade: " + notaMate);

        // Update value
        calificaciones.put("Spanish", 8.5);
        System.out.println("Spanish updated: " + calificaciones.get("Spanish"));

        // size: number of pairs
        System.out.println("Total subjects: " + calificaciones.size());
    }
}`}
</CodeBlock>

**Expected output:**
```
Grades: {Math=9.5, Spanish=8.0, Science=9.2}
Math grade: 9.5
Spanish updated: 8.5
Total subjects: 3
```

## Important Methods

| Method | Description | Returns |
|--------|-------------|---------|
| `put(key, value)` | Adds or updates | previous value (or null) |
| `get(key)` | Gets the value | value or null |
| `getOrDefault(key, defaultValue)` | Gets or uses the default | value or default |
| `remove(key)` | Removes the pair | removed value |
| `containsKey(key)` | Does the key exist? | boolean |
| `containsValue(value)` | Does the value exist? | boolean |
| `size()` | Number of pairs | int |

<CodeBlock lang="java" title="Useful HashMap methods">
{`import java.util.HashMap;

public class MetodosHashMap {
    public static void main(String[] args) {
        HashMap<String, Integer> inventario = new HashMap<>();
        inventario.put("Apples", 50);
        inventario.put("Pears", 30);

        // getOrDefault: if it does not exist, returns the default value
        int uvas = inventario.getOrDefault("Grapes", 0);
        System.out.println("Grapes: " + uvas);  // 0

        // putIfAbsent: only adds if it does not exist
        inventario.putIfAbsent("Apples", 100);  // does not change
        inventario.putIfAbsent("Grapes", 25);   // adds
        System.out.println("After putIfAbsent: " + inventario);

        // containsKey / containsValue
        System.out.println("Has Pears?: " + inventario.containsKey("Pears"));
        System.out.println("Has 50?: " + inventario.containsValue(50));

        // remove
        inventario.remove("Pears");
        System.out.println("Without Pears: " + inventario);
    }
}`}
</CodeBlock>

**Expected output:**
```
Grapes: 0
After putIfAbsent: {Apples=50, Grapes=25}
Has Pears?: true
Has 50?: true
Without Pears: {Apples=50, Grapes=25}
```

## Iterating over a HashMap

<CodeBlock lang="java" title="Three ways to traverse a HashMap">
{`import java.util.HashMap;
import java.util.Map;

public class IterarHashMap {
    public static void main(String[] args) {
        HashMap<String, String> capitales = new HashMap<>();
        capitales.put("Colombia", "Bogotá");
        capitales.put("México", "Ciudad de México");
        capitales.put("Argentina", "Buenos Aires");

        // Way 1: entrySet (key + value)
        System.out.println("--- entrySet ---");
        for (Map.Entry<String, String> entry : capitales.entrySet()) {
            System.out.println(entry.getKey() + " → " + entry.getValue());
        }

        // Way 2: keySet (only keys)
        System.out.println("--- keySet ---");
        for (String pais : capitales.keySet()) {
            System.out.println(pais);
        }

        // Way 3: values (only values)
        System.out.println("--- values ---");
        for (String capital : capitales.values()) {
            System.out.println(capital);
        }

        // Way 4: forEach with lambda (Java 8+)
        System.out.println("--- forEach ---");
        capitales.forEach((pais, capital) ->
            System.out.println(pais + " → " + capital));
    }
}`}
</CodeBlock>

**Expected output:**
```
--- entrySet ---
Colombia → Bogotá
México → Ciudad de México
Argentina → Buenos Aires
--- keySet ---
Colombia
México
Argentina
--- values ---
Bogotá
Ciudad de México
Buenos Aires
--- forEach ---
Colombia → Bogotá
México → Ciudad de México
Argentina → Buenos Aires
```

## HashMap with Objects as Values

<CodeBlock lang="java" title="HashMap with complex values">
{`import java.util.HashMap;

public class HashMapObjetos {
    public static void main(String[] args) {
        HashMap<String, double[]> notas = new HashMap<>();

        notas.put("Ana", new double[]{9.0, 8.5, 9.2});
        notas.put("Luis", new double[]{7.5, 8.0, 7.8});
        notas.put("María", new double[]{9.5, 9.0, 9.8});

        for (String nombre : notas.keySet()) {
            double[] exámenes = notas.get(nombre);
            double promedio = 0;
            for (double nota : exámenes) promedio += nota;
            promedio /= exámenes.length;
            System.out.printf("%s: average %.1f%n",
                nombre, promedio);
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Ana: average 8.9
Luis: average 7.8
María: average 9.4
```
