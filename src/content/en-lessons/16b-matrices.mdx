## What is a matrix?

A **matrix** (two-dimensional array) is a data structure that organizes elements into rows and columns. In Java, a matrix is simply an "array of arrays": each element of the matrix is another array.

Imagine an **Excel spreadsheet**: you need a row and a column to access a cell. In Java, that is written `matriz[row][column]`.

## Declaration and initialization

```java
// Full syntax: 3 rows, 4 columns
int[][] matriz = new int[3][4];

// Simplified syntax with values
int[][] tabla = {
    {100, 200, 300},
    {400, 500, 600}
};

// Jagged matrix (each row with a different size)
int[][] irregular = new int[3][];
irregular[0] = new int[2];
irregular[1] = new int[4];
irregular[2] = new int[3];
```

## lengths: rows vs columns

```java
int[][] m = {
    {100, 200, 300},
    {400, 500, 600}
};

System.out.println(m.length);      // 2 (rows)
System.out.println(m[0].length);   // 3 (columns of row 0)
System.out.println(m[1].length);   // 3 (columns of row 1)
```

## Traversing a matrix with nested loops

<CodeBlock lang="java" title="Traverse a matrix with nested for loops">
{`public class RecorrerMatriz {
    public static void main(String[] args) {
        int[][] matriz = {
            {100, 200, 300},
            {400, 500, 600}
        };

        for (int ren = 0; ren < matriz.length; ren++) {
            for (int col = 0; col < matriz[ren].length; col++) {
                System.out.printf("[%d][%d] = %d%n", ren, col, matriz[ren][col]);
            }
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
[0][0] = 100
[0][1] = 200
[0][2] = 300
[1][0] = 400
[1][1] = 500
[1][2] = 600
```

### Traversal order

```
2x3 matrix: [0][0] → [0][1] → [0][2] → (row moves to 1) → [1][0] → [1][1] → [1][2] → end
```

- **Outer loop** (`row`): iterates over rows
- **Inner loop** (`col`): iterates over the columns of the current row

## How it lives in memory

```
STACK                    HEAP (array of arrays)
┌─────────────┐
│ matriz ──────┼──► [ ref0 | ref1 ]
└─────────────┘       │       │
                      ▼       ▼
               [100|200|300] [400|500|600]
```

The `matriz` variable on the Stack holds a reference to an array that contains two references, each pointing to an array of integers on the Heap.

## Square matrix and main diagonal

A **square matrix** has the same number of rows and columns (`n x n`). The **main diagonal** is the cells where the row index equals the column index.

```java
int[][] m = {
    {100, 200, 300},
    {400, 500, 600},
    {700, 800, 900}
};
// Diagonal: [0][0]=100, [1][1]=500, [2][2]=900
```

<CodeBlock lang="java" title="Sum of the main diagonal">
{`public class SumaDiagonal {
    public static void main(String[] args) {
        int[][] m = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int suma = 0;
        for (int i = 0; i < m.length; i++) {
            suma += m[i][i];
        }
        System.out.println("Diagonal sum: " + suma);
    }
}`}
</CodeBlock>

**Expected output:**
```
Diagonal sum: 15
```

## Common errors

### Error 1: Swapping the indexes
```java
// ❌ Error: first index is row, second is column
matriz[col][ren] = 10;

// ✅ Correct
matriz[ren][col] = 10;
```

### Error 2: Using matriz.length for columns
```java
// ❌ Error: matriz.length gives the number of rows
for (int col = 0; col < matriz.length; col++)

// ✅ Correct: matriz[0].length gives the columns
for (int col = 0; col < matriz[0].length; col++)
```

### Error 3: Printing the matrix directly
```java
// ❌ Prints the memory address: [[I@1540e19d
System.out.println(matriz);

// ✅ Use Arrays.deepToString()
System.out.println(Arrays.deepToString(matriz));
```

## Best practices

1. **Name clearly** the variables that represent rows and columns: `for (int row = 0; row < matriz.length; row++)`
2. **Use `matriz[i].length`** in the inner loop, not a fixed number
3. **`Arrays.deepToString(matriz)`** for quick debugging
4. **`List<List<T>>`** when the size of the matrix may change dynamically
