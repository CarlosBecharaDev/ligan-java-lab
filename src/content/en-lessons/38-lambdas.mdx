## What is a lambda expression?

A **lambda** is an anonymous function that you can treat as a value. It is a concise way to implement functional interfaces (interfaces with a single method).

```java
// Basic syntax
(parametros) -> { cuerpo }

// Example: comparator
Comparator<String> c = (a, b) -> a.length() - b.length();
```

## Lambda syntax

<CodeBlock lang="java" title="Different ways to write a lambda">
{`import java.util.function.*;

public class SintaxisLambda {
    public static void main(String[] args) {
        // Form 1: no parameters
        Supplier<String> saludar = () -> "Hello World";
        System.out.println(saludar.get());

        // Form 2: one parameter (no parentheses)
        Function<String, Integer> longitud = s -> s.length();
        System.out.println("Length: " + longitud.apply("Java"));

        // Form 3: two parameters (with parentheses)
        BiFunction<Integer, Integer, Integer> suma = (a, b) -> a + b;
        System.out.println("Sum: " + suma.apply(5, 3));

        // Form 4: multiple lines (with braces and return)
        Predicate<Integer> esPar = n -> {
            System.out.println("Testing: " + n);
            return n % 2 == 0;
        };
        System.out.println("Is it even? " + esPar.test(7));
    }
}`}
</CodeBlock>

## Main functional interfaces

```java
// Evaluates a condition → returns boolean
Predicate<T>       → boolean test(T t)

// Transforms a value → returns another
Function<T, R>     → R apply(T t)

// Takes a value → returns nothing
Consumer<T>        → void accept(T t)

// Generates a value → takes no parameters
Supplier<T>        → T get()

// Compares two values → returns int
Comparator<T>      → int compare(T a, T b)
```

<CodeBlock lang="java" title="Using the functional interfaces">
{`import java.util.*;
import java.util.function.*;

public class InterfacesFuncionales {
    public static void main(String[] args) {
        List<String> nombres = Arrays.asList("Ana", "Luis", "María", "Carlos");

        // Consumer — print
        Consumer<String> imprimir = nombre -> System.out.println("Hello " + nombre);
        nombres.forEach(imprimir);

        // Predicate — filter
        Predicate<String> masDe3 = s -> s.length() > 3;
        System.out.println("Names with > 3 letters:");
        nombres.stream()
               .filter(masDe3)
               .forEach(System.out::println);

        // Function — transform
        Function<String, String> aMayusculas = s -> s.toUpperCase();
        List<String> mayusculas = new ArrayList<>();
        for (String n : nombres) {
            mayusculas.add(aMayusculas.apply(n));
        }
        System.out.println("Uppercase: " + mayusculas);
    }
}`}
</CodeBlock>

## Method References

A shortcut when the lambda only calls an existing method:

```java
// Lambda
list.forEach(s -> System.out.println(s));

// Method Reference (equivalent)
list.forEach(System.out::println);

// Lambda
list.sort((a, b) -> a.compareToIgnoreCase(b));

// Method Reference
list.sort(String::compareToIgnoreCase);
```

<CodeBlock lang="java" title="Method References in action">
{`import java.util.*;

public class MethodRefs {
    public static void main(String[] args) {
        List<String> ciudades = Arrays.asList(
            "Bogotá", "Medellín", "Cali", "Barranquilla");

        // Lambda
        ciudades.forEach(c -> System.out.print(c + " "));
        System.out.println();

        // Method Reference: System.out::println
        ciudades.forEach(System.out::println);

        // Static method reference
        ciudades.sort(String::compareToIgnoreCase);
        System.out.println("Sorted: " + ciudades);

        // Instance method reference
        ciudades.forEach(System.out::print);
    }
}`}
</CodeBlock>

## Lambdas vs anonymous classes

| Aspect | Anonymous class | Lambda |
|--------|-----------------|--------|
| Code | `new X() { method() { ... } }` | `() -> ...` |
| `this` | Points to the anonymous class | Points to the enclosing class |
| Variables | Can modify fields | Must be effectively final |
| Ideal for | Multiple methods | A single method (functional) |
