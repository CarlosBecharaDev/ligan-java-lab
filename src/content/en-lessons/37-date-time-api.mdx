## The java.time API

The modern date and time API in Java lives in the `java.time` package. It is **immutable**, **fluent**, and **thread-safe**.

```java
import java.time.*;

// Main classes
LocalDate fecha = LocalDate.now();           // 2026-07-27
LocalTime hora = LocalTime.now();            // 14:30:00
LocalDateTime fechaHora = LocalDateTime.now(); // 2026-07-27T14:30:00
```

## LocalDate — date without time

<CodeBlock lang="java" title="LocalDate operations">
{`import java.time.*;
import java.time.format.DateTimeFormatter;

public class LocalDateDemo {
    public static void main(String[] args) {
        // Create dates
        LocalDate hoy = LocalDate.now();
        LocalDate navidad = LocalDate.of(2026, 12, 25);
        LocalDate parseada = LocalDate.parse("2026-07-27");

        System.out.println("Today: " + hoy);
        System.out.println("Christmas: " + navidad);
        System.out.println("Parsed: " + parseada);

        // Access fields
        System.out.println("Year: " + hoy.getYear());
        System.out.println("Month: " + hoy.getMonth());
        System.out.println("Day: " + hoy.getDayOfMonth());
        System.out.println("Day of week: " + hoy.getDayOfWeek());

        // Add/subtract
        System.out.println("Tomorrow: " + hoy.plusDays(1));
        System.out.println("Next month: " + hoy.plusMonths(1));
        System.out.println("Yesterday: " + hoy.minusDays(1));
        System.out.println("Leap year?: " + hoy.isLeapYear());
    }
}`}
</CodeBlock>

```

Christmas: 2026-12-25
Parsed: 2026-07-27
Year: 2026
Month: JULY
Day: 27
Day of week: MONDAY
Tomorrow: 2026-07-28
Next month: 2026-08-27
Yesterday: 2026-07-26
Leap year?: false
```

## LocalTime and LocalDateTime

<CodeBlock lang="java" title="Working with times and combined dates">
{`import java.time.*;

public class TimeDemo {
    public static void main(String[] args) {
        // LocalTime — time only
        LocalTime ahora = LocalTime.now();
        System.out.println("Now: " + ahora);

        LocalTime reunion = LocalTime.of(15, 30);
        System.out.println("Meeting: " + reunion);
        System.out.println("Is it after?: " + ahora.isAfter(reunion));
        System.out.println("In 2 hours: " + ahora.plusHours(2));

        // LocalDateTime — date and time combined
        LocalDateTime cita = LocalDateTime.of(2026, 7, 27, 10, 30);
        System.out.println("Appointment: " + cita);
        System.out.println("Appointment + 3 days: " + cita.plusDays(3));
    }
}`}
</CodeBlock>

## Period and Duration — calculating differences

<CodeBlock lang="java" title="Period (dates) and Duration (time)">
{`import java.time.*;

public class PeriodDurationDemo {
    public static void main(String[] args) {
        // Period — between dates
        LocalDate inicio = LocalDate.of(2026, 1, 1);
        LocalDate fin = LocalDate.of(2026, 12, 31);
        Period periodo = Period.between(inicio, fin);
        System.out.printf("Period: %d years, %d months, %d days%n",
            periodo.getYears(),
            periodo.getMonths(),
            periodo.getDays());

        // Duration — between times
        LocalTime apertura = LocalTime.of(8, 0);
        LocalTime cierre = LocalTime.of(18, 0);
        Duration duracion = Duration.between(apertura, cierre);
        System.out.println("Working hours: " + duracion.toHours());
        System.out.println("Minutes: " + duracion.toMinutes());
    }
}`}
</CodeBlock>

**Expected output:**
```
Period: 0 years, 11 months, 30 days
Working hours: 10
Minutes: 600
```
