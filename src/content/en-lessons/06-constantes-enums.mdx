## Constants with `final`

A **constant** is a variable whose value cannot change after initialization. In Java, they are declared with `final`. By convention, constant names are written in `UPPERCASE_WITH_UNDERSCORES`.

### Local constants

Inside a method, you can declare local constants:

```java
public void metodo() {
    final double IVU = 0.16;
    final int MAX_USUARIOS = 100;

    // IVU = 0.18;    // ❌ Error: cannot be reassigned
}
```

### Class constants (static final)

For constants accessible from the entire application, use `public static final`:

```java
public class Constantes {
    public static final double PI = 3.14159265359;
    public static final int DIAS_SEMANA = 7;
    public static final String NOMBRE_APP = "Ligan Java Lab";
}
```

Then they are accessed with `Constantes.PI`, `Constantes.DIAS_SEMANA`, etc.

### Instance constants (final without static)

If each instance of a class has a fixed value that does not change:

```java
public class TarjetaCredito {
    private final String numeroTarjeta;   // fixed per instance
    private final String titular;

    public TarjetaCredito(String numero, String titular) {
        this.numeroTarjeta = numero;      // assigned once
        this.titular = titular;
    }
}
```

<CodeBlock lang="java" title="Constants in Java">
{`public class EjemploConstantes {
    // Class constants
    public static final String APP = "MiApp";
    public static final int MAX_CONEXIONES = 10;
    public static final double INTERES_ANUAL = 0.045;

    // Instance constant
    private final String nombreUsuario;

    public EjemploConstantes(String nombreUsuario) {
        this.nombreUsuario = nombreUsuario;
    }

    public void mostrarInfo() {
        final double DESCUENTO = 0.15;  // local constant

        System.out.println("App: " + APP);
        System.out.println("User: " + nombreUsuario);
        System.out.println("Annual interest: " + (INTERES_ANUAL * 100) + "%");
        System.out.println("Today's discount: " + (DESCUENTO * 100) + "%");
    }

    public static void main(String[] args) {
        EjemploConstantes ej = new EjemploConstantes("Carlos");
        ej.mostrarInfo();
    }
}`}
</CodeBlock>

**Expected output:**
```
App: MiApp
User: Carlos
Annual interest: 4.5%
Today's discount: 15.0%
```

## Introduction to Enums

An **enum** (enumeration) is a data type that defines a fixed set of related constants. It is the correct way to represent closed groups such as days of the week, order statuses, or user roles.

```java
public enum DiaSemana {
    LUNES, MARTES, MIERCOLES, JUEVES, VIERNES, SABADO, DOMINGO
}
```

### Using a basic enum

<CodeBlock lang="java" title="Basic enum">
{`public enum DiaSemana {
    LUNES, MARTES, MIERCOLES, JUEVES, VIERNES, SABADO, DOMINGO
}

public class UsarEnum {
    public static void main(String[] args) {
        DiaSemana hoy = DiaSemana.MIERCOLES;

        System.out.println("Today is: " + hoy);
        System.out.println("Ordinal: " + hoy.ordinal());
        System.out.println("Name: " + hoy.name());

        // Iterate over all values
        System.out.println("\\nAll days:");
        for (DiaSemana dia : DiaSemana.values()) {
            System.out.println("  " + dia.ordinal() + " = " + dia);
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Today is: MIERCOLES
Ordinal: 2
Name: MIERCOLES

All days:
  0 = LUNES
  1 = MARTES
  2 = MIERCOLES
  3 = JUEVES
  4 = VIERNES
  5 = SABADO
  6 = DOMINGO
```

### Enums with switch

<CodeBlock lang="java" title="Enum with switch">
{`public enum DiaSemana {
    LUNES, MARTES, MIERCOLES, JUEVES, VIERNES, SABADO, DOMINGO
}

public class EnumSwitch {
    public static void main(String[] args) {
        DiaSemana dia = DiaSemana.VIERNES;

        // Traditional switch
        switch (dia) {
            case LUNES:
                System.out.println("Start of the week");
                break;
            case SABADO:
            case DOMINGO:
                System.out.println("Weekend!");
                break;
            default:
                System.out.println("Workday");
        }

        // Switch expression (Java 14+) — no break, more concise
        String tipoDia = switch (dia) {
            case LUNES -> "Start of the week";
            case MARTES, MIERCOLES, JUEVES -> "Workday";
            case VIERNES -> "Pre-weekend day";
            case SABADO, DOMINGO -> "Weekend!";
        };
        System.out.println("Day type: " + tipoDia);
    }
}`}
</CodeBlock>

**Expected output:**
```
Pre-weekend day
Day type: Pre-weekend day
```

## Enums with properties and methods

Enums in Java are full classes. They can have:

- **Fields** (usually final so they are immutable)
- **Private constructor** (cannot be instantiated from outside)
- **Methods** to obtain additional information

<CodeBlock lang="java" title="Enums with properties and methods">
{`public enum NivelAcceso {
    INVITADO(0, "No access"),
    LECTOR(1, "Read only"),
    EDITOR(2, "Read and write"),
    ADMIN(3, "Full access");

    private final int prioridad;
    private final String descripcion;

    // Constructor — always private in an enum
    NivelAcceso(int prioridad, String descripcion) {
        this.prioridad = prioridad;
        this.descripcion = descripcion;
    }

    public int getPrioridad() { return prioridad; }
    public String getDescripcion() { return descripcion; }

    public boolean puedeEditar() {
        return this == EDITOR || this == ADMIN;
    }

    public boolean puedeAdministrar() {
        return this == ADMIN;
    }

    // Static method to look up by priority
    public static NivelAcceso desdePrioridad(int prioridad) {
        for (NivelAcceso nivel : values()) {
            if (nivel.prioridad == prioridad) {
                return nivel;
            }
        }
        return INVITADO;
    }
}

public class DemoNivel {
    public static void main(String[] args) {
        NivelAcceso nivel = NivelAcceso.EDITOR;

        System.out.println("Level: " + nivel);
        System.out.println("Priority: " + nivel.getPrioridad());
        System.out.println("Description: " + nivel.getDescripcion());
        System.out.println("Can edit: " + nivel.puedeEditar());
        System.out.println("Can administer: " + nivel.puedeAdministrar());

        // Look up by priority
        NivelAcceso buscado = NivelAcceso.desdePrioridad(3);
        System.out.println("Priority 3: " + buscado);
    }
}`}
</CodeBlock>

**Expected output:**
```
Level: EDITOR
Priority: 2
Description: Read and write
Can edit: true
Can administer: false
Priority 3: ADMIN
```

## Useful Enum methods

Every enum automatically inherits from `java.lang.Enum`, which provides:

| Method | Description | Example |
|--------|-------------|---------|
| `name()` | The exact name of the constant | `Nivel.ADMIN.name()` → `"ADMIN"` |
| `ordinal()` | Position (0-based) | `Nivel.ADMIN.ordinal()` → `3` |
| `values()` | All constants as an array | `Nivel.values()` → `[INVITADO, LECTOR, EDITOR, ADMIN]` |
| `valueOf(str)` | Constant from a String | `Nivel.valueOf("ADMIN")` → `Nivel.ADMIN` |

<CodeBlock lang="java" title="Methods inherited from Enum">
{`public class MetodosEnum {
    public static void main(String[] args) {
        // valueOf: convert String to enum
        NivelAcceso nivel = NivelAcceso.valueOf("LECTOR");
        System.out.println("valueOf('LECTOR'): " + nivel);

        // name(): get the exact name
        String nombre = NivelAcceso.ADMIN.name();
        System.out.println("ADMIN.name(): '" + nombre + "'");

        // ordinal(): 0-based position
        System.out.println("INVITADO.ordinal(): " + NivelAcceso.INVITADO.ordinal());
        System.out.println("ADMIN.ordinal(): " + NivelAcceso.ADMIN.ordinal());

        // values(): iterate over all constants
        System.out.println("\\nAll levels:");
        for (NivelAcceso n : NivelAcceso.values()) {
            System.out.printf("  %d. %s%n", n.ordinal(), n.name());
        }
    }
}`}
</CodeBlock>

## Common mistakes

### Mistake 1: Declaring constants without final
```java
// ❌ This is not a constant — it can be modified
double IVU = 0.16;

// ✅ Real constant
public static final double IVU = 0.16;
```

### Mistake 2: Not following the naming convention
```java
// ❌ Constants must be in UPPERCASE
public static final double maximo = 100;

// ✅ Standard convention
public static final double MAXIMO = 100;
```

### Mistake 3: Using `ordinal()` in business logic
```java
// ❌ If the enum order changes, the code breaks
if (nivel.ordinal() >= 2) { puedeEditar = true; }

// ✅ Use an explicit priority field
if (nivel.getPrioridad() >= 2) { puedeEditar = true; }
```

### Mistake 4: Enums outside their own file
```java
// ❌ A public enum needs its own file
public class Ejemplo {
    public enum Color { ROJO, VERDE, AZUL }  // No!
}

// ✅ Each public enum in its own .java file
// Color.java
public enum Color { ROJO, VERDE, AZUL }
```
