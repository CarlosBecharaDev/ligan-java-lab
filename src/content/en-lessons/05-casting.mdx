## What is casting?

**Casting** (type conversion) is the process of transforming a value from one data type to another. In Java, there are two forms of conversion:

1. **Widening (implicit / automatic):** From a small type to a larger one. Java does it on its own.
2. **Narrowing (explicit / manual):** From a large type to a smaller one. You must indicate it with `(type)`.

```java
int numero = 100;

// Widening: int → double (automatic, safe)
double decimal = numero;

// Narrowing: double → int (explicit, may lose data)
int entero = (int) decimal;
```

## Hierarchy of primitive types

```
byte → short → int → long → float → double
         ↑
        char
```

- **→** indicates the widening direction (safe, automatic)
- **←** indicates the narrowing direction (requires explicit casting)

## Widening: implicit conversion

Java converts automatically when the target type is **larger** or **more precise**:

<CodeBlock lang="java" title="Automatic widening">
{`public class Widening {
    public static void main(String[] args) {
        // These are all widening — no casting required
        byte b = 50;
        short s = b;      // byte → short (OK)
        int i = s;        // short → int (OK)
        long l = i;       // int → long (OK)
        float f = l;      // long → float (OK, possible precision loss)
        double d = f;     // float → double (OK)

        // char to int (char is numeric internally)
        char c = 'A';
        int valorUnicode = c;  // 65 (Unicode for 'A')

        System.out.println("byte: " + b);
        System.out.println("short: " + s);
        System.out.println("int: " + i);
        System.out.println("long: " + l);
        System.out.println("float: " + f);
        System.out.println("double: " + d);
        System.out.println("char 'A' as int: " + valorUnicode);
    }
}`}
</CodeBlock>

**Expected output:**
```
byte: 50
short: 50
int: 50
long: 50
float: 50.0
double: 50.0
char 'A' as int: 65
```

## Narrowing: explicit casting

When you convert from a larger type to a smaller one, you must do explicit casting. **It may lose data:**

<CodeBlock lang="java" title="Narrowing with data loss">
{`public class Narrowing {
    public static void main(String[] args) {
        double grande = 123.456;

        // double → int: truncates the decimals
        int truncado = (int) grande;
        System.out.println("original double: " + grande);
        System.out.println("(int) double: " + truncado);  // 123

        // int → byte: out-of-range value
        int desbordado = 128;
        byte muyPequeno = (byte) desbordado;
        System.out.println("int 128 → byte: " + muyPequeno);  // -128

        // long → int: truncates upper bits
        long largo = 3_000_000_000L;
        int truncadoLong = (int) largo;
        System.out.println("long 3B → int: " + truncadoLong);  // -1294967296

        // double → float: loses precision
        double precisa = 3.14159265358979;
        float menosPrecisa = (float) precisa;
        System.out.println("double: " + precisa);
        System.out.println("float: " + menosPrecisa);  // 3.1415927
    }
}`}
</CodeBlock>

**Expected output:**
```
original double: 123.456
(int) double: 123
int 128 → byte: -128
long 3B → int: -1294967296
double: 3.14159265358979
float: 3.1415927
```

## Arithmetic promotion

When you perform operations with mixed types, Java **promotes** the smaller types automatically to `int` or to the largest type in the expression:

<CodeBlock lang="java" title="Arithmetic promotion">
{`public class Promocion {
    public static void main(String[] args) {
        byte a = 10;
        byte b = 20;
        // byte + byte is promoted to int!
        int suma = a + b;  // required, not byte c = a + b;

        // Promotion to the largest type
        int entero = 5;
        double dec = 2.5;
        double resultado = entero + dec;  // int → double

        System.out.println("byte+byte as int: " + suma);
        System.out.println("int+double as double: " + resultado);

        // Integer division vs decimal division
        int x = 7, y = 2;
        int divEntera = x / y;               // 3
        double divDecimal = (double) x / y;  // 3.5

        System.out.println("Integer division: " + divEntera);
        System.out.println("Decimal division: " + divDecimal);
    }
}`}
</CodeBlock>

**Expected output:**
```
byte+byte as int: 30
int+double as double: 7.5
Integer division: 3
Decimal division: 3.5
```

## Conversion between String and numbers

One of the most common tasks: converting text entered by the user to numbers, and vice versa.

### String → number

| Method | Type | Usage |
|--------|------|-----|
| `Integer.parseInt(str)` | `int` | `int n = Integer.parseInt("42");` |
| `Double.parseDouble(str)` | `double` | `double d = Double.parseDouble("3.14");` |
| `Long.parseLong(str)` | `long` | `long l = Long.parseLong("1000000");` |
| `Float.parseFloat(str)` | `float` | `float f = Float.parseFloat("2.5f");` |
| `Boolean.parseBoolean(str)` | `boolean` | `boolean b = Boolean.parseBoolean("true");` |

### Number → String

| Method | Example | Result |
|--------|---------|-----------|
| `String.valueOf(n)` | `String.valueOf(42)` | `"42"` |
| `Integer.toString(n)` | `Integer.toString(255, 16)` | `"ff"` |
| `String.format()` | `String.format("%.2f", 3.14159)` | `"3.14"` |

<CodeBlock lang="java" title="String ↔ numbers">
{`public class StringNumero {
    public static void main(String[] args) {
        // String → int
        String edadStr = "25";
        int edad = Integer.parseInt(edadStr);

        // String → double
        String precioStr = "19.99";
        double precio = Double.parseDouble(precioStr);

        // String → boolean
        String activoStr = "true";
        boolean activo = Boolean.parseBoolean(activoStr);

        System.out.println("Age: " + edad + " (type: int)");
        System.out.println("Price: " + (precio + 5));
        System.out.println("Active: " + activo);

        // Number → String
        int total = 150;
        String totalStr = String.valueOf(total);
        String conFormato = String.format("Total: $%,.2f", 1500.5);

        System.out.println("String.valueOf: " + totalStr);
        System.out.println("String.format: " + conFormato);
    }
}`}
</CodeBlock>

**Expected output:**
```
Age: 25 (type: int)
Price: 24.99
Active: true
String.valueOf: 150
String.format: Total: $1,500.50
```

## Autoboxing and Unboxing

Since Java 5, primitive types are automatically converted to their **wrappers** (enclosing classes) and vice versa:

| Primitive | Wrapper |
|-----------|---------|
| `int` | `Integer` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |
| `long` | `Long` |
| `byte` | `Byte` |
| `short` | `Short` |
| `float` | `Float` |

<CodeBlock lang="java" title="Autoboxing and Unboxing">
{`import java.util.ArrayList;

public class Boxing {
    public static void main(String[] args) {
        // Autoboxing: int → Integer (automatic)
        int primitivo = 42;
        Integer wrapper = primitivo;  // Java creates the Integer object

        // Unboxing: Integer → int (automatic)
        Integer objeto = Integer.valueOf(100);
        int resultado = objeto + 50;  // Java extracts the value

        System.out.println("Primitive: " + primitivo);
        System.out.println("Wrapper: " + wrapper);
        System.out.println("Unboxing: " + resultado);

        // Useful for collections
        ArrayList<Integer> numeros = new ArrayList<>();
        numeros.add(10);  // autoboxing
        numeros.add(20);
        int primero = numeros.get(0);  // unboxing
        System.out.println("First in the list: " + primero);
    }
}`}
</CodeBlock>

**Expected output:**
```
Primitive: 42
Wrapper: 42
Unboxing: 150
First in the list: 10
```

## Common errors

### Error 1: NumberFormatException
```java
// ❌ Throws NumberFormatException
int numero = Integer.parseInt("abc");
int numero2 = Integer.parseInt("12.5");  // decimal point not valid for int

// ✅ Handle with try-catch or validate before
try {
    int numero = Integer.parseInt("abc");
} catch (NumberFormatException e) {
    System.out.println("Not a valid number");
}
```

### Error 2: Forgetting the cast in division
```java
// ❌ Result: 2 (integer division)
int a = 7, b = 3;
double resultado = a / b;

// ✅ At least one operand must be double
double resultado = (double) a / b;
```

### Error 3: Casting long to int without checking the range
```java
// ❌ Unexpected result: -1294967296
long valorGrande = 3_000_000_000L;
int truncado = (int) valorGrande;

// ✅ Check the range
if (valorGrande >= Integer.MIN_VALUE && valorGrande <= Integer.MAX_VALUE) {
    int seguro = (int) valorGrande;
} else {
    System.out.println("Value out of int range");
}
```
