## String immutability

In Java, **String is immutable**: once created, it cannot be modified. Every operation creates a **new** String.

```java
String s = "Hello";
s.toUpperCase();   // returns "HELLO" but does NOT modify s
System.out.println(s);  // prints "Hello"

String s2 = s.toUpperCase();  // s2 is new, s stays the same
```

**Consequence:** Frequent concatenations in loops create many temporary objects. That is why StringBuilder exists.

## Extracting substrings

<CodeBlock lang="java" title="substring and extraction methods">
{`public class Substring {
    public static void main(String[] args) {
        String fecha = "2026-07-27";

        // substring(start, end) — end excluded
        String anio = fecha.substring(0, 4);
        String mes = fecha.substring(5, 7);
        String dia = fecha.substring(8, 10);

        System.out.println("Year: " + anio);
        System.out.println("Month: " + mes);
        System.out.println("Day: " + dia);

        // substring(start) — until the end
        String desdeJulio = fecha.substring(5);
        System.out.println("From July: " + desdeJulio);

        // charAt — get character at position
        System.out.println("First character: " + fecha.charAt(0));
    }
}`}
</CodeBlock>

**Expected output:**
```
Year: 2026
Month: 07
Day: 27
From July: 07-27
First character: 2
```

## Searching in a String

<CodeBlock lang="java" title="Search methods">
{`public class BuscarString {
    public static void main(String[] args) {
        String email = "usuario@ejemplo.com";

        // indexOf — position of substring
        int arroba = email.indexOf("@");
        System.out.println("@ at position: " + arroba);

        // lastIndexOf — last occurrence
        int ultimo = email.lastIndexOf(".");
        System.out.println("Last . at position: " + ultimo);

        // startsWith and endsWith
        System.out.println("Starts with 'user': " + email.startsWith("user"));
        System.out.println("Ends with '.com': " + email.endsWith(".com"));

        // contains
        System.out.println("Contains '@': " + email.contains("@"));

        // Comparison ignoring case
        String nombre = "Carlos";
        System.out.println("equals 'carlos'?: " + nombre.equalsIgnoreCase("carlos"));
    }
}`}
</CodeBlock>

**Expected output:**
```
@ at position: 7
Last . at position: 13
Starts with 'user': true
Ends with '.com': true
Contains '@': true
equals 'carlos'?: true
```

## Replacing, trimming and splitting

<CodeBlock lang="java" title="replace, trim/strip, split">
{`public class ManipularString {
    public static void main(String[] args) {
        // replace
        String msg = "Hello World Java";
        System.out.println(msg.replace("Java", "World"));
        System.out.println(msg.replaceAll("o", "0"));

        // trim (Java 1.0) and strip (Java 11+)
        String conEspacios = "   Hello   ";
        System.out.println("[" + conEspacios.trim() + "]");
        System.out.println("[" + conEspacios.strip() + "]");

        // split
        String csv = "apple,pear,grape,orange";
        String[] frutas = csv.split(",");
        for (String f : frutas) {
            System.out.println("  - " + f);
        }

        // join
        String unido = String.join(" | ", frutas);
        System.out.println("Joined: " + unido);
    }
}`}
</CodeBlock>

**Expected output:**
```
Hello World World
Hell0 W0rld Java
[   Hello   ]
[Hello]
  - apple
  - pear
  - grape
  - orange
Joined: apple | pear | grape | orange
```

## Formatting strings

<CodeBlock lang="java" title="String.format and printf">
{`public class Formatear {
    public static void main(String[] args) {
        String nombre = "Ana";
        double nota = 9.25;
        int edad = 22;

        // String.format — returns a new String
        String perfil = String.format(
            "%s is %d years old with grade %.1f",
            nombre, edad, nota
        );
        System.out.println(perfil);

        // Common formats
        System.out.printf("Hexadecimal: %x%n", 255);
        System.out.printf("Octal: %o%n", 255);
        System.out.printf("Scientific notation: %e%n", 123456.789);
        System.out.printf("With zeros: %05d%n", 42);

        // Alignment
        System.out.printf("%-10s | %5d%n", "Java", 30);
        System.out.printf("%-10s | %5d%n", "Python", 25);
        System.out.printf("%-10s | %5d%n", "JavaScript", 20);
    }
}`}
</CodeBlock>

**Expected output:**
```
Ana is 22 years old with grade 9.3
Hexadecimal: ff
Octal: 377
Scientific notation: 1.234568e+05
With zeros: 00042
Java       |    30
Python     |    25
JavaScript |    20
```

## StringBuilder — for building strings efficiently

<CodeBlock lang="java" title="Building text with StringBuilder">
{`public class BuilderString {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();

        // append — add text
        sb.append("Line 1\\n");
        sb.append("Line 2\\n");
        sb.append("Line 3\\n");

        String resultado = sb.toString();
        System.out.println(resultado);

        // Build CSV
        StringBuilder csv = new StringBuilder();
        String[] datos = {"Ana", "25", "Bogotá"};
        for (int i = 0; i < datos.length; i++) {
            csv.append(datos[i]);
            if (i < datos.length - 1) csv.append(", ");
        }
        System.out.println("CSV: " + csv.toString());

        // insert, delete, reverse
        StringBuilder sb2 = new StringBuilder("Hello");
        sb2.insert(4, " World");
        System.out.println("Insert: " + sb2);

        sb2.delete(4, 10);
        System.out.println("Delete: " + sb2);

        sb2.reverse();
        System.out.println("Reverse: " + sb2);
    }
}`}
</CodeBlock>

**Expected output:**
```
Line 1
Line 2
Line 3

CSV: Ana, 25, Bogotá
Insert: Hello World
Delete: Hello
Reverse: olleH
```
