## What Is a LinkedList?

A **LinkedList** is a doubly linked list: each element (node) holds the data and references to the previous and next nodes. Unlike ArrayList (array-based), LinkedList allows efficient insertions and deletions at any position.

```java
import java.util.LinkedList;

LinkedList<String> lista = new LinkedList<>();
lista.add("First");
lista.add("Second");
lista.add("Third");
```

## Creating and Using a LinkedList

<CodeBlock lang="java" title="Create LinkedList and basic operations">
{`import java.util.LinkedList;

public class CrearLinkedList {
    public static void main(String[] args) {
        LinkedList<String> ciudades = new LinkedList<>();

        // Add elements
        ciudades.add("Bogotá");
        ciudades.add("Medellín");
        ciudades.add("Cali");
        System.out.println("List: " + ciudades);

        // Add at the beginning and end
        ciudades.addFirst("Barranquilla");
        ciudades.addLast("Cartagena");
        System.out.println("With ends: " + ciudades);

        // Access
        System.out.println("First: " + ciudades.getFirst());
        System.out.println("Last: " + ciudades.getLast());
        System.out.println("Index 2: " + ciudades.get(2));
    }
}`}
</CodeBlock>

**Expected output:**
```
List: [Bogotá, Medellín, Cali]
With ends: [Barranquilla, Bogotá, Medellín, Cali, Cartagena]
First: Barranquilla
Last: Cartagena
Index 2: Medellín
```

## End Methods

| Method | Description | Exception if empty |
|--------|-------------|-------------------|
| `addFirst(e)` / `addLast(e)` | Adds at the beginning/end | Does not throw |
| `getFirst()` / `getLast()` | Gets without removing | `NoSuchElementException` |
| `removeFirst()` / `removeLast()` | Gets and removes | `NoSuchElementException` |
| `peekFirst()` / `peekLast()` | Gets without removing | `null` if empty |
| `pollFirst()` / `pollLast()` | Gets and removes | `null` if empty |

## LinkedList as a Queue

<CodeBlock lang="java" title="FIFO queue with LinkedList">
{`import java.util.LinkedList;

public class ColaFIFO {
    public static void main(String[] args) {
        LinkedList<String> cola = new LinkedList<>();

        // Enqueue (add at the end)
        cola.offer("Customer 1");
        cola.offer("Customer 2");
        cola.offer("Customer 3");
        System.out.println("Queue: " + cola);

        // Dequeue (take from the front)
        while (!cola.isEmpty()) {
            String cliente = cola.poll();
            System.out.println("Serving: " + cliente);
        }
        System.out.println("Queue empty: " + cola.isEmpty());
    }
}`}
</CodeBlock>

**Expected output:**
```
Queue: [Customer 1, Customer 2, Customer 3]
Serving: Customer 1
Serving: Customer 2
Serving: Customer 3
Queue empty: true
```

## LinkedList as a Stack

<CodeBlock lang="java" title="LIFO stack with LinkedList">
{`import java.util.LinkedList;

public class PilaLIFO {
    public static void main(String[] args) {
        LinkedList<String> pila = new LinkedList<>();

        // Push (add to the front)
        pila.push("First");
        pila.push("Second");
        pila.push("Third");
        System.out.println("Stack: " + pila);

        // Pop (take from the front)
        while (!pila.isEmpty()) {
            System.out.println("Popping: " + pila.pop());
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Stack: [Third, Second, First]
Popping: Third
Popping: Second
Popping: First
```

## Iterating over a LinkedList

```java
LinkedList<String> lista = new LinkedList<>();
// ... add elements

// classic for (slow in LinkedList)
for (int i = 0; i < lista.size(); i++) {
    System.out.println(lista.get(i));  // O(n) per get
}

// for-each (recommended)
for (String elemento : lista) {
    System.out.println(elemento);  // O(1) per iterator
}
```

**Important:** In LinkedList, using `get(i)` in a for loop is O(n²) because each access traverses the list from the beginning. Use for-each or Iterator to traverse a LinkedList efficiently.
