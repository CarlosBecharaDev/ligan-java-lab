## What is Optional?

`Optional<T>` is a container that may hold a value of type T... or not. It is an explicit way to say "this method may have no result".

```java
// Instead of:
String resultado = buscar("id");  // can it return null?
if (resultado != null) { ... }

// With Optional:
Optional<String> resultado = buscar("id");  // explicit: it may have no value
resultado.ifPresent(System.out::println);
```

## Creating Optionals

<CodeBlock lang="java" title="The three ways to create Optional">
{`import java.util.*;

public class CrearOptional {
    public static void main(String[] args) {
        // 1. Optional.of — when you KNOW the value is NOT null
        Optional<String> presente = Optional.of("Hola");
        System.out.println("present: " + presente);

        // 2. Optional.ofNullable — when it MAY be null
        String nulo = null;
        Optional<String> vacio = Optional.ofNullable(nulo);
        System.out.println("empty: " + vacio);

        // 3. Optional.empty — explicit empty Optional
        Optional<String> explicito = Optional.empty();
        System.out.println("explicit: " + explicito);

        // Check if there is a value
        System.out.println("present.isPresent(): " + presente.isPresent());
        System.out.println("empty.isPresent(): " + vacio.isPresent());
        System.out.println("present.isEmpty(): " + presente.isEmpty());

        // Java 11+:
        System.out.println("empty.isEmpty(): " + vacio.isEmpty());
    }
}`}
</CodeBlock>

**Expected output:**
```
present: Optional[Hola]
empty: Optional.empty
explicit: Optional.empty
present.isPresent(): true
empty.isPresent(): false
present.isEmpty(): false
empty.isEmpty(): true
```

## Extracting values

<CodeBlock lang="java" title="Safe ways to get values from Optional">
{`import java.util.*;

public class ExtraerOptional {
    public static void main(String[] args) {
        Optional<String> opt = Optional.of("Java");
        Optional<String> vacio = Optional.empty();

        // get — only if you are sure there is a value
        System.out.println("get: " + opt.get());

        // orElse — default value
        System.out.println("orElse: " + vacio.orElse("default"));

        // orElseGet — default value with a lambda (only evaluated if empty)
        System.out.println("orElseGet: " + vacio.orElseGet(() -> "generated"));

        // orElseThrow — throw an exception if empty
        try {
            vacio.orElseThrow(() -> new RuntimeException("No value"));
        } catch (RuntimeException e) {
            System.out.println("orElseThrow: " + e.getMessage());
        }

        // ifPresent — run an action only if there is a value
        opt.ifPresent(v -> System.out.println("Value: " + v));
    }
}`}
</CodeBlock>

## Operations with lambdas

<CodeBlock lang="java" title="Optional with map, filter, ifPresent">
{`import java.util.*;

public class OptionalLambdas {
    public static void main(String[] args) {
        Optional<String> opt = Optional.of("Java 21");
        Optional<String> vacio = Optional.empty();

        // map — transform the value if it exists
        Optional<Integer> longitud = opt.map(String::length);
        System.out.println("Length: " + longitud.orElse(0));

        vacio.map(String::length)
             .ifPresent(l -> System.out.println("Never printed"));

        // filter — test a condition
        opt.filter(s -> s.contains("Java"))
           .ifPresent(s -> System.out.println("Contains Java: " + s));

        opt.filter(s -> s.startsWith("Python"))
           .ifPresent(s -> System.out.println("Never printed"));

        // flatMap — for nested Optionals
        Optional<String> anidado = Optional.of("  texto  ");
        Optional<Integer> resultado = anidado
            .map(String::trim)
            .flatMap(s -> Optional.of(s.length()));
        System.out.println("Trim length: " + resultado.orElse(0));
    }
}`}
</CodeBlock>

**Expected output:**
```
Length: 7
Contains Java: Java 21
Trim length: 7
```

## When NOT to use Optional

- ❌ As a class field
- ❌ As a method parameter
- ❌ In collections (`List<Optional<String>>`)
- ❌ As a serializable instance

```java
// ❌ Bad
class Persona {
    private Optional<String> email;  // Don't
}

// ✅ Good
class Persona {
    private String email;  // null means "no email"
}
```
