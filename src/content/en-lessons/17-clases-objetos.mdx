## What is a Class?

A **class** is a mold or template that defines the characteristics and behaviors of a type of object. It is like the blueprint of a house: it defines which rooms it has and how they are connected, but it is not the house itself.

```java
// The class is the mold
public class Mascota {
    // Attributes (characteristics)
    String nombre;
    String especie;
    int edad;
    double peso;

    // Methods (behaviors)
    void comer() {
        System.out.println(nombre + " está comiendo");
    }

    void presentarse() {
        System.out.println("Soy " + nombre + ", un " + especie + " de " + edad + " años");
    }
}
```

**Anatomy of a class:**
- **Name**: Identifies the type of object (PascalCase)
- **Attributes**: Variables that store the object's data
- **Methods**: Functions that define the behavior

## Creating Objects with `new`

An **object** is a concrete instance of a class. To create one, we use `new`:

```java
public class CrearObjetos {
    public static void main(String[] args) {
        // Create a Persona object
        Persona persona1 = new Persona();

        // Assign values to attributes
        persona1.nombre = "María";
        persona1.edad = 25;
        persona1.email = "maria@email.com";

        // Call methods
        persona1.saludar();           // Hola, soy María
        System.out.println(persona1.esMayorDeEdad());  // true

        // Create another object (each one is independent)
        Persona persona2 = new Persona();
        persona2.nombre = "Carlos";
        persona2.edad = 15;
        persona2.saludar();           // Hola, soy Carlos
    }
}
```

**Each object has its own copy of the attributes:**
- `persona1` has nombre="María", edad=25
- `persona2` has nombre="Carlos", edad=15
- Changing `persona1.nombre` does not affect `persona2`

## Memory and References

When you create an object, Java allocates memory in the **heap** and the variable stores a **reference** (address) to that memory:

```java
// This does NOT create a second object
Persona copia = persona1;  // copia points to the SAME object

copia.nombre = "Ana";
System.out.println(persona1.nombre);  // "Ana" - both variables point to the same object!
```

To create an independent object, you need a new one:

```java
// This DOES create a second object
Persona otra = new Persona();
otra.nombre = "Luis";
otra.edad = 30;
// persona1 is still "Ana"
```

<CodeBlock

        System.out.println("b: " + b.nombre);  // Rocky (same as a)
        System.out.println("c: " + c.nombre);  // Luna (separate object)
    }
}`}

## Static Attributes and Methods

`static` members belong to the **class**, not to a specific object:

```java
public class Contador {
    // Static attribute: shared among ALL objects
    static int totalMascotas = 0;

    // Instance attribute: unique per object
    String nombre;

    Contador(String nombre) {
        this.nombre = nombre;
        totalMascotas++;  // Incremented when each object is created
    }

    // Static method: called on the class, not on the object
    static int getTotal() {
        return totalMascotas;
    }

    public static void main(String[] args) {
        Contador c1 = new Contador("Max");
        Contador c2 = new Contador("Luna");
        Contador c3 = new Contador("Rocky");

        System.out.println(Contador.getTotal());  // 3 (shared)
        System.out.println(c1.totalMascotas);     // 3 (same value)
    }
}
```

        p2.mostrar();  // Pedido #2 - Luis - $85.5
        p3.mostrar();  // Pedido #3 - María - $220.0

        System.out.println("Total pedidos: " + Pedido.totalPedidos);  // 3
        System.out.println("Promedio: $" + Pedido.promedio());  // $151.83
    }
}`}

    static int totalPacientes = 0;

    String nombre;
    int edad;
    double temperatura;
    String sintoma;

    Paciente(String nombre, int edad, double temperatura, String sintoma) {
        this.nombre = nombre;

    }

        System.out.println("Paciente: " + nombre + " | Edad: " + edad);
        System.out.println("Temperatura: " + temperatura + "°C | Síntoma: " + sintoma);
        System.out.println("Clasificación: " + clasificar());
        System.out.println("---");
    }

    static void reporte() {
        System.out.println("=== REPORTE: " + totalPacientes + " pacientes en el día ===");
    }

    public static void main(String[] args) {
        Paciente p1 = new Paciente("Carlos", 45, 36.8, "Dolor de cabeza");
        Paciente p2 = new Paciente("Ana", 32, 38.5, "Tos seca");
        Paciente p3 = new Paciente("Pedro", 67, 39.2, "Fiebre alta");

        p1.mostrarFicha();
        p2.mostrarFicha();
        p3.mostrarFicha();

        Paciente.reporte();
    }
}`}

## Real Example: E-commerce 🛒

<CodeBlock
  title="Product with state"
  lang="java"
  code={`public class Producto {
    static int totalProductos = 0;

    String nombre;
    double precio;
    int stock;
    boolean activo;

    Producto(String nombre, double precio, int stock) {
        this.nombre = nombre;
        this.precio = precio;
        this.stock = stock;
        this.activo = stock > 0;
        totalProductos++;
    }

    boolean hayStock() {
        return stock > 0 && activo;
    }

    void vender(int cantidad) {
        if (cantidad > stock) {
            System.out.println("Stock insuficiente: solo quedan " + stock);
            return;
        }
        stock -= cantidad;
        if (stock == 0) agotar();
        System.out.println("Venta de " + cantidad + " x " + nombre);
    }

    void reabastecer(int cantidad) {
        stock += cantidad;
        activo = true;
    }

    void agotar() {
        activo = false;
    }

    void mostrar() {
        String estado = activo ? "Activo" : "Agotado";
        System.out.println(nombre + " - $" + precio + " | Stock: " + stock + " | " + estado);
    }

    public static void main(String[] args) {
        Producto laptop = new Producto("Laptop", 1200.00, 10);
        Producto mouse = new Producto("Mouse", 25.00, 0);

        laptop.mostrar();   // Laptop - $1200.0 | Stock: 10 | Activo
        mouse.mostrar();    // Mouse - $25.0 | Stock: 0 | Agotado

        laptop.vender(3);   // Venta de 3 x Laptop
        laptop.mostrar();   // Laptop - $1200.0 | Stock: 7 | Activo

        laptop.vender(10);  // Stock insuficiente: solo quedan 7
    }
}`}
/>

## Summary

| Concept | Description |
|----------|-------------|
| **Class** | Mold that defines attributes and methods |
| **Object** | Concrete instance created with `new` |
| **Attribute** | Variable that belongs to an object |
| **Method** | Function that defines behavior |
| **Reference** | Variable that points to an object in memory |
| **static** | Member that belongs to the class, not to the object |
| **new** | Operator that creates an object in memory |

## Frequently Asked Questions

<details>
<summary>What happens if I don't initialize an attribute?</summary>
Java assigns default values: `0` for integers, `0.0` for decimals, `null` for objects, `false` for booleans.
</details>

<details>
<summary>Can I have a class without methods?</summary>
Yes, but it makes no sense. A class without methods only stores data without behavior.
</details>

<details>
<summary>When do I use static vs instance?</summary>
- **static**: Shared by all (counters, constants, utilities)
- **instance**: Unique to each object (name, age, state)
</details>

<details>
<summary>What exactly is the new operator?</summary>
It reserves memory on the heap for the object, initializes its attributes, and returns the memory address (reference).
</details>
