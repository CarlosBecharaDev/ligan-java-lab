## What is a decision statement?

Decision statements allow a program to **take different paths** depending on specific conditions. They are the foundation of logic in any programming language.

In Java, the fundamental decision statement is `if`:

```java
if (condicion) {
    // block that runs if condicion is true
}
```

## The if statement

`if` executes a block of code **only if** the condition is `true`:

<CodeBlock lang="java" title="Basic if statement">
{`public class IfBasico {
    public static void main(String[] args) {
        int edad = 20;

        if (edad >= 18) {
            System.out.println("You are an adult");
        }

        System.out.println("This line always runs");

        // if with a single line (no braces, not recommended)
        if (edad >= 18) System.out.println("Adult");

        // Always use braces to avoid errors
        if (edad >= 18) {
            System.out.println("Adult");
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
You are an adult
This line always runs
Adult
Adult
```

## If-else: two paths

`else` executes a block when the condition is `false`:

```java
if (condicion) {
    // when it is true
} else {
    // when it is false
}
```

<CodeBlock lang="java" title="If-else">
{`public class IfElse {
    public static void main(String[] args) {
        int temperatura = 5;

        if (temperatura > 25) {
            System.out.println("It's hot 🥵");
        } else {
            System.out.println("It's cold 🥶");
        }

        System.out.println("Inside or outside, the program continues");
    }
}`}
</CodeBlock>

**Expected output:**
```
It's cold 🥶
Inside or outside, the program continues
```

## Else-if: multiple conditions

When you have more than two paths, chain `else if`:

<CodeBlock lang="java" title="Else-if">
{`public class ElseIf {
    public static void main(String[] args) {
        int nota = 85;

        if (nota >= 90) {
            System.out.println("Excellent 🏆");
        } else if (nota >= 80) {
            System.out.println("Very good 👍");
        } else if (nota >= 70) {
            System.out.println("Good 👌");
        } else if (nota >= 60) {
            System.out.println("Enough 📖");
        } else {
            System.out.println("Failed ❌");
        }

        System.out.println("Final grade: " + nota);
    }
}`}
</CodeBlock>

**Expected output:**
```
Very good 👍
Final grade: 85
```

## Complex boolean conditions

You can combine multiple conditions with logical operators:

<CodeBlock lang="java" title="Compound conditions">
{`public class CondicionesCompuestas {
    public static void main(String[] args) {
        int edad = 25;
        boolean tieneLicencia = true;
        boolean tieneMultas = false;

        // AND: both must hold
        if (edad >= 18 && tieneLicencia) {
            System.out.println("Can drive legally");
        }

        // OR: at least one must hold
        if (edad < 12 || tieneMultas) {
            System.out.println("Has restrictions");
        }

        // NOT + AND: combination
        if (edad >= 18 && !tieneMultas) {
            System.out.println("Has no tickets and is an adult");
        }

        // Complex compound condition
        if ((edad >= 18 && tieneLicencia) && !tieneMultas) {
            System.out.println("✅ Driver without restrictions");
        } else {
            System.out.println("⚠️ Cannot drive");
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Can drive legally
Has no tickets and is an adult
✅ Driver without restrictions
```

## If-else vs ternary operator

The ternary operator is a compact version of `if-else` for assignments:

```java
// traditional if-else
String mensaje;
if (edad >= 18) {
    mensaje = "Adult";
} else {
    mensaje = "Minor";
}

// Equivalent ternary (one line)
String mensaje = (edad >= 18) ? "Adult" : "Minor";
```

## Common mistakes

### Mistake 1: Using `=` instead of `==`
```java
// ❌ Assigns 5 to x, does not compare. The condition is always true
if (x = 5) { }  // Compilation error

// ✅ Correct comparison
if (x == 5) { }
```

### Mistake 2: Forgetting the braces
```java
// ❌ Only "Check..." is inside the if
if (edad >= 18)
    System.out.println("Check...");
    System.out.println("Adult");  // always runs

// ✅ With braces, both lines are inside
if (edad >= 18) {
    System.out.println("Check...");
    System.out.println("Adult");
}
```

### Mistake 3: Semicolon after the if
```java
// ❌ The ; ends the if statement, the block always runs
if (edad >= 18); {
    System.out.println("Adult");  // always prints
}

// ✅ Without semicolon
if (edad >= 18) {
    System.out.println("Adult");
}
```

### Mistake 4: Comparing Strings with ==
```java
// ❌ Compares references, not content
if (nombre == "Carlos") { }

// ✅ Compares content correctly
if ("Carlos".equals(nombre)) { }
```
