## The exception hierarchy

```
Throwable (the root of everything)
├── Error (serious JVM problems — don't handle)
│   ├── OutOfMemoryError
│   ├── StackOverflowError
│   └── ...
└── Exception (errors your code can handle)
    ├── RuntimeException (UNCHECKED)
    │   ├── NullPointerException
    │   ├── IllegalArgumentException
    │   ├── ArrayIndexOutOfBoundsException
    │   └── ...
    └── Checked Exceptions (verified by the compiler)
        ├── IOException
        ├── FileNotFoundException
        ├── SQLException
        └── ...
```

## Unchecked Exceptions (RuntimeException)

They are **programming** errors (bugs). The compiler does not force you to handle them.

<CodeBlock lang="java" title="Most common RuntimeException">
{`public class TiposRuntimeException {
    public static void main(String[] args) {
        // 1. NullPointerException
        try {
            String texto = null;
            texto.length();
        } catch (NullPointerException e) {
            System.out.println("NullPointerException: " + e.getMessage());
        }

        // 2. ArrayIndexOutOfBoundsException
        try {
            int[] nums = {1, 2, 3};
            int valor = nums[10];
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("ArrayIndexOutOfBounds: " + e.getMessage());
        }

        // 3. NumberFormatException
        try {
            int num = Integer.parseInt("abc");
        } catch (NumberFormatException e) {
            System.out.println("NumberFormatException: " + e.getMessage());
        }

        // 4. IllegalArgumentException
        try {
            setEdad(-5);
        } catch (IllegalArgumentException e) {
            System.out.println("IllegalArgumentException: " + e.getMessage());
        }
    }

    static void setEdad(int edad) {
        if (edad < 0 || edad > 150) {
            throw new IllegalArgumentException("Invalid age: " + edad);
        }
        System.out.println("Age set: " + edad);
    }
}`}
</CodeBlock>

**Expected output:**
```
NullPointerException: null
ArrayIndexOutOfBounds: Index 10 out of bounds for length 3
NumberFormatException: For input string: "abc"
IllegalArgumentException: Invalid age: -5
```

## Checked Exceptions

The compiler **forces** you to handle them with `try-catch` or declare them with `throws`.

<CodeBlock lang="java" title="Checked exception — FileNotFoundException">
{`import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class CheckedDemo {
    static void leerArchivo(String ruta) throws FileNotFoundException {
        // FileNotFoundException is checked — we must declare throws
        Scanner sc = new Scanner(new File(ruta));
        while (sc.hasNextLine()) {
            System.out.println(sc.nextLine());
        }
        sc.close();
    }

    public static void main(String[] args) {
        try {
            leerArchivo("datos.txt");
        } catch (FileNotFoundException e) {
            System.out.println("Could not read: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Could not read: datos.txt (The system cannot find the file specified)
```

## Reading a stack trace

When an exception occurs, the stack trace tells you **where** and **how** it happened:

```
java.lang.ArithmeticException: / by zero
    at Calculator.dividir(Calculator.java:15)      ← where it happened
    at Calculator.main(Calculator.java:8)            ← who called it
```

**Read from bottom to top:** `main` calls `dividir`, and that's where the division by zero occurs.

## The most important exceptions

| Exception | Type | Common cause |
|-----------|------|--------------|
| `NullPointerException` | Unchecked | Using a null object as if it had a value |
| `ArrayIndexOutOfBoundsException` | Unchecked | Accessing an index out of range |
| `NumberFormatException` | Unchecked | Converting invalid text to a number |
| `IllegalArgumentException` | Unchecked | Parameter with an unacceptable value |
| `FileNotFoundException` | Checked | File not found on disk |
| `IOException` | Checked | General input/output error |
| `ClassNotFoundException` | Checked | Class not found in the classpath |
