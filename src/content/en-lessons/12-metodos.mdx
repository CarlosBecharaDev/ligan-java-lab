## What is a method?

A method is a **named block of code** that performs a specific task. Instead of writing all your code in `main`, you split it into methods that do concrete things and can be reused as many times as you need.

```
// Basic syntax
modifier returnType methodName(parameters) {
    // body
    return value; // if returnType is not void
}
```

## Your first method

Let's look at a simple method that greets a person:

<CodeBlock lang="java" title="Basic method — greeting">
{`public class Saludar {
    // Method definition
    static void saludar(String nombre) {
        System.out.println("Hello, " + nombre + "!");
    }

    public static void main(String[] args) {
        // Method call
        saludar("Ana");
        saludar("Luis");
        saludar("María");
    }
}`}
</CodeBlock>

**Expected output:**
```
Hello, Ana!
Hello, Luis!
Hello, María!
```

The `saludar` method is defined once and called three times with different arguments. Without methods, you'd have to write `System.out.println("Hello, " + nombre + "!");` three times.

## Parameters vs arguments

These terms are frequently confused:

- **Parameter**: the variable in the method definition (`String nombre`)
- **Argument**: the actual value you pass when calling (`"Ana"`)

```java
//            parameters
static int sumar(int a, int b) {
    return a + b;
}

//         arguments
int resultado = sumar(5, 3);  // a=5, b=3 → returns 8
```

## Methods with return values

A method can **return a value** using `return`. The return type indicates what type of data it returns:

<CodeBlock lang="java" title="Method with return — calculate circle area">
{`public class AreaCirculo {
    static double calcularArea(double radio) {
        return Math.PI * radio * radio;
    }

    static String clasificar(double area) {
        if (area < 10)  return "Small";
        if (area < 50)  return "Medium";
        return "Large";
    }

    public static void main(String[] args) {
        double[] radios = {2.0, 4.0, 7.0};

        for (double r : radios) {
            double area = calcularArea(r);
            String tipo = clasificar(area);
            System.out.printf("Radius %.1f → Area: %.2f (%s)%n",
                r, area, tipo);
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Radius 2.0 → Area: 12.57 (Medium)
Radius 4.0 → Area: 50.27 (Large)
Radius 7.0 → Area: 153.94 (Large)
```

## void methods — no return value

A `void` method performs an action but **returns nothing**. It doesn't need `return`, or it can use `return;` without a value to exit early:

<CodeBlock lang="java" title="void method — print report">
{`public class Reporte {
    static void imprimirLinea(char caracter, int veces) {
        for (int i = 0; i < veces; i++) {
            System.out.print(caracter);
        }
        System.out.println();
    }

    static void imprimirTitulo(String titulo) {
        imprimirLinea('=', 40);
        System.out.println("  " + titulo);
        imprimirLinea('=', 40);
    }

    public static void main(String[] args) {
        imprimirTitulo("SALES REPORT");
        System.out.println("January:   $12,500");
        System.out.println("February: $15,200");
        System.out.println("March:     $18,900");
        imprimirLinea('-', 40);
        System.out.println("Total:     $46,600");
    }
}`}
</CodeBlock>

**Expected output:**
```
========================================
  SALES REPORT
========================================
January:   $12,500
February: $15,200
March:     $18,900
----------------------------------------
Total:     $46,600
```

## Multiple parameters

A method can receive several parameters of different types:

<CodeBlock lang="java" title="Multiple parameters — tax calculator">
{`public class Impuestos {
    static double calcularImpuesto(
            double monto, double tasaPorcentaje, double descuento) {
        double base = monto - descuento;
        if (base < 0) base = 0;
        return base * tasaPorcentaje / 100;
    }

    public static void main(String[] args) {
        double imp1 = calcularImpuesto(100000, 19, 0);
        double imp2 = calcularImpuesto(100000, 19, 20000);
        double imp3 = calcularImpuesto(50000, 16, 5000);

        System.out.printf("No discount: $%.2f%n", imp1);
        System.out.printf("With $20k discount: $%.2f%n", imp2);
        System.out.printf("Rate 16%%: $%.2f%n", imp3);
    }
}`}
</CodeBlock>

**Expected output:**
```
No discount: $19000.00
With $20k discount: $15200.00
Rate 16%: $7200.00
```

## Order matters

In Java, a method must be **defined before** it is used (within the same class). Best practice is to put helper methods before `main`, or in a separate class.

```
// ✅ Correct: method defined before it is used
static void saludar(String nombre) { ... }

public static void main(String[] args) {
    saludar("Ana"); // works
}
```

## Pass by value

In Java, primitive types are passed **by value**: the method receives a copy, not the original variable. Modifying the parameter inside the method does NOT change the original variable:

<CodeBlock lang="java" title="Pass by value — the original does not change">
{`public class PasoPorValor {
    static void duplicar(int numero) {
        numero = numero * 2; // modifies the copy
        System.out.println("Inside the method: " + numero);
    }

    public static void main(String[] args) {
        int edad = 25;
        System.out.println("Before: " + edad);
        duplicar(edad);
        System.out.println("After: " + edad);
    }
}`}
</CodeBlock>

**Expected output:**
```
Before: 25
Inside the method: 50
After: 25
```

The `edad` variable is still 25 because `duplicar` received a copy, not the original reference.
