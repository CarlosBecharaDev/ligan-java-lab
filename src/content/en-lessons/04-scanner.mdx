## What is Scanner?

`Scanner` is a class from the `java.util` package that allows reading data from various sources: the console (System.in), files, strings, etc. It is the most common way to get user input in Java programs.

To use Scanner, you must first import it:

```java
import java.util.Scanner;
```

The import line must go **before** the definition of any class.

## Creating a Scanner

To read data from the console:

```java
Scanner sc = new Scanner(System.in);
```

- `Scanner` is the type of the variable
- `new Scanner(System.in)` creates a new object that reads from standard input (keyboard)

Always tell the user what you expect **before** calling a reading method:

```java
System.out.print("What is your name? ");
String nombre = sc.nextLine();  // stops here until the user presses Enter
```

## Main reading methods

| Method | Reads | Return type |
|--------|-----|-----------------|
| `nextLine()` | A complete line (until Enter) | `String` |
| `next()` | A word (until a space) | `String` |
| `nextInt()` | An integer | `int` |
| `nextDouble()` | A decimal | `double` |
| `nextBoolean()` | true or false | `boolean` |

<CodeBlock lang="java" title="Reading different types">
{`import java.util.Scanner;

public class TiposDeEntrada {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Your name: ");
        String nombre = sc.nextLine();

        System.out.print("Your age: ");
        int edad = sc.nextInt();

        System.out.print("Your height (m): ");
        double altura = sc.nextDouble();

        System.out.print("Are you studying? (true/false): ");
        boolean estudiando = sc.nextBoolean();

        System.out.println("\\n--- Your profile ---");
        System.out.println("Name: " + nombre);
        System.out.println("Age: " + edad);
        System.out.println("Height: " + altura + "m");
        System.out.println("Studying: " + estudiando);

        sc.close();
    }
}`}
</CodeBlock>

**Example output:**
```
Your name: Ana López
Your age: 22
Your height (m): 1.65
Are you studying? (true/false): true

--- Your profile ---
Name: Ana López
Age: 22
Height: 1.65m
Studying: true
```

## The buffer trap: the most common error

When you use `nextInt()` or `nextDouble()`, Scanner reads the number but **leaves the newline** (Enter) in the buffer. If you then call `nextLine()`, it consumes that pending newline and seems to "skip" the input:

<CodeBlock lang="java" title="The buffer problem">
{`import java.util.Scanner;

public class TrampaBuffer {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Age: ");
        int edad = sc.nextInt();

        // ❌ PROBLEM: nextLine() consumes the pending Enter
        System.out.print("Name: ");
        String nombre = sc.nextLine();  // It gets skipped! It doesn't wait for input

        System.out.println("Age: " + edad);
        System.out.println("Name: '" + nombre + "'");  // name is empty

        sc.close();
    }
}`}
</CodeBlock>

**The solution:** Add an empty `nextLine()` after each `nextInt()` or `nextDouble()` to clear the buffer:

<CodeBlock lang="java" title="Solution to the buffer problem">
{`import java.util.Scanner;

public class SolucionBuffer {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Age: ");
        int edad = sc.nextInt();
        sc.nextLine();  // Clears the buffer — key!

        System.out.print("Name: ");
        String nombre = sc.nextLine();  // Now it works correctly

        System.out.println("Age: " + edad);
        System.out.println("Name: " + nombre);

        sc.close();
    }
}`}
</CodeBlock>

**Example output:**
```
Age: 25
Name: Carlos Bechara
Age: 25
Name: Carlos Bechara
```

## Reading full lines vs. words

<CodeBlock lang="java" title="nextLine vs next">
{`import java.util.Scanner;

public class LineaVsPalabra {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // next() reads only up to the first space
        System.out.print("Type something (one word): ");
        String palabra = sc.next();
        System.out.println("Read with next(): '" + palabra + "'");

        sc.nextLine();  // clear buffer

        // nextLine() reads the whole line
        System.out.print("Type something (a full line): ");
        String linea = sc.nextLine();
        System.out.println("Read with nextLine(): '" + linea + "'");

        sc.close();
    }
}`}
</CodeBlock>

**Example output:**
```
Type something (one word): Hola Mundo
Read with next(): 'Hola'
Type something (a full line): Hola Mundo
Read with nextLine(): 'Hola Mundo'
```

## Error handling with hasNext

To prevent your program from crashing if the user enters a wrong type, use `hasNextInt()`, `hasNextDouble()`, etc.:

<CodeBlock lang="java" title="Validation with hasNext">
{`import java.util.Scanner;

public class EntradaSegura {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // Read an integer safely
        int numero = 0;
        boolean valido = false;

        while (!valido) {
            System.out.print("Enter an integer: ");
            if (sc.hasNextInt()) {
                numero = sc.nextInt();
                valido = true;
            } else {
                System.out.println("❌ That's not an integer. Try again.");
                sc.next();  // discard the incorrect input
            }
        }

        System.out.println("✅ You entered: " + numero);
        sc.close();
    }
}`}
</CodeBlock>

**Example output:**
```
Enter an integer: abc
❌ That's not an integer. Try again.
Enter an integer: 42
✅ You entered: 42
```

## Common errors

### Error 1: Forgetting to import Scanner
```java
// ❌ Error: Scanner cannot be resolved to a type
Scanner sc = new Scanner(System.in);

// ✅ Add the import at the top
import java.util.Scanner;
```

### Error 2: Not clearing the buffer after nextInt
```java
// ❌ The pending Enter is consumed by nextLine()
int edad = sc.nextInt();
String nombre = sc.nextLine();  // name is left empty

// ✅ Clear the buffer
int edad = sc.nextInt();
sc.nextLine();  // consumes the pending Enter
String nombre = sc.nextLine();
```

### Error 3: Not closing Scanner
```java
// ❌ Resource leak
Scanner sc = new Scanner(System.in);
// ... use sc
// you forgot sc.close()

// ✅ Always close
Scanner sc = new Scanner(System.in);
// ... use sc
sc.close();
```
