## Flow control statements

So far we have seen loops that run until their condition becomes `false`. But sometimes you need to **exit early**, **skip an iteration**, or **end a method** immediately. The three control statements that allow this are `break`, `continue`, and `return`.

## The break statement

`break` **immediately terminates** the innermost loop or switch in which it appears. Execution continues with the first statement after that loop or switch.

<CodeBlock lang="java" title="break — exiting upon finding a number">
{`public class BuscarNumero {
    public static void main(String[] args) {
        int[] numeros = {5, 12, 8, 23, 1, 17};
        int objetivo = 23;

        for (int i = 0; i < numeros.length; i++) {
            if (numeros[i] == objetivo) {
                System.out.println("Found " + objetivo
                    + " at index " + i);
                break; // stop searching
            }
        }
        System.out.println("Search ended");
    }
}`}
</CodeBlock>

**Expected output:**
```
Found 23 at index 3
Search ended
```

Without `break`, the loop would keep checking elements 1 and 17 unnecessarily. With `break`, the loop ends as soon as it finds the target.

## The continue statement

`continue` **jumps to the start of the next iteration** of the loop, skipping the rest of the body for the current iteration. The loop does not end; it simply ignores what remains in the body and moves to the next turn.

<CodeBlock lang="java" title="continue — printing only odd numbers">
{`public class SoloImpares {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4, 5, 6, 7, 8};

        for (int n : numeros) {
            if (n % 2 == 0) {
                continue; // skip evens
            }
            System.out.println("Odd: " + n);
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Odd: 1
Odd: 3
Odd: 5
Odd: 7
```

When `n` is even (2, 4, 6, 8), `continue` jumps directly to the next iteration without running `System.out.println`.

## Key difference: break vs continue

```
break:     [1] [2] [3] ← exits here ──→ after the loop
continue:  [1] [2] [3] ← skips this ──→ [5] [6] (the loop continues)
```

- `break` **stops** the loop completely.
- `continue` **skips** only the current iteration and continues.

## The return statement

`return` **exits the current method** immediately, returning control to the method that called it. If the method has a return type, `return` must be followed by the value to return.

<CodeBlock lang="java" title="return — exiting a method early">
{`public class ValidadorEdad {
    public static String clasificarEdad(int edad) {
        if (edad < 0) {
            return "Invalid age";
        }
        if (edad < 13) {
            return "Child";
        }
        if (edad < 18) {
            return "Teenager";
        }
        return "Adult";
    }

    public static void main(String[] args) {
        System.out.println(clasificarEdad(5));
        System.out.println(clasificarEdad(16));
        System.out.println(clasificarEdad(25));
        System.out.println(clasificarEdad(-1));
    }
}`}
</CodeBlock>

**Expected output:**
```
Child
Teenager
Adult
Invalid age
```

Each `return` ends the method immediately: once `return "Child"` runs, the rest of the method does not execute. This is known as an **early return** and is a very common pattern to avoid nesting conditionals.

## return in void — exiting without a value

When a method returns nothing (`void`), you can use `return` without a value to exit early:

<CodeBlock lang="java" title="return void — exiting without returning anything">
{`public class BuscarEnMatriz {
    public static void imprimirPrimeraOcurrencia(
            int[][] matriz, int objetivo) {

        for (int i = 0; i < matriz.length; i++) {
            for (int j = 0; j < matriz[i].length; j++) {
                if (matriz[i][j] == objetivo) {
                    System.out.println("Found at ["
                        + i + "][" + j + "]");
                    return; // exit the whole method
                }
            }
        }
        System.out.println("Not found");
    }

    public static void main(String[] args) {
        int[][] datos = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        imprimirPrimeraOcurrencia(datos, 5);
        imprimirPrimeraOcurrencia(datos, 10);
    }
}`}
</CodeBlock>

**Expected output:**
```
Found at [1][1]
Not found
```

## Labeled break and continue

In nested loops, `break` and `continue` by default only affect the **innermost** loop. With a **label**, you can control outer loops.

<CodeBlock lang="java" title="Labeled break — exiting two loops at once">
{`public class BusquedaMatriz {
    public static void main(String[] args) {
        int[][] matriz = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int objetivo = 5;
        boolean encontrado = false;

        busqueda:
        for (int i = 0; i < matriz.length; i++) {
            for (int j = 0; j < matriz[i].length; j++) {
                if (matriz[i][j] == objetivo) {
                    System.out.println("Found at ["
                        + i + "][" + j + "]");
                    encontrado = true;
                    break busqueda; // exits BOTH loops
                }
            }
        }

        if (!encontrado) {
            System.out.println("Not found");
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Found at [1][1]
```

Without `break busqueda`, only the inner loop would exit and it would keep traversing the next row. The `busqueda:` label is placed before the outer `for`, and `break busqueda` exits that loop and all inner ones.

## Labeled continue

The same applies to `continue`: with a label you can jump to the next iteration of the **outer** loop instead of the inner one.

<CodeBlock lang="java" title="Labeled continue — skipping a whole row">
{`public class SaltarFila {
    public static void main(String[] args) {
        int[][] datos = {
            {1, -1, 3},
            {-1, -1, 6},
            {7, 8, 9}
        };

        for (int i = 0; i < datos.length; i++) {
            System.out.println("Processing row " + i + ":");
            for (int j = 0; j < datos[i].length; j++) {
                if (datos[i][j] < 0) {
                    System.out.println("  Negative value"
                        + " — skipping the whole row");
                    continue; // only skips the column
                }
                // Without a label, continue only skips the column.
                // With a label: continue fila; would jump to the
                // next complete row.
                System.out.println("  Value: " + datos[i][j]);
            }
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
Processing row 0:
  Negative value — skipping the whole row
  Value: 3
Processing row 1:
  Negative value — skipping the whole row
  Negative value — skipping the whole row
Processing row 2:
  Value: 7
  Value: 8
  Value: 9
```

In this case, `continue` without a label only skips the current column. If we wanted to skip the whole row when we find a negative value, we would use a label: `continue fila;` (where `fila:` is the label of the outer loop).

## Common pattern: Early return

The **early return** pattern uses `return` at the start of a method to handle special cases without nesting conditionals:

<CodeBlock lang="java" title="Early return — validate and exit early">
{`public class ProcesarPedido {
    public static String procesarPedido(
            double monto, boolean tieneCupon) {

        // Special cases: exit early
        if (monto <= 0) {
            return "Error: invalid amount";
        }
        if (monto > 100000) {
            return "Error: amount exceeds the limit";
        }

        // Main logic
        double total = monto;
        if (tieneCupon) {
            total *= 0.9; // 10% discount
        }
        if (total >= 500) {
            total *= 0.95; // 5% additional for high purchases
        }

        return "Total to pay: $" + total;
    }

    public static void main(String[] args) {
        System.out.println(procesarPedido(100, true));
        System.out.println(procesarPedido(600, false));
        System.out.println(procesarPedido(-50, false));
    }
}`}
</CodeBlock>

**Expected output:**
```
Total to pay: $90.0
Total to pay: $570.0
Error: invalid amount
```

Without early return, the code would need multiple levels of nested `if`, making it harder to read.

## When to use each statement

| Situation | Statement | Example |
|-----------|-----------|---------|
| You found what you were looking for in a loop | `break` | Find a file in a list |
| You want to skip elements that do not meet a condition | `continue` | Filter null or negative values |
| The method already has the result it must return | `return` | Calculate and return an average |
| You need to exit nested loops | `break` with label | Search in a two-dimensional matrix |
| You need to jump to the next row of a matrix | `continue` with label | Process rows with incomplete data |
| Validate something at the start of a method | early `return` | Reject invalid input before processing |
