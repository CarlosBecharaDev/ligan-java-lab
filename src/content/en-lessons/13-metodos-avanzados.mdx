## Method composition

A method can **call other methods**. This lets you split a complex problem into smaller, more manageable parts. Each method does one specific, well-defined thing.

<CodeBlock lang="java" title="Methods that call other methods">
{`public class Composicion {
    static double calcularDescuento(double monto, double porcentaje) {
        return monto * porcentaje / 100;
    }

    static double calcularImpuesto(double base, double tasa) {
        return base * tasa / 100;
    }

    static double precioFinal(double monto, double desc, double imp) {
        double descuento = calcularDescuento(monto, desc);
        double base = monto - descuento;
        double impuesto = calcularImpuesto(base, imp);
        return base + impuesto;
    }

    public static void main(String[] args) {
        double total = precioFinal(50000, 15, 16);
        System.out.printf("Final price: $%.2f%n", total);
    }
}`}
</CodeBlock>

**Expected output:**
```
Final price: $45800.00
```

`precioFinal` calls `calcularDescuento` and `calcularImpuesto`, which are helper methods that each encapsulate a separate calculation.

## Recursion

A method can **call itself**. This is called recursion, a powerful technique for solving problems that have subproblems of the same type.

<CodeBlock lang="java" title="Recursion — factorial">
{`public class Factorial {
    static long factorial(int n) {
        if (n <= 1) return 1;          // base case
        return n * factorial(n - 1);   // recursive case
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));
        System.out.println("10! = " + factorial(10));
    }
}`}
</CodeBlock>

**Expected output:**
```
5! = 120
10! = 3628800
```

Recursion has **two essential parts**:

```
factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * factorial(2)
= 5 * 4 * 3 * 2 * factorial(1)
= 5 * 4 * 3 * 2 * 1
= 120
```

**Without a base case**, recursion would be infinite and cause a `StackOverflowError`.

## Recursive Fibonacci

<CodeBlock lang="java" title="Recursion — Fibonacci">
{`public class Fibonacci {
    static int fibonacci(int n) {
        if (n <= 0) return 0;
        if (n == 1) return 1;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 10; i++) {
            System.out.printf("fib(%d) = %d%n", i, fibonacci(i));
        }
    }
}`}
</CodeBlock>

**Expected output:**
```
fib(0) = 0
fib(1) = 1
fib(2) = 1
fib(3) = 2
fib(4) = 3
fib(5) = 5
fib(6) = 8
fib(7) = 13
fib(8) = 21
fib(9) = 34
fib(10) = 55
```

**Note:** For large values of `n`, this recursive version is slow because it recomputes the same values many times. The iterative version is more efficient for this particular case.

## Recursion with arrays

Recursion is natural for processing arrays, especially when looking for a repeating pattern:

<CodeBlock lang="java" title="Recursion — sum of elements">
{`public class SumaArreglo {
    static int suma(int[] arr, int indice) {
        if (indice >= arr.length) return 0;  // base case
        return arr[indice] + suma(arr, indice + 1);
    }

    public static void main(String[] args) {
        int[] numeros = {3, 7, 2, 9, 5};
        System.out.println("Sum: " + suma(numeros, 0));
    }
}`}
</CodeBlock>

**Expected output:**
```
Sum: 26
```

## Varargs — variable arguments

Java lets you receive an **indeterminate number of arguments** of the same type with the `Type... args` syntax:

<CodeBlock lang="java" title="Varargs — sum any number of values">
{`public class Varargs {
    static double sumar(double... numeros) {
        double total = 0;
        for (double n : numeros) {
            total += n;
        }
        return total;
    }

    static void imprimir(String separador, String... palabras) {
        for (int i = 0; i < palabras.length; i++) {
            System.out.print(palabras[i]);
            if (i < palabras.length - 1) {
                System.out.print(separador);
            }
        }
        System.out.println();
    }

    public static void main(String[] args) {
        System.out.println("Sum: " + sumar(1, 2, 3));
        System.out.println("Sum: " + sumar(10, 20, 30, 40));
        imprimir(", ", "Java", "Python", "C++");
    }
}`}
</CodeBlock>

**Expected output:**
```
Sum: 6.0
Sum: 100.0
Java, Python, C++
```

Internally, `double... numeros` is a `double[]`. You can pass it as a regular array or as separate arguments.

## Javadoc documentation

Methods are documented with Javadoc comments that describe what they do, their parameters, and what they return:

```java
/**
 * Computes the average of an array of doubles.
 * @param notas Array with the grades
 * @return The average of all grades
 * @throws IllegalArgumentException if the array is empty
 */
static double promedio(double[] notas) {
    if (notas.length == 0) {
        throw new IllegalArgumentException("Empty array");
    }
    double suma = 0;
    for (double n : notas) suma += n;
    return suma / notas.length;
}
```
