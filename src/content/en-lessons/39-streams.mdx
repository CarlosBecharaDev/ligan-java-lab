## What is a Stream?

A **Stream** is a sequence of elements that supports chained functional operations (pipeline). It is not a data structure: it is a **view** that allows you to process data declaratively.

```java
// Instead of:
for (Producto p : productos) {
    if (p.precio > 100) {
        System.out.println(p);
    }
}

// Stream (more expressive):
productos.stream()
    .filter(p -> p.precio > 100)
    .forEach(System.out::println);
```

## Stream Pipeline

A pipeline has three parts:

1. **Source**: `collection.stream()` or `Stream.of(...)`
2. **Intermediate operations**: `filter`, `map`, `sorted` (they return a Stream)
3. **Terminal operation**: `forEach`, `collect`, `count` (they produce a result)

<CodeBlock lang="java" title="Complete Stream Pipeline">
{`import java.util.*;
import java.util.stream.*;

public class PipelineStream {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(5, 2, 8, 1, 9, 3, 7);

        List<String> resultado = nums.stream()           // source
            .filter(n -> n > 3)                          // intermediate
            .map(n -> "Number: " + n)                    // intermediate
            .sorted()                                    // intermediate
            .collect(Collectors.toList());               // terminal

        System.out.println(resultado);
    }
}`}
</CodeBlock>

**Expected output:**
```
[Number: 5, Number: 7, Number: 8, Number: 9]
```

## Intermediate operations

<CodeBlock lang="java" title="The most common intermediate operations">
{`import java.util.*;
import java.util.stream.*;

public class OpIntermedias {
    public static void main(String[] args) {
        List<String> nombres = Arrays.asList(
            "Ana", "Luis", "María", "Carlos", "Ana", "Pedro", "Luisa");

        // filter — filter elements
        System.out.println("More than 4 letters:");
        nombres.stream()
            .filter(n -> n.length() > 4)
            .forEach(System.out::println);

        // map — transform elements
        System.out.println("In uppercase:");
        nombres.stream()
            .map(String::toUpperCase)
            .forEach(System.out::println);

        // distinct — remove duplicates
        System.out.println("Without duplicates:");
        nombres.stream()
            .distinct()
            .forEach(System.out::println);

        // sorted — sort
        System.out.println("Sorted:");
        nombres.stream()
            .sorted()
            .forEach(System.out::println);
    }
}`}
</CodeBlock>

## Terminal operations

<CodeBlock lang="java" title="Terminal operations — produce the final result">
{`import java.util.*;
import java.util.stream.*;

public class OpTerminales {
    public static void main(String[] args) {
        List<Integer> numeros = Arrays.asList(10, 20, 30, 40, 50);

        // forEach — apply an action to each element
        numeros.stream().forEach(n -> System.out.print(n + " "));
        System.out.println();

        // count — count elements
        long cantidad = numeros.stream()
            .filter(n -> n > 25)
            .count();
        System.out.println("> 25: " + cantidad);

        // collect — collect into a list
        List<Integer> mayores = numeros.stream()
            .filter(n -> n > 25)
            .collect(Collectors.toList());
        System.out.println("Greater: " + mayores);

        // toList — Java 16+
        List<Integer> menores = numeros.stream()
            .filter(n -> n < 30)
            .toList();
        System.out.println("Lesser: " + menores);

        // findFirst — first element (Optional)
        Optional<Integer> primero = numeros.stream()
            .filter(n -> n > 100)
            .findFirst();
        System.out.println("First > 100: " + primero.orElse(0));
    }
}`}
</CodeBlock>

## Collectors — grouping and partitioning

<CodeBlock lang="java" title="Grouping and partitioning with Collectors">
{`import java.util.*;
import java.util.stream.*;

public class CollectorsDemo {
    public static void main(String[] args) {
        List<String> palabras = Arrays.asList(
            "Java", "Python", "JavaScript", "C", "C++", "Go", "Rust");

        // groupingBy — group by criterion
        Map<Integer, List<String>> porLongitud = palabras.stream()
            .collect(Collectors.groupingBy(String::length));

        System.out.println("By length:");
        porLongitud.forEach((len, lista) ->
            System.out.printf("  %d: %s%n", len, lista));

        // partitioningBy — partition into true/false
        Map<Boolean, List<String>> particion = palabras.stream()
            .collect(Collectors.partitioningBy(p -> p.length() > 4));

        System.out.println("Long (>4): " + particion.get(true));
        System.out.println("Short (<=4): " + particion.get(false));

        // joining — join strings
        String unidas = palabras.stream()
            .collect(Collectors.joining(", "));
        System.out.println("Joined: " + unidas);
    }
}`}
</CodeBlock>

## Parallel streams

```java
// Parallelize with .parallelStream()
long total = lista.parallelStream()
    .filter(p -> p.precio > 100)
    .count();
```

**Important:** Use parallel streams only with large collections (>10,000 elements) and side-effect-free operations. The parallelization overhead reduces the benefit on small collections.
