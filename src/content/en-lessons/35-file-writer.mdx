## Writing to a file

<CodeBlock lang="java" title="Write with FileWriter and PrintWriter">
{`import java.io.*;

public class EscribirArchivo {
    public static void main(String[] args) {
        try (PrintWriter pw = new PrintWriter(new FileWriter("salida.txt"))) {
            pw.println("First line");
            pw.println("Second line");
            pw.printf("Number: %d%n", 42);
            System.out.println("File written successfully");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

**PrintWriter** offers familiar methods:
- `println(texto)` — writes line + line break
- `printf(formato, args...)` — writes formatted
- `print(texto)` — writes without a line break

## Append mode (add to the end)

<CodeBlock lang="java" title="Append to the end with FileWriter(ruta, true)">
{`import java.io.*;

public class AppendArchivo {
    public static void main(String[] args) {
        // The second parameter 'true' enables append
        try (FileWriter fw = new FileWriter("bitacora.txt", true);
             PrintWriter pw = new PrintWriter(fw)) {
            pw.println("New log entry");
            System.out.println("Entry added");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}`}
</CodeBlock>

## Writing with Files.writeString() (Java 11+)

<CodeBlock lang="java" title="Write a String directly with NIO.2">
{`import java.nio.file.*;

public class WriteString {
    public static void main(String[] args) throws Exception {
        Path ruta = Path.of("nota.txt");

        // Write all the text
        Files.writeString(ruta, "Hello World\\nJava NIO.2\\n");
        System.out.println("Written!");

        // Read it back
        String contenido = Files.readString(ruta);
        System.out.println("Content: " + contenido);
    }
}`}
</CodeBlock>

## Creating directories and files

<CodeBlock lang="java" title="Create a directory structure">
{`import java.nio.file.*;

public class CrearDirectorios {
    public static void main(String[] args) throws Exception {
        // Create directory (fails if it already exists)
        Path dir = Path.of("reportes/ventas");
        Files.createDirectories(dir);
        System.out.println("Directory created: " + dir);

        // Create file
        Path archivo = dir.resolve("ventas.txt");
        Files.createFile(archivo);
        System.out.println("File created: " + archivo);

        // Create and write in a single step
        Files.writeString(archivo, "Sales data here");
        System.out.println("Data written");

        // Verify
        System.out.println("Exists: " + Files.exists(archivo));
        System.out.println("Size: " + Files.size(archivo) + " bytes");
    }
}`}
</CodeBlock>

**Expected output:**
```
Directory created: reportes/ventas
File created: reportes/ventas/ventas.txt
Data written
Exists: true
Size: 18 bytes
```

## Writing a list of lines

<CodeBlock lang="java" title="Write several lines with Files.write()">
{`import java.nio.file.*;
import java.util.List;

public class EscribirLista {
    public static void main(String[] args) throws Exception {
        List<String> lineas = List.of(
            "Nombre,Edad,Ciudad",
            "Ana,25,Bogotá",
            "Luis,30,Medellín"
        );

        Path archivo = Path.of("personas.csv");
        Files.write(archivo, lineas);
        System.out.println("CSV created with " + lineas.size() + " lines");

        // Read back
        List<String> leidas = Files.readAllLines(archivo);
        for (String linea : leidas) {
            System.out.println("  " + linea);
        }
    }
}`}
</CodeBlock>
