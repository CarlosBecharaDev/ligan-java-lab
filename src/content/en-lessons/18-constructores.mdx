## What is a Constructor?

A **constructor** is a special method that runs automatically when you create an object with `new`. Its job is to initialize the object's attributes.

```java
public class Mascota {
    String nombre;
    int edad;

    // Constructor
    Mascota(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }
}

// Usage
Mascota m = new Mascota("Max", 3);  // The constructor is called
System.out.println(m.nombre);       // "Max"
```

**Differences between constructor and method:**

| Characteristic | Constructor | Method |
|---------------|-------------|---------|
| Called with | `new` | `objeto.metodo()` |
| Name | Same as the class | Any valid name |
| Return | None (not even void) | Can have any type |
| Executes | Once (when created) | As many times as it is called |

## The `this` Keyword

`this` refers to the **current object**. It is useful when the parameter has the same name as the attribute:

```java
public class Persona {
    String nombre;
    int edad;

    // Without this: the "nombre" parameter SHADOWS the attribute
    Persona(String nombre, int edad) {
        nombre = nombre;  // ❌ The parameter is assigned to itself
        edad = edad;      // ❌ Same problem
    }

    // With this: the attribute is distinguished from the parameter
    Persona(String nombre, int edad) {
        this.nombre = nombre;  // ✅ this.nombre = attribute
        this.edad = edad;      // ✅ nombre = parameter
    }
}
```

## Default Constructor

If you don't define any constructor, Java creates an empty one automatically:

```java
public class Persona {
    String nombre;
    int edad;
    // Java implicitly creates: Persona() {}
}

// You can use it without problems
Persona p = new Persona();  // ✅ Works
p.nombre = "Ana";           // You assign afterwards
```

But **as soon as you define a constructor**, Java no longer creates the default one:

```java
public class Persona {
    String nombre;

    Persona(String nombre) {
        this.nombre = nombre;
    }
}

// This no longer compiles
Persona p = new Persona();  // ❌ Error: there is no parameterless constructor
```

If you need both, define both explicitly.

## Overloaded Constructor

You can have multiple constructors with different parameters (overloading):

```java
public class Persona {
    String nombre;
    int edad;
    String email;

    // Full constructor
    Persona(String nombre, int edad, String email) {
        this.nombre = nombre;
        this.edad = edad;
        this.email = email;
    }

    // Partial constructor
    Persona(String nombre, int edad) {
        this(nombre, edad, "Sin email");  // Calls the other constructor
    }

    // Minimal constructor
    Persona(String nombre) {
        this(nombre, 0);  // Calls the previous one
    }

    // Default constructor (empty)
    Persona() {
        this("Desconocido");  // Calls the previous one
    }
}
```

**Call flow:**
```
new Persona()           → calls Persona(String)
new Persona("Ana")      → calls Persona(String, int)
new Persona("Ana", 25)  → calls Persona(String, int, String)
```

## Real Example: Health 🏥

<CodeBlock
  title="Patient constructor"
  lang="java"
  code={`public class Paciente {
    String nombre;
    int edad;
    double temperatura;
    String diagnostico;

    // Full constructor (for new patients)
    Paciente(String nombre, int edad, double temperatura, String diagnostico) {
        this.nombre = nombre;
        this.edad = edad;
        this.temperatura = temperatura;
        this.diagnostico = diagnostico;
    }

    // Quick constructor (emergency: only name and temperature)
    Paciente(String nombre, double temperatura) {
        this(nombre, 0, temperatura, "Por determinar");

    // Transfer constructor (with previous diagnosis)
    Paciente(String nombre, int edad, String diagnostico) {
        this(nombre, edad, 36.5, diagnostico);
    }

    boolean necesitaUrgencia() {
        return temperatura >= 39.0;
    }

    void mostrarFicha() {
        String urgencia = necesitaUrgencia() ? " [URGENCIA]" : "";
        System.out.println(nombre + " (" + edad + " años) - " + temperatura + "°C");
        System.out.println("Diagnóstico: " + diagnostico + urgencia);
    }

    public static void main(String[] args) {
        Paciente p1 = new Paciente("Carlos", 45, 36.8, "Resfriado");
        Paciente p2 = new Paciente("Ana", 39.5);  // Only name and temperature
        Paciente p3 = new Paciente("Pedro", 67, "Diabetes");

        p1.mostrarFicha();
        p2.mostrarFicha();
        p3.mostrarFicha();
    }
}`}

## Real Example: E-commerce 🛒

<CodeBlock
  title="Product constructor with validation"
  lang="java"
  code={`public class Producto {
    String nombre;
    double precio;
    int stock;

    // Full constructor with validation
    Producto(String nombre, double precio, int stock) {
        this.nombre = nombre;
        this.precio = Math.max(0, precio);  // No negatives
        this.stock = Math.max(0, stock);
    }

    // Sale constructor (original price and discount)
    Producto(String nombre, double precioOriginal, double descuento, int stock) {
        this(nombre, precioOriginal * (1 - descuento), stock);
    }

    // Out-of-stock product
    Producto(String nombre, double precio) {
        this(nombre, precio, 0);
    }

    double precioConIva(double iva) {
        return precio * (1 + iva);
    }

    void mostrar() {
        String estado = stock > 0 ? "Disponible" : "Agotado";
        System.out.println(nombre + " - $" + precio + " | " + estado + " (" + stock + ")");
    }

    public static void main(String[] args) {
        Producto normal = new Producto("Laptop", 1200.00, 10);
        Producto oferta = new Producto("Mouse", 45.00, 0.20, 50);  // 20% discount
        Producto agotado = new Producto("Teclado", 89.99);

        normal.mostrar();    // Laptop - $1200.0 | Disponible (10)
        oferta.mostrar();    // Mouse - $36.0 | Disponible (50)
        agotado.mostrar();   // Teclado - $89.99 | Agotado (0)
    }
}`}

## Summary

| Concept | Description |
|----------|-------------|
| **Constructor** | Special method that initializes an object when it is created |
| **Default constructor** | No parameters, Java creates it if there are no others |
| **Parameterized constructor** | With parameters to initialize attributes |
| **Overloading** | Multiple constructors with different signatures |
| **this** | Reference to the current object |

## Frequently Asked Questions

<details>
<summary>Can I have a void constructor?</summary>
No. A constructor has no return type, not even void. If you write `void MiClase(){}`, it is interpreted as a normal method.
</details>

<details>
<summary>Can a constructor call another constructor?</summary>
Yes, with `this(...)`. It must be the first line of the constructor.
</details>

<details>
<summary>What happens if I don't use this in the constructor?</summary>
The parameter "shadows" the attribute. `nombre = nombre` assigns the parameter to itself, and the attribute stays at its default value.
</details>

<details>
<summary>When do I use a default constructor?</summary>
When initialization is optional or the object can work without initial data. For example, an object that is filled later with setters.
</details>
